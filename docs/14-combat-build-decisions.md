# 诸世问道：战斗与 Build 已确认决策

> 状态：Matt `grill-with-docs` 进行中的阶段性决策记录。
>
> 用途：记录第 5～6 轮已确认的战斗与 Build 方向；完整 Grill 结束后再归并到正式设计文档。

## 1. 战斗空间

战斗发生在当前地图原地，不切换独立战斗背景。

位置、距离、遮挡、地形、阵法区域具有战术意义，但不以动作游戏级精准操作作为考核。

核心原则：

> **位置是战术资源，不是手速资源。**

## 2. 时间运行

采用可暂停实时（RTwP）式战术时间轴：

- 非暂停时战斗时间持续推进。
- 玩家可主动暂停查看战场并下达行动。
- 关键情况可以触发自动暂停，例如行动完成、危险术法出现、重伤、新敌人加入或队友倒下。
- 每个动作拥有施法 / 启动时间、执行窗口和可能的打断条件。

不把系统做成“回合制外面套时间条”。

## 3. 控制对象

玩家只完全控制主角。

盟友采用简化战术倾向与有限指令，例如：保护、集火、保留法力、撤退、跟随、自由行动。

不把游戏发展成多角色技能栏管理型 CRPG。

## 4. 战斗 Build

玩家可以掌握大量功法、术法和其他能力，但当前一世 / 当前战斗只配置有限的实战方案。

配置应覆盖：

- 主修功法。
- 有限数量的战斗术法。
- 身法。
- 护体 / 防御手段。
- 法宝。
- 消耗品。

具体槽位数量后续平衡。

战斗中不能随意把所有已掌握能力当作无限工具箱；重大配置变化需要脱离战斗，部分变化还可能需要准备时间或闭关。

## 5. 生存与伤势

不使用单一 HP 作为完整生存模型，也不做器官级模拟。

采用“基础生存资源 + 结构化伤势”的中间方案，例如：

- 气血。
- 法力。
- 护体。
- 轻伤 / 重伤。
- 经脉损伤。
- 神魂受创。
- 中毒。
- 特殊伤势。

战斗胜利不等于状态恢复。惨胜产生的疗伤时间、错失事件和后续风险属于正式玩法后果。

## 6. 一击致死

允许具有明确规则依据的一击致死，例如明显境界压制、致命术法命中要害、护体失效后的强力攻击等。

不允许无意义的低概率随机猝死。

因此“不要被这一招命中”可以成为有效 Knowledge。

## 7. Knowledge 与战斗

Knowledge 不直接展示完全游戏化的下一招伤害、命中率和精确数值答案。

它主要揭示：

- 敌人习惯。
- 技能顺序。
- 功法缺陷。
- 旧伤。
- 空门。
- 隐藏阶段。
- 虚弱时间窗口。
- 可提前准备的克制手段。

表现层可据此提供更可靠的时间轴预警、特殊提示或额外战术选项。

## 8. 战斗与资源经济

战斗不是主要资源生成器。

资源可以来自宗门份额、坊市交易、人物关系、秘境、灵地、委托、生产、抢夺、杀人夺宝和 Knowledge 截胡机缘等多种渠道。

杀人夺宝可以高收益，但需要承担追查、仇怨、势力关系、因果、赃物印记或高阶人物介入等后果。

核心原则：

> **战斗是解决冲突和争夺资源的重要方式，但不能退化为“缺什么就刷怪”。**

## 9. 功法、术法与神通

三者严格区分：

- **功法**：修士如何修炼、如何形成自身力量体系的长期路径。
- **术法**：修士如何调用已有力量完成攻击、防御、身法、控制、治疗、探查等具体行为。
- **神通**：由高层修炼、特殊传承、体质、血脉或重大悟道形成的稀有规则能力。

神通不是普通术法的高等级版本，应具有明显规则改变能力。

## 10. 主修与兼修

每一世存在明确主修功法。

允许有限兼修辅助法门，但兼修会受到：

- 修炼时间。
- 资源。
- 属性与经脉兼容。
- 功法冲突。
- 突破路线。
- 隐患与反噬。

等限制。

不采用“同时修十几门功法并叠加全部收益”的设计。

## 11. 术法掌握

术法可以存在掌握层级，例如初学、熟练、精通、化境，但不通过机械重复施放刷经验升级。

成长来源包括：

- 实际使用。
- 修炼参悟。
- 师承指导。
- 战斗经历。
- 特殊事件。
- Knowledge 带来的理解优势。

层级提升优先改变规则、用途和施法方式，而不仅是提高数值。

## 12. 神通稀有度

真正神通应保持稀有。

主要来源包括：

- 大境界质变。
- 功法深层修炼。
- 特殊体质或血脉。
- 高阶传承。
- 重大悟道。
- 特殊人生经历。

一个低阶修士掌握多种普通术法但没有真正神通属于正常状态。

## 13. 法宝

法宝是拥有独立能力、限制和来历的能力对象，而不是简单数值装备。

法宝可以具有：

- 主动 / 被动能力。
- 境界或法力要求。
- 炼化程度。
- 主人印记。
- 损坏与修复。
- 被抢夺 / 遗失。
- 追踪风险。
- 隐藏秘密或反噬。

法宝与承世系统存在天然互动，一件关键法宝是否带回下一世应成为重要选择。

## 14. 丹药、符箓与其他消耗品

消耗品允许很强，因为它们代表玩家基于信息进行的主动准备。

丹药、符箓、毒物、阵盘等可以帮助玩家制造原本不存在的胜机，但受到钱、材料、制作能力、数量、使用条件、持续时间、副作用和携带风险约束。

核心原则：

> **Knowledge 应能通过“提前准备正确的东西”改变未来。**

## 15. 修仙技艺 / 道艺

炼丹、炼器、制符、阵法、灵植、御兽等可以作为世界中的完整修仙技艺存在，但不要求每一门都发展为独立复杂小游戏或生产模拟器。

每门道艺主要通过：

- 技艺层级。
- 配方 / 知识。
- 材料与资源。
- 时间投入。
- 关键决策。
- 相关事件与人物。

体现。

单个角色通常只深修少数道艺，其余需求应通过坊市、宗门、朋友、交换、委托甚至抢夺解决，以保持 NPC 与修真社会的价值。

## 16. Knowledge 与实际掌握严格分离

前世 Knowledge 保留“玩家知道什么”，但不自动恢复角色身体、法力、经脉适应或实际术法掌握。

例如上一世花二十年精通某剑诀，回到少年 Anchor 后：

- 玩家仍记得诀窍、错误路径、师承位置和修炼方法。
- 重新学习可以显著加速，并跳过已知错误。
- 但当前角色仍需重新建立相应身体、经脉、法力和实际掌握。

除非通过承世或其他明确跨世规则保留某项成果，否则 Knowledge 不能成为隐藏的修为继承。

核心边界：

> **Knowledge 决定“我知道什么”；当前现实状态与承世决定“我现在拥有什么、真正会什么”。**
