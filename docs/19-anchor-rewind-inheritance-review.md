# 诸世问道：Anchor / 回溯 / 承世 / 悟世二次审视

> 状态：Matt `grill-with-docs` 第 11 轮已确认决策。
>
> 用途：在完整玩法设计收口前，对早期多世核心规则在当前修仙 RPG 设计下进行二次校验；后续统一归并到正式核心设计文档。

## 1. 每世界基础 10 次回溯

- 每个新 World 基础拥有 10 次回溯。
- 第一世不消耗回溯次数，因此一个 World 理论上最多可经历第一世 + 10 次重新开启的人生。
- 普通游戏流程不能稳定刷取或恢复回溯次数。
- 回溯次数越少，继续通过死亡换情报的成本越高。
- 回溯为 0 时，当前仍存活的一世继续正常进行；再次死亡则该 World 结束。

回溯次数是需要管理的世界级战略资源，不是可以通过重复劳动恢复的体力值。

## 2. Anchor 永久保留

一个 World 中已经建立的后期 Anchor，不会因为玩家后来选择更早 Anchor 重走历史而消失。

例如玩家已经拥有：

```text
炼气 Anchor
筑基 Anchor
紫府 Anchor
```

之后即使从炼气 Anchor 开始另一条人生路线，原筑基 / 紫府 Anchor 仍然是已经被固定在命轮之外的可选未来起点。

Anchor 因此不是普通存档，也不是当前现实时间线中唯一存在的历史节点。

## 3. 每个大境界只能定世一次

- 初始 Anchor 自动占用初始大境界的 Anchor 位。
- 之后每个大境界最多拥有一个 Anchor 位。
- 玩家可以自行选择该境界内何时“定世”。
- 一旦建立，不可覆盖、不可更新、不可重置。

“刚突破就定世”与“在该境界经营多年后再定世”应形成真实战略取舍。

## 4. Anchor 保存完整现实状态

Anchor 是该时刻完整现实世界的合法快照，包括但不限于：

- 玩家角色状态。
- 境界、修为、功法、术法掌握。
- 装备、法宝、普通物品。
- NPC 状态、生死、位置与关系。
- 玩家社会身份。
- 势力与派系状态。
- 资源归属。
- Event Chain 状态。
- 地图 / 地点变化。
- 市场与地区状态。
- 当前世界时间。

不属于 Anchor 快照的命轮外信息：

- Knowledge。
- Trait Library。
- 回溯次数等 World 级跨世状态。
- 需要特殊处理的世界级唯一物身份状态。

## 5. 死亡结算顺序

标准顺序继续保持：

```text
死亡
→ 冻结本世状态
→ 一世总结
→ 更新 Knowledge / 历史
→ 选择下一世 Anchor
→ 承世 OR 悟世
→ 配置本世 Trait
→ 消耗一次回溯
→ 开启下一世
```

先选 Anchor，再决定承世 / 悟世，因为同一成果带回炼气、筑基或更晚 Anchor 的战略价值并不相同。

## 6. 承世：一次只带一项合法成果

承世可以携带一项本世死亡时仍然合法拥有或掌握的成果。

### 可承世的实体成果

- 法宝。
- 装备。
- 丹药。
- 特殊材料。
- 普通合法物品。
- 其他明确允许的成果单位。

### 可承世的修炼成果

- 一门功法的实际掌握状态。
- 一门术法的实际掌握状态。
- 其他明确允许的单项修炼成果。

### 绝对不可承世

- 境界。
- 修为。
- 当前法力上限等境界派生能力。
- 筑基道基。
- 紫府。
- 金丹等大境界本体结构。

承世修炼成果并不取消低境界身体、法力和规则限制。高阶术法即使被承世回到早期，也可能因当前境界不足而只能部分使用或暂时无法使用。

## 7. Knowledge 与承世的边界

Knowledge 保留：

> 我知道如何练、哪里容易错、谁能教、什么条件更合适。

承世保留：

> 这一项合法修炼成果本身被跨世带回来。

因此 Knowledge 可以显著降低重新学习成本，但不会自动把前世几十年的身体适应、法力积累和实际掌握全部塞进早期角色。

## 8. 世界级唯一物

唯一物继续使用 World 级唯一身份。

如果某唯一物被承世带回原获取时间之前：

- 原未来获取路径不再生成第二件相同唯一物。
- 选择更早 Anchor 也不会复制它。
- 如果之后没有继续承世，也没有把它固化进新的 Anchor，该唯一物可能真正从当前 World 的可达历史中失落。

唯一物规则用于保证多 Anchor + 承世不会形成无限复制漏洞，同时制造真实的跨世取舍。

## 9. 悟世与 Trait

悟世继续采用：

- 根据本世真实经历生成最多 3 个代表性 Trait 候选。
- 玩家选择 1 个加入当前 World 的 Trait Library。
- 无有效经历时允许没有候选。
- 同源 Trait 可以通过后续悟世成长，但每次升级仍消耗一次完整悟世选择。
- 每一世最多装备 5 个 Trait。

Trait 定位为“人生留下的规则印记”，优先提供：

- 信息能力。
- 特殊判断。
- 新事件 / 对话选项。
- 条件性规则改变。
- 特殊生存或战斗机制。

纯粹的永久百分比数值加成为次要甚至应避免的设计。

## 10. Trait 与境界门槛

Trait 跨 Anchor 保留，不要求回到低境界后失去。

但高境界人生形成的 Trait 可以拥有分阶段生效条件，例如：

```text
炼气 → 只提供微弱感应
筑基 → 开放主要规则效果
紫府 → 发挥完整能力
```

这样既保留历世成长感，也不允许炼气角色无条件调用紫府级能力边界。

## 11. 新 World 的 Meta Progression

一个 World 真正结束后：

- Knowledge 清空。
- Trait Library 清空。
- Anchor 清空。
- 当前世界物品与修为清空。

不采用跨 World 的永久战力堆叠，例如永久攻击、悟性、修炼速度等递增。

允许保留内容型 Meta Progression，例如：

- 世界史 / 命书收藏。
- 已见人物、功法、死法、秘境等图鉴。
- Steam 成就。
- 挑战条件。
- 新世界模板。
- 新的可选出身。
- 新内容模块或世界组合。

跨 World 成长主要扩大选择空间与内容广度，而不是让失败次数最终自动转化为数值碾压。
