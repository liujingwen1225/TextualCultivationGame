# 诸世问道：角色与修炼系统

> 状态：设计基线 V0.2  
> 依赖：`01-game-system-framework.md`、`02-v0.1-playable-prototype.md`  
> 目标：定义适合长期游玩的角色成长、修为、境界、功法、突破、寿元与跨世悟道规则。

---

# 1. 核心定位

修炼系统不是“经验条升级系统”，而是游戏长期成长的主轴。

玩家应持续面对四个问题：

1. **我是否值得花几年时间继续闭关？**
2. **我缺的是修为、资源、理解，还是机缘？**
3. **这一世还值得继续，还是应该用死亡/结束推演换取下一世优势？**
4. **我能否利用前世知识，用更短时间走过曾经走过的路？**

因此正式游戏必须满足：

> 境界提升慢，但修炼过程不能无聊；跨世之后可以“更聪明地修”，而不是简单获得永久经验加成。

---

# 2. 原型速度与正式速度必须分离

这是项目的硬性规则。

## 2.1 开发/测试模式

为了自动化测试、演示和开发，可提供：

```text
Game Balance Profile = DEVELOPMENT
```

特点：

- 修炼速度 10x～50x
- 事件等待时间缩短
- 可快速触发死亡/回溯
- 可快速验证突破和事件链

此模式只用于开发和测试。

## 2.2 正式模式

```text
Game Balance Profile = STANDARD
```

正式游戏不得为了“15 分钟 Demo”而破坏长期数值。

首个可玩 Demo 只需要让玩家体验：

```text
修炼
→ 遭遇事件
→ 死亡
→ 获得前世知识
→ 回溯
→ 出现新的前世选项
```

**不要求 Demo 中筑基。**

---

# 3. 长期成长目标

正式版目标不是“一晚上修到元婴”。

建议首轮无攻略玩家的真实游玩节奏参考：

| 阶段 | 建议累计有效游玩时间 |
|---|---:|
| 炼气前期 | 1～3 小时 |
| 炼气中期 | 3～8 小时 |
| 炼气后期 | 8～15 小时 |
| 第一次成功筑基 | 15～30 小时 |
| 筑基完整阶段 | 30～80 小时 |
| 第一次金丹 | 80 小时以上 |

这不是强制在线时长，而是内容和平衡目标。

熟悉世界、积累前世情报之后，同样道路可以明显缩短，例如第一次筑基 25 小时，后续高质量路线可能压缩到 10～15 小时。

**跨世知识的意义就是减少无效时间，而不是跳过整个游戏。**

---

# 4. 长期游玩不能靠“把经验条拉长”

每个大阶段都必须同时包含：

```text
修为积累
+
资源准备
+
功法理解
+
瓶颈处理
+
世界事件
+
NPC关系
+
探索/秘境
+
路线选择
```

禁止设计成：

```text
闭关 100 次
→ 修为满
→ 点击突破
```

理想节奏：

```text
修炼一段时间
↓
遇到瓶颈
↓
需要资源/指导/历练
↓
离开洞府进入世界
↓
发生人物与事件内容
↓
得到新的理解或资源
↓
再次闭关
↓
准备突破
```

这样升级慢仍然有游戏内容。

---

# 5. 角色状态模型

```text
Character State
├── Identity      身份
├── Innate        先天资质
├── Cultivation   修行状态
├── Body          身体状态
├── Capability    能力
└── Social        社会身份
```

## 5.1 Identity

- 姓名
- 性别
- 出生日期
- 当前年龄（由日期计算）
- 宗门
- 宗门身份
- 当前地点

首个版本使用固定主角模板，后续再开放随机/自定义角色。

## 5.2 Innate

- 五行灵根
- 悟性
- 体魄根基
- 神识资质
- 气运倾向
- 命格

先天属性重要，但不能直接决定角色是否“废号”。

## 5.3 Cultivation

- 大境界
- 小境界
- 当前修为
- 修为上限
- 当前瓶颈
- 根基稳定度
- 主修功法
- 功法理解度
- 已学术法
- 道基/金丹等境界特性

## 5.4 Body

- 生命状态
- 灵力
- 伤势
- 中毒
- 经脉
- 根基损伤
- 衰老
- 临时效果

---

# 6. 五行灵根

五行使用 0～100 连续数值：

```text
木 72
水 48
土 23
火 15
金 8
```

展示层可归纳：

> 木水偏灵根 / 木系主灵根

规则层始终使用数值。

## 6.1 灵根影响

- 功法适配
- 修炼效率
- 术法学习
- 突破方案
- 特殊机缘
- 后期悟道倾向

灵根原则上提供**效率差异而非绝对封锁**。

基础适配建议：

```text
灵根适配 = 0.70 + 属性亲和 / 200
```

大致范围 0.70～1.20。

资质好的人确实快，但不能出现 5 倍、10 倍基础差距，否则普通资质没有长期游玩价值。

---

# 7. 悟性、体魄、神识、气运

统一建议 1～100。

## 7.1 悟性

主要影响“理解”，而非直接增加修为：

- 功法理解
- 瓶颈突破
- 阵法学习
- 从失败中提取经验
- 悟道事件

## 7.2 体魄

- 生命
- 伤势恢复
- 中毒抗性
- 强行突破风险
- 炼体/特殊道基适配

## 7.3 神识

- 感知
- 阵法
- 伏击发现
- 秘境探索
- 部分战斗先手

## 7.4 气运

气运只轻度改变随机事件权重和极端结果。

不得设计成：

> 气运高 = 自动获得顶级传承。

关键机缘仍必须通过条件、路线和事件链获得。

# 8. 境界体系

长期版预留：

```text
凡人
↓
炼气 1～9 层
↓
筑基 初期 / 中期 / 后期 / 圆满
↓
金丹 初期 / 中期 / 后期 / 圆满
↓
元婴
↓
化神
↓
……
```

但设计与开发严格逐境界扩展。

当前阶段只实现炼气，筑基作为第一重大目标。

---

# 9. 炼气九层不是九根经验条

炼气划成三个阶段：

## 9.1 前期：1～3 层

主题：入门。

主要内容：

- 熟悉修炼
- 选择功法
- 宗门生活
- 基础资源
- 认识核心 NPC

瓶颈较弱。

## 9.2 中期：4～6 层

主题：路线形成。

开始要求：

- 更好的修炼环境
- 丹药/宗门资源
- 功法理解
- 历练
- 更危险的任务

不能只闭关解决所有问题。

## 9.3 后期：7～9 层

主题：为筑基准备。

需要：

- 修为圆满
- 根基稳定
- 筑基知识
- 资源
- 人脉/宗门资格
- 对自己功法的足够理解

炼气九层只是“有资格准备筑基”，不是自动进入筑基。

---

# 10. 修为积累

修为表示当前境界稳定积累。

```text
修炼收益 =
基础收益
× 功法效率
× 灵根适配
× 环境
× 身体状态
× 理解修正
× 资源修正
```

## 10.1 修为增长采用递减节奏

越接近当前境界圆满，普通闭关效率可轻度下降。

目的：促使玩家寻找更好的环境、资源或解决瓶颈，而不是永远点击同一按钮。

示例：

```text
0%～70%：正常
70%～90%：效率 -10%
90%～100%：效率 -25%，且更依赖理解/瓶颈
```

不是硬性公式，可作为平衡思路。

---

# 11. 修炼行动

不要只提供“3 天 / 30 天”两个按钮。

正式版建议：

### 打坐修炼

玩家选择：

- 3 天
- 10 天
- 30 天

适合短期推进。

### 闭关

玩家选择目标：

```text
修炼至某个修为阈值
尝试参悟功法
恢复伤势
冲击瓶颈
```

系统预计耗时，并允许重要事件中断。

### 研读

消耗时间提升功法/阵法等理解，而非修为。

### 历练

通过事件获得：

- 瓶颈理解
- 资源
- 战斗经验
- Knowledge

形成“闭关与入世”的循环。

---

# 12. 修炼环境

地点提供灵气品质和其他修正。

| 环境 | 基础修炼系数 |
|---|---:|
| 灵气贫瘠 | 0.70～0.80 |
| 普通地区 | 1.00 |
| 宗门普通修炼地 | 1.05～1.15 |
| 私人洞府 | 1.15～1.30 |
| 高品质灵地 | 1.30～1.50 |

高品质环境必须需要：

- 身份
- 灵石
- 宗门贡献
- 事件奖励
- 特殊关系

之一。

这样环境本身成为长期追求。

---

# 13. 功法系统

每部主修功法至少拥有：

```text
品阶
属性权重
境界上限
修炼效率
学习难度
理解难度
突破修正
特性
缺陷
特殊事件标签
```

## 13.1 低阶功法不是纯垃圾

低阶功法可以：

- 容易理解
- 资源消耗低
- 根基稳定
- 适合特定路线

高阶功法则可能：

- 修炼效率高
- 上限高
- 对资质/资源要求高
- 瓶颈困难
- 风险更大

避免简单的：

> 品阶更高 = 所有数值都更高。

---

# 14. 功法理解度

取值 0～100。

真正价值优先级：

```text
特殊选项解锁
>
突破辅助
>
修炼倍率
```

例如：

```text
青木诀理解 30
→ 看出运气路线的一个问题

理解 50
→ 解锁师父讨论事件

理解 70
→ 筑基时出现青木护脉方案

理解 90
→ 后续可能出现功法改良事件
```

因此功法可以长期培养，而不是拿到新功法立即淘汰旧功法。

---

# 15. 瓶颈系统

升级慢的关键不是修为需求大，而是**瓶颈需要解决**。

瓶颈分为：

### 修为瓶颈

继续修炼即可逐渐突破。

### 理解瓶颈

需要：

- 研读
- 师父指导
- 事件
- 历练
- 前世经验

### 资源瓶颈

需要：

- 丹药
- 灵地
- 宗门资格
- 特定材料

### 身体瓶颈

需要：

- 疗伤
- 稳固根基
- 修复经脉

### 机缘瓶颈

部分高价值路线需要特定事件/秘境，但**基础成长路线不能完全依赖随机机缘**。

---

# 16. 小境界突破

小境界不应全部是“一键概率”。

达到修为上限后，玩家进入瓶颈状态。

根据瓶颈准备程度，可能需要数日至数月完成突破。

结果可以包括：

- 顺利突破
- 延迟突破
- 失败并消耗时间
- 轻伤
- 修为回退少量

炼气小境界一般不设计高死亡率。

真正危险放在：

- 特殊功法
- 强行突破
- 大境界突破

---

# 17. 大境界突破：筑基

筑基是第一阶段长期目标。

玩家必须准备：

```text
炼气九层圆满
+
根基稳定
+
功法理解
+
筑基方法
+
筑基资源
+
合适环境
```

根据路线不同，还可能要求：

- 宗门身份
- NPC关系
- 秘境传承
- 特定 Knowledge

---

# 18. 筑基路线

## 18.1 宗门正统筑基

优点：

- 稳定
- 信息透明
- 可重复规划

要求：

- 宗门贡献
- 筑基丹
- 洞府资格
- 功法达到要求

缺点：

- 准备周期长
- 资源竞争
- 道基普通

## 18.2 黑水古修筑基

优点：

- 独特道基
- 能体现跨世情报价值

要求：

- 多世破解黑水秘境
- 获得传承
- 对阵法/功法有对应理解

缺点：

- 风险高
- 第一世几乎不可能完整掌握
- 未来改变后部分旧情报可能失效

未来可继续增加不同路线，但每一种都必须是**玩法路线**，不能只是换一个突破材料。

---

# 19. 突破结果

大境界至少支持：

1. 上品结果 / 完美筑基
2. 正常筑基
3. 勉强筑基
4. 失败但保命
5. 经脉重伤
6. 根基受损
7. 走火入魔
8. 死亡
9. 内容定义的特殊异变

后台可以用数值判定，但 UI 重点展示“准备程度与风险原因”。

例如：

```text
筑基准备：尚可

优势：
+ 功法理解充分
+ 洞府灵气稳定
+ 已服用筑基丹

风险：
- 经脉存在旧伤
- 根基稳定度不足
```

---

# 20. 寿元

寿元是长期压力，而不是装饰。

参考初始：

```text
年龄：16
炼气寿元上限：90
筑基寿元上限：180
```

游戏时间应该真实以“年”为尺度流逝。

一个角色可能：

```text
16 岁入宗
23 岁炼气六层
35 岁炼气九层
42 岁第一次筑基失败
51 岁第二次筑基
```

这比“三天炼气、五分钟筑基”更有修仙人生感。

---

# 21. 衰老

长期版应加入衰老阶段：

- 青壮：正常
- 年长：恢复轻微下降
- 暮年：体魄/恢复/突破承受下降

但不要让老年角色完全不能玩。

可能出现：

> 寿元所剩无几，只能冒险进入秘境寻找筑基机缘。

这种压力本身就是内容。

---

# 22. 伤势与根基

基础状态：

- 健康
- 轻伤
- 重伤
- 经脉受损
- 中毒
- 根基受损

长期游玩需要让“带伤继续修炼”成为真实取舍。

根基受损尤其重要：

> 某一世虽然没死，但已经失去正常筑基希望。

此时玩家可以：

- 花多年寻找修复方法
- 走危险特殊路线
- 继续探索换 Knowledge
- 主动结束本次推演

这样失败不必立即死亡也能产生 Roguelite 决策。

---

# 23. 跨世悟道 Insight

永久成长不保留修为，但允许保留部分“理解”。

分三类：

### 功法悟道

对某部功法的理解。

### 境界悟道

经历某个瓶颈/突破失败之后获得。

### 技艺悟道

阵法、丹道等理解。

示例：

```text
第一世：
炼气六层瓶颈花费 2 年

结算获得：
炼气六层瓶颈悟道 +20

下一世：
相同瓶颈所需时间明显减少
并可能出现新的处理选项
```

这比永久增加“修炼速度 +5%”更有意义。

---

# 24. 跨世悟道必须有上限

不允许玩家靠重复自杀把某功法直接刷满。

建议：

- 每个阶段可继承理解有阶段上限。
- 重复同样失败的边际收益快速下降。
- 新的 Insight 主要来自首次经历、不同方案和更深入结果。

例如：

```text
第一次筑基失败：高悟道收益
第二次相同原因失败：低收益
第三次完全相同失败：几乎无收益
```

逼迫玩家探索新的方案，而不是对刷。

---

# 25. 长期成长中的“追赶机制”

多世之后，玩家不应该每次都花 20 小时重新从炼气三层走一遍。

但也不能直接跳级。

采用三类加速：

## 25.1 路线知识

玩家知道：

- 哪种功法更适合自己
- 哪里能拿到资源
- 哪些任务值得做
- 哪些 NPC 可以帮助自己

减少试错。

## 25.2 悟道加速

已走过的小瓶颈更容易再次通过。

## 25.3 事件捷径

前世 Knowledge 解锁新的高效率选项。

例如：

```text
普通路线：
做三个月宗门任务换贡献

前世路线：
★ 提前帮助陈执事解决药园问题
→ 一次获得足够贡献
```

这使第二世更快是因为**玩家知道正确办法**，而不是系统送经验。

---

# 26. 防止重复劳动

长期游戏最大的风险不是“升级慢”，而是“每一世重复做同样的事情”。

因此规定：

1. 已验证的低风险行动可支持批量时间推进。
2. 已掌握事件可以提供“快速处理”选项。
3. 前世知识可以跳过部分已完全解决的教学步骤。
4. 高价值节点仍需要玩家选择。
5. 新世界线偏移后，快速处理可能失效。

例如：

```text
第一次：完整经历 6 段入门任务

第三世：
【前世已熟悉】快速完成宗门入门杂务（30天）
```

避免 Roguelite 变成重复点击。

---

# 27. 长期境界内容原则

以后每开放一个新大境界，必须同时提供：

- 新修炼资源
- 新人物层级
- 新地点
- 新风险
- 新突破方式
- 新事件链
- 新功法选择
- 新的时间尺度

不能只增加：

> 修为上限从 1 万变成 10 万。

境界本质上是“新的玩法层”。

# 28. 当前原型实际验证范围

为了不让长期目标拖垮第一版，V0.1 只验证：

```text
炼气三层
→ 修炼积累
→ 遇到一个小瓶颈
→ 黑水事件链
→ 死亡
→ Insight / Knowledge
→ 回溯
→ 第二世更高效地处理相同阶段
```

**V0.1 不以筑基为完成条件。**

筑基作为第一个正式版本的重要长期里程碑。

# 29. 平衡测试指标

以后需要记录：

- 玩家平均多久提升一个小境界
- 每一世平均游戏内经过多少年
- 玩家每小时遭遇多少有意义事件
- 修炼行动占比
- 纯等待/无决策时间
- 首次筑基耗时
- 第 N 世相同阶段耗时缩短比例
- 玩家主动结束推演的原因
- 突破失败原因分布

目标不是让升级快，而是：

> **升级慢，但玩家始终在做有意义的规划。**

---

# 30. 规则不变量

开发必须保持：

1. 境界只能由正式突破流程改变。
2. Run 中的境界、修为、物品不能直接写入 Meta。
3. Meta 只保存明确允许的 Knowledge、Insight、诸世记录和天衍相关资源。
4. 同样失败的跨世收益存在边际递减。
5. 正式模式与开发加速模式的平衡配置必须隔离。
6. AI 不得直接修改修为、境界、寿元、物品和突破结果。
7. 任何境界都必须有玩法内容，不允许只靠增加修为需求延长时长。

# 31. 当前结论

《诸世问道》的长期成长应形成：

```text
这一世花十年踩坑
↓
死亡并理解原因
↓
下一世用三年解决同一问题
↓
把省下来的七年投入新的道路
↓
抵达过去从未见过的未来
```

因此游戏的核心成长不是简单的：

> 数值越来越高。

而是：

> **玩家越来越懂得如何使用自己有限的一生。**
