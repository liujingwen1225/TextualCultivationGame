# 诸世问道：角色与修炼系统

> 状态：设计基线 V0.1  
> 依赖：`01-game-system-framework.md`、`02-v0.1-playable-prototype.md`  
> 目标：定义角色、灵根、修为、功法、境界、突破、寿元、伤势与跨世悟道的统一规则，使“修仙成长”本身可玩，同时服务“推演—死亡—回溯—改命”的核心循环。

---

# 1. 设计目标

角色与修炼系统必须同时满足以下目标：

1. **时间有价值**：修炼不是点击领取经验，而是用寿元交换成长。
2. **资质重要但不决定命运**：灵根影响效率，不能把普通资质角色直接判死刑。
3. **境界不是纯等级**：突破需要修为、理解、状态和准备方案共同满足。
4. **失败有内容价值**：失败可以产生伤势、经验、情报或跨世悟道，而非只有“重来”。
5. **不同路线真实不同**：正统筑基、秘境筑基等路线应在成本、风险和长期特性上有差异。
6. **跨世成长不能破坏 Roguelite**：物质和境界随推演消失，知识与部分理解可保留。
7. **数值必须可解释**：玩家应该知道自己为什么修得快、为什么突破失败、哪里可以改善。

---

# 2. 角色状态模型

角色状态分为六组。

```text
Character State
├── 身份 Identity
├── 先天 Innate
├── 修行 Cultivation
├── 身体 Body
├── 能力 Capability
└── 社会 Social
```

## 2.1 身份 Identity

V0.1 至少包含：

- 姓名
- 性别（可暂不影响规则）
- 出生日期
- 当前年龄
- 宗门
- 宗门身份
- 当前地点

V0.1 使用固定主角模板，暂不做随机捏人。

## 2.2 先天 Innate

先天属性原则上在单次角色生命周期内不自然变化：

- 五行灵根
- 悟性
- 体魄根基
- 神识资质
- 气运倾向
- 命格（V0.1 可只预留）

## 2.3 修行 Cultivation

- 当前大境界
- 当前小境界
- 当前修为
- 当前瓶颈
- 主修功法
- 已学功法/术法
- 功法理解度
- 当前修炼效率
- 道基特性（筑基后）

## 2.4 身体 Body

- 当前生命状态
- 灵力
- 伤势
- 中毒
- 经脉状态
- 根基状态
- 临时增益/减益

## 2.5 能力 Capability

能力不全部做成传统 RPG 六维属性，而由基础属性、功法和状态推导。

V0.1 主要使用：

- 战斗能力
- 感知能力
- 阵法理解
- 丹药知识
- 身法/逃生能力

其中阵法、丹药等允许先使用等级或标签，而非复杂技能树。

## 2.6 社会 Social

角色本体只保存必要引用：

- 宗门贡献
- 身份权限
- 声望

NPC 关系和因果由独立系统维护。

# 3. 五行灵根

## 3.1 数据结构

五行灵根不是“单/双/三灵根”离散标签，而是五个 0–100 的亲和值。

例如：

```text
木 72
水 48
土 23
火 15
金 8
```

展示层可以根据数值自动归纳为：

> 木水偏灵根 / 木系主灵根

但规则层始终使用原始数值。

## 3.2 灵根的作用

灵根主要影响：

1. 对应属性功法的修炼效率。
2. 对应术法的掌握速度。
3. 特定突破方案的适配度。
4. 某些事件的隐藏选项。
5. 后期悟道倾向。

灵根**不直接决定能否修炼某功法**，除非功法明确存在硬性条件。

## 3.3 灵根效率建议

V0.1 不使用过大的倍率差异。

可采用：

```text
灵根适配系数 = 0.70 + 主属性亲和 / 200
```

亲和 20：0.80  
亲和 50：0.95  
亲和 80：1.10  
亲和 100：1.20

这样好资质明显更快，但普通资质仍可通过时间、环境、丹药和前世理解弥补。

## 3.4 多属性功法

多属性功法使用权重计算：

```text
适配 = Σ(灵根亲和 × 功法属性权重)
```

例如木 70%、水 30% 的功法，会同时参考木、水亲和。

# 4. 悟性、体魄、神识与气运

四项基础资质建议统一使用 1–100。

## 4.1 悟性

影响：

- 功法理解增长
- 术法学习
- 瓶颈理解
- 阵法学习
- 特殊悟道事件
- 从失败中提取“悟道”的效率

不直接增加修为获取。

## 4.2 体魄根基

影响：

- 最大生命
- 重伤承受
- 中毒抗性
- 强行突破容错
- 某些炼体/特殊筑基方案

## 4.3 神识资质

V0.1 主要影响：

- 感知检查
- 阵法检查
- 埋伏察觉
- 秘境探索

不建立独立神魂境界。

## 4.4 气运倾向

V0.1 不做“高气运 = 免费好东西”。

气运只可轻度影响：

- 随机事件池权重
- 极端判定中的小幅修正
- 稀有事件触发

核心剧情、突破与关键奖励不得由气运一项决定。

# 5. 境界结构

## 5.1 V0.1 范围

```text
炼气三层（初始）
↓
炼气四层
↓
...
↓
炼气九层
↓
筑基初期
```

完成筑基即视为 V0.1 主目标完成。

## 5.2 境界定义

每个小境界包含：

- 修为上限
- 基础修炼难度
- 基础战斗修正
- 基础灵力上限
- 是否存在瓶颈

示例基线：

| 境界 | 修为上限 | 备注 |
|---|---:|---|
| 炼气三层 | 300 | 初始 |
| 炼气四层 | 420 | 小瓶颈 |
| 炼气五层 | 560 |  |
| 炼气六层 | 720 | 小瓶颈 |
| 炼气七层 | 920 |  |
| 炼气八层 | 1160 | 小瓶颈 |
| 炼气九层 | 1450 | 筑基前圆满 |

这些值是第一版平衡参数，不属于不可修改的世界观常量。

# 6. 修为系统

## 6.1 修为不是经验值的包装

修为表示角色在当前境界积累并稳定下来的灵力与修行成果。

普通修炼收益由以下因素共同组成：

```text
本次修为收益 =
基础收益
× 功法效率
× 灵根适配
× 环境系数
× 身体状态
× 理解修正
× 资源修正
```

## 6.2 基础修炼行动

V0.1 提供两种主行动：

### 修炼 3 天

- 时间成本低。
- 适合玩家等待事件、处理日常。
- 无额外风险。

### 闭关 30 天

- 总效率略高于 10 次普通修炼。
- 期间无法处理普通可选事件。
- 重要/强制事件可中断闭关。
- 身体状态不佳时不允许长闭关。

## 6.3 环境系数

地点可以提供灵气等级。

建议：

| 环境 | 系数 |
|---|---:|
| 灵气贫瘠 | 0.75 |
| 普通区域 | 1.00 |
| 宗门修炼场 | 1.10 |
| 普通洞府 | 1.20 |
| 高品质灵地 | 1.35+ |

V0.1 不做动态灵脉经济。

## 6.4 身体状态

示例：

| 状态 | 修炼系数 |
|---|---:|
| 健康 | 1.00 |
| 轻伤 | 0.90 |
| 重伤 | 0.45 |
| 经脉受损 | 0.60 |
| 中毒 | 视毒素 |

严重状态可直接禁止闭关或突破。

# 7. 功法系统

## 7.1 功法定义

每部功法至少包含：

```text
id
名称
品阶
属性权重
境界要求
基础修炼效率
学习难度
特性
缺陷
突破修正
特殊条件
```

## 7.2 V0.1 主修功法

### 《青木诀》

定位：稳定、恢复、适合主角。

建议特性：

- 修炼效率：1.00
- 木属性
- 伤势恢复小幅提升
- 筑基稳定性略高

### 《玄水诀》

定位：另一条路线。

建议特性：

- 修炼效率：0.95
- 水属性
- 灵力容量略高
- 对特定秘境事件有额外选项

其他《基础御物术》《基础阵解》属于能力/术法，不作为主修修为来源。

# 8. 功法理解度

## 8.1 为什么单独存在

同样拥有《青木诀》的两个角色，不应完全等价。

功法理解度代表：

> 玩家对功法运行、缺陷、瓶颈和变化的理解。

取值：0–100。

## 8.2 理解度影响

- 修炼效率小幅提升。
- 突破稳定性提升。
- 解锁功法相关事件选项。
- 达到阈值后可发现功法缺陷或变式。

V0.1 建议不要让理解度倍率过大：

```text
理解修正 = 0.90 + 理解度 × 0.002
```

理解 0：0.90  
理解 50：1.00  
理解 100：1.10

真正重要的价值应来自**选项解锁**，而不是纯数字膨胀。

## 8.3 理解度增长来源

- 持续修炼功法
- 师长讲解
- 藏经阁研究
- 突破成功/失败
- 特殊事件
- 前世悟道

# 9. 小境界突破

## 9.1 小境界不建议全部做概率按钮

炼气阶段的小境界主要用于节奏和成长反馈。

基础条件：

```text
修为达到当前上限
+
身体状态允许
```

达到条件后进入“小突破”。

## 9.2 小瓶颈

部分层级设置轻量瓶颈，例如炼气三→四、五→六、七→八。

瓶颈通过以下方式降低：

- 功法理解
- 师长指导
- 丹药
- 历练事件
- 前世突破经验

失败一般不会死亡，只消耗时间并可能产生轻伤/修为波动。

目的不是惩罚，而是避免成长变成纯进度条。

# 10. 筑基系统

筑基是 V0.1 的终局级决策，必须明显区别于小突破。

## 10.1 筑基前置

至少要求：

- 炼气九层圆满
- 身体无重伤
- 根基状态不为严重受损
- 完成一个合法筑基方案

不能只看“成功率”。

## 10.2 筑基方案模型

一个筑基方案由以下组成：

```text
FoundationPlan
├── 核心方法
├── 必要物品
├── 环境要求
├── 属性适配
├── 稳定性
├── 潜在道基特性
└── 失败后果
```

## 10.3 V0.1 两条路线

### A. 宗门正统筑基

要求示例：

- 宗门贡献达到门槛
- 获得筑基丹
- 使用宗门灵脉洞府

特点：

- 稳定
- 风险较低
- 道基普通但无明显缺陷
- 需要时间和宗门资源

### B. 黑水古修筑基

要求示例：

- 完成黑水秘境深层事件链
- 获得古修残卷/传承核心
- 满足对应属性或悟性要求

特点：

- 风险更高
- 对前世情报依赖明显
- 可得到特殊道基特性
- 是 V0.1 核心 Roguelite 奖励

# 11. 突破判定

## 11.1 判定由“准备度”而非单一成功率驱动

系统内部仍可最终落到概率，但玩家界面应展示主要因素。

建议内部计算：

```text
突破准备度 =
基础值
+ 修为圆满修正
+ 功法理解修正
+ 方案稳定性
+ 环境修正
+ 资源修正
+ 前世悟道修正
- 伤势惩罚
- 根基惩罚
- 方案不适配惩罚
```

再映射为结果区间。

## 11.2 结果不是二元

筑基至少支持：

1. 完美筑基
2. 正常筑基
3. 勉强筑基
4. 失败但保命
5. 根基受损
6. 经脉重伤
7. 走火入魔
8. 死亡
9. 特殊异变（仅内容事件显式开启）

## 11.3 玩家必须知道失败原因

结算示例：

```text
筑基失败

主要原因：
- 古修方法与你的水灵根适配不足
- 功法理解不足
- 经脉旧伤未愈

本世获得：
- KNOWLEDGE_FOUNDATION_MERIDIAN_RISK
- 筑基失败悟道 +18
```

失败应成为下一世决策信息。

# 12. 道基

筑基成功后生成一个 `Foundation` 状态。

V0.1 只需区分：

### 普通道基

- 无额外特性。
- 稳定。

### 黑水古修道基

- 根据传承定义固定或半固定特性。
- V0.1 不允许 AI 任意生成规则。

示例：

```text
玄水道基
灵力上限 +10%
水系功法理解获取 +10%
火系功法修炼效率 -5%
```

好处应伴随代价，避免纯上位替代。

# 13. 寿元系统

## 13.1 核心原则

寿元是角色最重要的长期压力之一。

V0.1 主角：

```text
初始年龄：16
凡人/炼气寿元上限：90
```

筑基后建议：

```text
寿元上限：180
```

具体数值后续平衡。

## 13.2 年龄推进

每次时间系统推进后，使用游戏日期计算年龄，而不是单独累加年龄字段。

## 13.3 临近寿元上限

不建议直接在 89 岁仍满状态、90 岁瞬间死亡。

可以设置“衰老阶段”：

```text
剩余寿元 > 20%：正常
剩余寿元 10%–20%：轻微衰老
剩余寿元 < 10%：明显衰老
达到上限：寿尽
```

V0.1 如游戏周期较短，可以只实现寿尽检查，衰老修正后置。

# 14. 伤势与异常状态

## 14.1 V0.1 状态类型

控制复杂度，只实现：

- 健康
- 轻伤
- 重伤
- 经脉受损
- 中毒
- 根基受损

## 14.2 状态必须有玩法意义

例如：

### 轻伤

- 可自然恢复。
- 修炼效率轻微下降。

### 重伤

- 禁止突破。
- 修炼效率大幅下降。
- 需要疗伤或较长时间恢复。

### 经脉受损

- 修炼效率下降。
- 突破风险提高。
- 可成为一世长期后果。

### 中毒

- 根据毒素定义持续时间/伤害。
- 黑水秘境下毒事件的核心状态。

### 根基受损

- 极重长期状态。
- 影响突破。
- 某些一世可能因此“走废”，迫使玩家考虑结束推演。

# 15. 丹药与修炼资源

V0.1 丹药只做明确功能，不做完整炼丹系统。

建议：

| 物品 | 功能 |
|---|---|
| 聚气丹 | 提高一定时间修炼收益 |
| 疗伤丹 | 加速/直接处理轻中伤势 |
| 解毒丹 | 处理指定毒素或提高抗毒判定 |
| 筑基丹 | 宗门正统筑基核心资源 |

所有物品效果由内容配置决定。

不做：丹毒、药性相克、炼丹火候等复杂系统。

# 16. 修炼与时间的节奏

角色成长必须让玩家经常面对：

```text
现在闭关半年？
还是三个月后的秘境先去？
```

因此修炼系统与事件时间轴直接绑定。

示例：

```text
当前：132年3月

已知：
132年6月 宗门小比
133年4月 黑水秘境开启

选择：
A. 闭关 90 天冲炼气四层
B. 做任务换聚气丹
C. 去坊市准备解毒丹
```

单纯“哪个收益更高”不是唯一答案；未来知识会改变时间分配。

# 17. 跨世悟道

## 17.1 定义

`Insight` 是从推演经历中抽取、可以跨世保留的“理解”，区别于具体情报 `Knowledge`。

Knowledge：

> 赵长青会在洞府中下毒。

Insight：

> 你已经经历过炼气九层突破失败，对该瓶颈更加熟悉。

## 17.2 V0.1 悟道类别

只需：

- 指定功法理解
- 指定境界突破经验
- 指定能力理解（如基础阵解）

暂不做开放式“道途生成”。

## 17.3 保留原则

推演结束后不直接保留全部理解度。

建议：

```text
可提取悟道 = 本世新增理解 × 提取系数
```

提取系数由：

- 悟性
- 是否经历关键事件
- 是否主动在结算选择该项
- 天衍资源

共同决定。

V0.1 可以简化成固定 30%–50%。

## 17.4 上限

跨世悟道不能把一部功法直接推到满级。

可设置：

```text
Meta 功法理解上限 = 60
```

后续更高层次必须在现实/新锚点中继续真正修炼。

# 18. 推演中死亡与修炼的关系

以下死亡原因必须可由修炼系统产生：

- 寿元耗尽
- 突破失败死亡
- 走火入魔
- 重伤未治
- 中毒

死亡时输出明确结构：

```text
DeathResult
├── cause
├── source
├── timestamp
├── avoidableFactors[]
├── discoveredKnowledge[]
└── insightCandidates[]
```

这样诸世结算才能给出“下一世可以怎么改变”的信息。

# 19. 数值透明度

游戏不应完全隐藏概率，也不应把所有公式直接暴露。

建议展示：

### 修炼

```text
预计修炼效率：较高
原因：
+ 青木诀与木灵根适配良好

```

# 21. 规则不变量

开发时必须保持：

1. `currentCultivation <= currentRealm.cap`，超过部分必须由突破流程处理。
2. 境界变化只能由 `Breakthrough` 流程完成，事件不得直接随意改境界。
3. 死亡角色不能继续执行行动。
4. 重伤/严重经脉状态不能执行明确禁止的突破。
5. 推演结束后，Run 中的境界、修为、物品不得直接写入 Meta。
6. Meta 只能获得明确允许的 Knowledge、Insight、记录和天衍资源。
7. AI 文案不得修改任何上述状态。

# 22. V0.1 验收

角色与修炼系统完成至少满足：

- [ ] 主角可从炼气三层通过时间修炼至炼气九层。
- [ ] 地点、灵根、功法理解会真实影响修炼效率。
- [ ] 修炼和闭关会推进游戏日期。
- [ ] 伤势会影响修炼或突破。
- [ ] 至少存在 3 个小境界瓶颈。
- [ ] 可通过宗门正统路线筑基。
- [ ] 可通过黑水秘境路线筑基。
- [ ] 筑基支持多种结果，不是只有成功/失败。
- [ ] 筑基失败可产生可继承的突破 Insight。
- [ ] 推演死亡后不会保留境界和物品。
- [ ] 前世功法/突破悟道能让下一世相同成长阶段产生明显优势。
