# 诸世问道：旧移动端 V0.1 UI 原型

> 状态：历史方案，已废弃
>
> 当前产品已调整为 **Steam / Windows 优先的东方修仙像素人生模拟 Roguelite RPG**。本文件原本定义的移动端竖屏页面结构、底部导航、卡片式主界面和 H5 交互不再作为实现依据。

## 仍可复用的交互原则

以下内容继续保留，并应重新设计到桌面像素 RPG 中：

- Knowledge 解锁的选项必须有清晰视觉辨识。
- 死亡后需要连续完成“一世总结 → Anchor → 承世 / 悟世 → 下一世”。
- 主动坐化属于低频特殊行为，不应成为高频主操作。
- 承世与悟世必须在语义和视觉上明显不同。
- Anchor / Knowledge / 死亡结算需要有强烈的修仙轮回仪式感。
- 长文本仍需保证可读性。

## 已废弃的布局规则

- 移动端竖屏作为第一设计目标。
- 一只手完成大多数主要操作。
- 底部 5 项导航。
- 以“推演主界面 + 卡片行动入口”作为主要游戏空间。
- 通过页面跳转代替角色在地图中的实际移动与交互。

## 新 UI 方向

新的 V0.1 UI 应围绕：

```text
像素地图 / 场景
+
角色 HUD
+
交互提示
+
事件选择界面
+
角色 / 背包 / 功法 / Knowledge / 词条界面
+
死亡与轮回结算
```

重新设计。

具体桌面 UI / HUD 文档将在游戏引擎最终确定后补充。

原完整移动端原型仍可通过 Git 历史查看。
