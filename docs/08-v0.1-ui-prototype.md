# V0.1 原型界面设计

> 状态：当前有效基线
>
> 本文档只定义 V0.1 可玩原型的页面结构、核心交互和信息层级，不追求最终美术表现。目标是让前端可以直接按页面流程实现可玩闭环。

## 1. 原型目标

V0.1 只验证以下交互是否顺畅：

```text
进入一世
→ 进行修炼 / 探索 / 事件选择
→ 获取 Knowledge / 物品 / 经历
→ 死亡
→ 查看一世评价
→ 选择下一世 Anchor
→ 承世 或 悟世
→ 配置词条
→ 回溯
→ 使用前世信息改变下一世
```

原型不承担正式商城、登录、社交、复杂地图和完整多端适配。

## 2. 视觉方向

整体采用东方修仙文本 RPG 风格：

- 深色墨色 / 宣纸灰为主要背景。
- 信息卡片模拟卷轴、册页、竹简或宗门案牍感，但不过度拟物。
- 金色只用于重要命运信息、Anchor、稀有成果和关键按钮。
- 危险 / 死亡使用暗红色语义。
- Knowledge 使用明显的“前世记忆”标识，例如星标 `★`。
- UI 以文字可读性为第一优先，避免大量装饰挤占事件文本空间。

V0.1 以移动端竖屏为主进行设计，同时保持 Web/H5 可响应式扩展。

## 3. 页面地图

V0.1 需要 8 个核心页面 / 状态：

1. 推演主界面
2. 事件决策界面
3. 角色与词条界面
4. Knowledge / 前世记忆界面
5. 一世死亡总结界面
6. Anchor 选择界面
7. 承世 / 悟世结算界面
8. 回溯次数耗尽界面

其中 5～7 可以设计为连续的“死亡结算流程”，不一定必须拆成独立路由。

---

## 4. 推演主界面

### 4.1 信息布局

```text
┌──────────────────────────────┐
│ 第 3 世   青玄历 137年3月     │
│ 炼气三层  修为 63%   回溯 8/10 │
├──────────────────────────────┤
│ 当前地点：青玄宗 · 外门       │
│                              │
│ 近期状态                     │
│ [轻伤] [灵石不足] [黑水传闻]  │
├──────────────────────────────┤
│                              │
│        当前人生叙事区         │
│                              │
│  你结束了七日吐纳……           │
│  山门外近来有弟子谈起黑水山。 │
│                              │
├──────────────────────────────┤
│ [修炼] [外出] [休整] [人物]   │
│ [查看记忆]        [主动坐化]   │
└──────────────────────────────┘
```

### 4.2 核心要求

顶部始终可见：

- 当前第几世。
- 游戏内日期 / 年龄。
- 当前境界与修为。
- 剩余基础回溯次数。
- 当前地点。

主内容区展示最近发生的重要事件与结果，不做传统聊天气泡。

底部只保留少量高频行动；行动进入更具体的二级选择，例如：

```text
修炼
├─ 吐纳 3 日
├─ 闭关 30 日
└─ 研习当前功法
```

每个长期行动必须明确显示会推进多少游戏时间。

## 5. 事件决策界面

```text
┌──────────────────────────────┐
│ 【黑水山 · 林间异响】         │
│ 危险：未知                    │
├──────────────────────────────┤
│ 林间传来短促的金铁交鸣声。    │
│ 你隐约闻到一股淡淡腥甜。      │
│                              │
│ ★ 前世记忆                    │
│ 上一世你在此继续前进，随后     │
│ 中毒身亡。                    │
├──────────────────────────────┤
│ [继续靠近]                    │
│ [绕路观察]                    │
│ ★ [提前服下解毒丹]            │
│                              │
│ [离开]                        │
└──────────────────────────────┘
```

### 5.1 选择类型

- 普通选择：所有满足基础条件的玩家可见。
- 条件选择：功法、属性、物品、NPC 关系等满足时出现。
- `★ 前世记忆`：由 Knowledge 解锁，是本游戏最重要的视觉标识之一。
- 词条选择：由已装备词条解锁，显示词条来源。

示例：

```text
【丹心】你察觉这并非普通瘴气。
[辨认毒性]
```

### 5.2 结果展示

结果不要只显示数值：

```text
你没有贸然进入林间。

获得 Knowledge：
「黑水山外围存在人为布置的毒障」

时间 +2 日
```

重大结果允许使用整屏短暂结果卡强化反馈。

---

## 6. 角色 / 词条界面

使用顶部 Tab：

```text
[角色] [功法] [装备] [物品] [词条]
```

### 6.1 角色

展示：

- 境界 / 小境界。
- 修为进度。
- 寿元 / 年龄。
- 伤势与特殊状态。
- 当前地点与身份。

### 6.2 词条

```text
本世已装备 3 / 5

[丹心·通明]      已装备
炼丹事件出现额外判断信息……

[趋吉避凶]        已装备
部分危险事件提前出现风险提示……

[剑感]            未装备
剑道事件获得额外观察选项……
```

词条库可超过 5 个，但一世最多装备 5 个。

正常人生中不可随时切换已装备词条；下一世开始前重新配置。

---

## 7. Knowledge / 前世记忆界面

按类型分组：

```text
[全部] [人物] [地点] [事件] [资源] [危险]
```

每条 Knowledge 显示当前适用状态：

```text
★ 黑水山毒障
状态：仍可信

上一世发现黑水山外围存在人为毒障。
```

或：

```text
★ 赵长青将在三月前往黑水山
状态：可能变化

原因：当前世界线中赵长青已提前离开宗门。
```

Knowledge 是“记忆库”，不应该像任务列表一样强制引导玩家执行。

## 8. 死亡与一世总结

死亡后不立即回 Anchor，而是进入完整结算。

```text
┌──────────────────────────────┐
│          第 三 世 终          │
│                              │
│ 享年：23 岁                  │
│ 境界：炼气三层                │
│ 死因：黑水山毒发              │
├──────────────────────────────┤
│ 【一世评语】                  │
│                              │
│ 你因前世之鉴避过旧路，却仍     │
│ 未能看清黑水山真正的杀机……    │
├──────────────────────────────┤
│ 本世重要经历                  │
│ · 发现黑水山外围毒障           │
│ · 获得《基础解毒篇》           │
│ · 与赵长青关系恶化             │
│ · 首次进入黑水洞外围           │
├──────────────────────────────┤
│          [进入结算]           │
└──────────────────────────────┘
```

一世评价由规则系统提供事实摘要；正式版本可以由 AI 润色，但 V0.1 使用模板即可。

## 9. Anchor 选择

死亡总结后先选下一世 Anchor。

V0.1 只有初始炼气 Anchor，但界面必须按照未来多 Anchor 结构设计。

```text
选择下一世起点

● 炼气 Anchor
  16岁 · 炼气三层
  青玄宗外门
  已建立

○ 筑基 Anchor
  尚未建立

○ 金丹 Anchor
  尚未建立

[确认此 Anchor]
```

正式版已建立 Anchor 卡片需要预览：

- 建立年龄 / 日期。
- 境界。
- 核心功法。
- 代表性装备。
- 关键身份。

Anchor 不提供“编辑”“覆盖”“删除”按钮。

## 10. 承世 / 悟世界面

选完 Anchor 后进入二选一。

```text
┌──────────────┬──────────────┐
│    承 世      │    悟 世      │
│ 带回一项成果  │ 凝结一项词条   │
└──────────────┴──────────────┘
```

### 10.1 承世

只显示死亡时仍合法持有 / 掌握的候选：

```text
请选择一项承世：

○ 《基础解毒篇》
  功法 · 可在炼气期使用

○ 解毒丹 ×2
  消耗品 · 本次最多承世 2 枚

○ 青纹短剑
  装备
```

明确提示：

> 承世成果只会进入紧接着的下一世，并非永久 Meta 资产。

### 10.2 悟世

```text
本世经历可凝结：

○ 【识毒】
  形成原因：多次接触毒物并成功辨识毒性

○ 【慎行】
  形成原因：多次在危险事件前选择观察

无第三项候选
```

最多 3 个候选；没有达到任何形成条件时显示：

> 此世未留下足以凝成词条的轨迹。

此时玩家可以返回选择承世，但不能凭空获得词条。

词条升级也显示在悟世候选中，例如：

```text
【识毒】 → 【百毒辨微】
```

选择升级后旧词条被替换。

## 11. 下一世词条配置

结算完成后、真正进入下一世前：

```text
选择本世生效词条 3 / 5

☑ 识毒
☑ 趋吉避凶
☑ 丹心
☐ 剑感
☐ 老谋深算

[开启下一世]
```

该页面同时展示：

```text
下一世起点：炼气 Anchor
承世成果：《基础解毒篇》
剩余回溯：7 / 10
```

让玩家在进入下一世前清楚知道自己的 Build。

---

## 12. 回溯次数耗尽

当前人生在 `0` 次回溯时仍继续进行，直到死亡。

死亡后：

```text
本世界已经没有自然回溯机会。

基础回溯：0
付费回溯额度：0

[补充回溯额度]
[结束此世界，开始新游戏]
```

V0.1 不接真实支付：

```text
[DEV：增加 1 次额外回溯]
```

正式版本中基础次数始终优先消耗，基础次数为 0 后才使用账号付费额度。

---

## 13. 主动坐化

推演主界面提供低强调度入口：

```text
更多
└─ 主动坐化
```

点击后二次确认：

> 主动坐化会立即结束本世。它属于正式死亡，如果继续回溯将消耗 1 次回溯机会；已提交和已经结算的事件不会撤销。

按钮：

```text
[取消]
[确认坐化]
```

主动坐化后正常进入“一世总结 → Anchor → 承世 / 悟世”流程。

## 14. V0.1 页面流

```text
启动
 ↓
推演主界面
 ├─ 角色 / 物品 / 词条
 ├─ Knowledge
 └─ 行动
      ↓
    事件页
      ↓
    结果
      ↓
    推演主界面
      ↓
    死亡 / 主动坐化
      ↓
    一世总结
      ↓
    Anchor 选择
      ↓
    承世 / 悟世
      ↓
    词条配置
      ↓
    下一世
```

## 15. V0.1 原型验收

界面原型满足以下条件即可进入前端实现：

- 玩家始终能看懂自己处于第几世、什么境界、剩余多少回溯。
- `★ 前世记忆` 选项能一眼区别于普通选择。
- 死亡不是简单 Game Over，而是明显进入核心结算流程。
- Anchor 选择发生在承世 / 悟世之前。
- 承世与悟世互斥，玩家能理解两者差异。
- 词条库与最多 5 个装备槽的关系清楚。
- Knowledge 与词条视觉和概念不混淆。
- 主动坐化不会被误解为免费撤销当前事件。
- V0.1 即使只有一个炼气 Anchor，界面结构也允许未来扩展筑基、金丹等 Anchor。
- 所有关键流程可在移动端单手完成，不依赖自由文本输入。

## 16. 暂不设计

V0.1 原型不包含：

- 登录 / 注册页面。
- 充值商城完整 UI。
- 社交系统。
- 排行榜。
- 多角色账号管理。
- 完整世界地图。
- 筑基及更高境界 Anchor 创建页面。
- 正式 AI 对话界面。
- PC 桌面专用复杂布局。

这些功能只有在核心轮回闭环通过验证后再展开。
