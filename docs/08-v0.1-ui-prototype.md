# V0.1 原型界面设计

> 状态：当前有效基线
>
> 本文档定义 V0.1 可玩原型的页面结构、核心交互和信息层级。具体视觉表现以 `09-ui-visual-style-guide.md` 为准。

## 1. 原型目标

V0.1 只验证以下交互是否顺畅：

```text
进入一世
→ 修炼 / 探索 / 事件选择
→ 获取 Knowledge / 物品 / 经历
→ 死亡
→ 查看一世评价
→ 选择下一世 Anchor
→ 承世 或 悟世
→ 配置词条
→ 回溯
→ 使用前世信息改变下一世
```

原型不承担正式商城、登录、社交、复杂地图和完整多端适配。

V0.1 以**移动端竖屏**为第一设计目标。

---

## 2. 视觉基线

页面信息架构必须服从移动端，但视觉语言不得改成现代深色 Dashboard / App 风。

当前已确认视觉方向：

```text
墨青夜色
+ 暗金古纹
+ 山水 / 宗门 / 秘境插画
+ 命书 / 道卷感面板
+ 精致卡牌式操作
+ 修仙轮回仪式感
```

详细规范统一参见：

`09-ui-visual-style-guide.md`

核心原则：

> **移动端适配只改变布局，不改变首版高保真原型已经确认的美术语言。**

---

## 3. 页面地图

V0.1 需要以下核心页面 / 状态：

1. 推演主界面。
2. 事件决策界面。
3. 角色 / 功法 / 装备 / 物品 / 词条界面。
4. Knowledge / 前世记忆界面。
5. 一世死亡总结界面。
6. Anchor 选择界面。
7. 承世 / 悟世结算界面。
8. 下一世词条配置界面。
9. 回溯次数耗尽界面。
10. 更多 / 特殊行动界面。

其中 5～8 可以设计成连续的“死亡结算流程”，不要求拆成独立路由。

---

## 4. 推演主界面

推演主界面是玩家停留时间最长的页面，应同时承担：

- 当前人物状态。
- 当前地点与人生阶段。
- 最近发生的重要事情。
- 前世 Knowledge 提示。
- 高频行动入口。

### 4.1 推荐移动端结构

```text
┌──────────────────────────────┐
│ 炼气三层  16岁  青玄宗外门    │
│ 回溯 8/10                    │
├──────────────────────────────┤
│ 灵石 1260  气血 1260/1260    │
│ 灵力 680/680  初春·第12日     │
├──────────────────────────────┤
│                              │
│       当前场景山水插画         │
│                              │
│ 【当前人生】                  │
│ 你是青玄宗外门弟子……          │
│ 宗门近日戒备黑水山。           │
│                              │
│ 【前世记忆】 2/6              │
│ · 黑水山有异动                │
│ · 赵长青需提防                │
├──────────────────────────────┤
│ [修炼] [外出历练]             │
│ [拜访人物] [查看黑水线索]      │
├──────────────────────────────┤
│ 推演  角色  记忆  锚点  更多   │
└──────────────────────────────┘
```

### 4.2 顶部必须可见

- 当前境界。
- 年龄。
- 当前身份 / 地点。
- 剩余回溯次数。
- 核心资源状态。
- 游戏内日期 / 时辰。

不要求把所有角色属性都塞进主屏。

### 4.3 当前人生区

主内容区应使用地点插画 + 文本，而不是传统聊天气泡。

重点展示：

- 当前处境。
- 近期重要变化。
- 可行动的线索。
- 已获得的关键 Knowledge。

### 4.4 高频行动

主屏只保留高频行为：

- 修炼。
- 外出历练。
- 拜访人物。
- 探索 / 查看当前线索。

每个长期行动必须明确会推进多少游戏内时间。

例如：

```text
修炼
├─ 吐纳 3 日
├─ 闭关 30 日
└─ 研习当前功法
```

### 4.5 主动坐化不得放在主屏

主动坐化属于低频特殊行为，**不得作为主界面常驻按钮或大型行动卡片**。

统一入口：

```text
更多
└─ 特殊行动
   └─ 主动坐化
```

## 5. 事件决策界面

### 5.1 页面结构

```text
┌──────────────────────────────┐
│          黑水山异动           │
│ 初春 · 第12日 · 午时          │
├──────────────────────────────┤
│                              │
│          事件插画             │
│                              │
├──────────────────────────────┤
│ 你循着线索来到黑水山外围……    │
│ 山间灵气紊乱，隐有异象波动。   │
│                              │
│ 【前世记忆提示】               │
│ 上一世曾在此遭遇危险。         │
├──────────────────────────────┤
│ [沿主路深入]                  │
│ [走左侧岔路]                  │
│ [先回宗门求证]                │
│ [布置后手再行动]              │
└──────────────────────────────┘
```

### 5.2 选择类型

- 普通选择：满足基础条件即可出现。
- 条件选择：由功法、属性、物品、NPC 关系等解锁。
- Knowledge 选择：由前世记忆解锁，使用青玉 / 冷青标识。
- 词条选择：由已装备词条解锁，显示词条来源。
- 高风险选择：可以使用暗红提示，但不能直接告诉玩家完整结果。

示例：

```text
【丹心】你察觉这并非普通瘴气。
[辨认毒性]
```

### 5.3 结果展示

结果不能只显示数字。

推荐：

```text
你没有贸然进入林间。

获得 Knowledge：
「黑水山外围存在人为布置的毒障」

时间 +2 日
```

重大结果允许使用整屏结果卡强化反馈。

## 6. 角色 / 功法 / 装备 / 物品 / 词条

采用统一角色详情页，顶部 Tab：

```text
[角色] [功法] [装备] [物品] [词条]
```

### 6.1 角色

展示：

- 境界 / 小境界。
- 修为进度。
- 寿元 / 年龄。
- 气血 / 灵力 / 体力等核心状态。
- 伤势与特殊状态。
- 当前地点与身份。

### 6.2 功法

展示：

- 当前主修功法。
- 已掌握功法。
- 功法层级 / 理解状态。
- 使用条件。
- 可产生的特殊事件能力。

### 6.3 装备与物品

装备与物品需要明确：

- 是否当前持有。
- 是否属于唯一物。
- 使用境界 / 条件。
- 是否可能进入承世候选。

### 6.4 词条

```text
本世已装备 3 / 5

[丹心·通明]      已装备
炼丹事件出现额外判断信息……

[趋吉避凶]        已装备
部分危险事件提前出现风险提示……

[剑感]            未装备
剑道事件获得额外观察选项……
```

词条库可以超过 5 个，但一世最多装备 5 个。

当前一世中不允许随时切换已装备词条；进入下一世前重新配置。

## 7. Knowledge / 前世记忆界面

按类型分组：

```text
[全部] [人物] [地点] [事件] [资源] [危险]
```

每条 Knowledge 显示当前适用状态。

例如：

```text
黑水山毒障
状态：仍可信

上一世发现黑水山外围存在人为毒障。
```

或：

```text
赵长青将在三月前往黑水山
状态：可能变化

原因：当前世界线中赵长青已提前离开宗门。
```

视觉上 Knowledge 应具有“命书 / 前世残页 / 青玉记忆”的识别感。

Knowledge 是记忆库，不是任务列表，不应强迫玩家逐条执行。

## 8. 死亡与一世总结

死亡后不立即回 Anchor，而是进入完整结算。

### 8.1 页面结构

```text
┌──────────────────────────────┐
│          第 七 世 终          │
│                              │
│ 享年：23 岁                  │
│ 境界：炼气三层                │
│ 死因：黑水洞伏杀              │
├──────────────────────────────┤
│ 【一世评价】                  │
│                              │
│ 你谨慎踏入黑水山……            │
│ 最终仍未逃过此地杀机。         │
├──────────────────────────────┤
│ 【人生大事记】                │
│ · 拜入青玄宗                  │
│ · 探查黑水山                  │
│ · 获得残缺丹方                │
│ · 深入黑水秘境                │
│ · 死于伏杀                    │
├──────────────────────────────┤
│ 【本世收获】                  │
│ 功法 / 物品 / Knowledge ……    │
├──────────────────────────────┤
│ 【可悟词条倾向】              │
│ 谨慎 / 识险 / 探秘者          │
├──────────────────────────────┤
│          [进入死亡结算]        │
└──────────────────────────────┘
```

### 8.2 表现原则

一世总结属于高仪式感页面：

- “第 X 世终”应成为主视觉。
- 人生评价优先于纯统计数据。
- 人生大事使用时间线。
- 本世收获使用图鉴卡片。
- 死亡统计仅作为辅助信息。

V0.1 的一世评价使用模板即可；正式版本可由 AI 在规则事实基础上润色。

## 9. Anchor 选择

死亡总结后，**先选择下一世 Anchor**。

V0.1 只有初始炼气 Anchor，但界面按正式多 Anchor 结构设计。

```text
选择下一世起点

● 炼气 Anchor
  16岁 · 炼气三层
  青玄宗外门
  已建立

○ 筑基 Anchor
  尚未建立

○ 金丹 Anchor
  尚未建立

[确认此 Anchor]
```

正式版已建立 Anchor 需要预览：

- 建立年龄 / 日期。
- 境界。
- 核心功法。
- 代表性装备。
- 关键身份。

Anchor 应采用命轮 / 法阵 / 道印等视觉表达。

Anchor 不提供编辑、覆盖或删除按钮。

## 10. 承世 / 悟世界面

选择 Anchor 后进入承世 / 悟世二选一。

```text
┌──────────────┬──────────────┐
│    承 世      │    悟 世      │
│ 带回一项成果  │ 凝结一项词条   │
└──────────────┴──────────────┘
```

### 10.1 承世

只显示死亡时仍合法持有 / 掌握的候选：

```text
请选择一项承世：

○ 《基础解毒篇》
  功法 · 可在炼气期使用

○ 解毒丹 ×2
  消耗品 · 本次最多承世 2 枚

○ 青纹短剑
  装备
```

明确提示：

> 承世成果只进入紧接着的下一世，并非永久 Meta 资产。

承世视觉以暖金 / 古铜 / 功法卷轴 / 法宝实体为主。

### 10.2 悟世

```text
本世经历可凝结：

○ 【识毒】
  形成原因：多次接触毒物并成功辨识毒性

○ 【慎行】
  形成原因：多次在危险事件前选择观察

无第三项候选
```

最多 3 个候选。

没有达到任何形成条件时显示：

> 此世未留下足以凝成词条的轨迹。

此时玩家可返回选择承世，但不能凭空获得词条。

词条升级也显示在悟世候选中，例如：

```text
【识毒】 → 【百毒辨微】
```

选择升级后，旧词条被替换。

悟世视觉以命格纹章 / 道纹 / 青绿、幽蓝、紫青低饱和色为主。

## 11. 下一世词条配置

结算完成后、真正进入下一世前配置：

```text
选择本世生效词条 3 / 5

☑ 识毒
☑ 趋吉避凶
☑ 丹心
☐ 剑感
☐ 老谋深算

[开启下一世]
```

同时展示：

```text
下一世起点：炼气 Anchor
承世成果：《基础解毒篇》
剩余回溯：7 / 10
```

让玩家在进入下一世前清楚知道自己的 Build。

## 12. 回溯次数耗尽

当前人生在 `0` 次回溯时仍继续，直到死亡。

死亡后：

```text
本世界已经没有自然回溯机会。

基础回溯：0
付费回溯额度：0

[补充回溯额度]
[结束此世界，开始新游戏]
```

V0.1 不接真实支付：

```text
[DEV：增加 1 次额外回溯]
```

正式版本中基础次数优先消耗；基础次数为 0 后才使用账号付费额度。

## 13. 更多 / 特殊行动

低频功能不占据推演主屏。

推荐：

```text
更多
├─ 诸世录
├─ 设置
├─ 帮助
└─ 特殊行动
   └─ 主动坐化
```

### 13.1 主动坐化

点击后必须二次确认：

> 主动坐化会立即结束本世。它属于正式死亡，如果继续回溯将消耗 1 次回溯机会；已提交和已经结算的事件不会撤销。

按钮：

```text
[取消]
[确认坐化]
```

主动坐化不得与修炼、历练、探索等高频行动采用同等级视觉权重。

---

## 14. 底部导航

正式移动端建议控制在 5 项以内：

```text
推演
角色
记忆
锚点
更多
```

`诸世录` 可以从“更多”进入，也可以在后续版本根据使用频率替换某一主导航项。

底部图标统一使用古风线稿：命书、人物、轮回环、Anchor 道印、古卷等，不直接使用通用 Material / iOS 图标。

## 15. V0.1 原型验收标准

V0.1 UI 原型完成至少需要满足：

1. 一只手可以完成绝大多数主要操作。
2. 主屏能在不进入二级页的情况下看懂当前人物、地点、回溯次数和当前人生状态。
3. 主动坐化不出现在主屏高频操作区。
4. Knowledge 解锁的事件选项能被玩家一眼识别。
5. 死亡后能连续完成“一世总结 → Anchor → 承世/悟世 → 词条配置 → 下一世”。
6. 承世与悟世视觉和语义明显不同。
7. 整体视觉保持墨青、暗金、山水、古纹与修仙仪式感，不退化为现代 Dashboard 风格。
8. 页面在典型移动端竖屏宽度下不依赖横向滚动。
9. 长文本场景仍有足够字号、行高和对比度。
10. V0.1 不因高保真视觉要求阻塞核心玩法开发，插画允许先使用占位资源逐步替换。
