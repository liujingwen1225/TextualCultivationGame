# 诸世问道：修炼、事件与节奏系统

> 状态：Steam 像素 RPG 重设计当前有效基线

## 1. 设计目标

修仙成长必须有分量，但不能依靠现实挂机时间、超长经验条或无意义跑图制造时长。

核心原则：

> **有意义的行动推进游戏内时间，时间推动世界变化，世界变化反过来制造新的修炼与人生选择。**

## 2. 游戏内时间模型

桌面像素 RPG 引入真实地图移动后，需要区分“玩家操作时间”和“世界规则时间”。

### 2.1 不采用现实秒 = 游戏秒

玩家站在原地、打开背包、调整设置或绕着房间走，不应该让世界按现实秒数持续推进数日。

否则会出现：

- UI 操作影响世界命运。
- 帧率影响事件。
- 玩家故意挂机刷时间。
- 多世复现失去稳定性。

### 2.2 时间由有意义行为推进

典型时间消耗：

```text
同一建筑内移动 / 对话浏览
→ 通常不单独推进宏观时间

本地调查 / 采集 / 普通交互
→ 按行为结算少量时间

跨区域旅行
→ 小时 / 天

修炼 / 炼丹 / 养伤
→ 天 / 月

闭关
→ 月 / 年
```

具体数值由平衡阶段确定。

### 2.3 地图移动不是事件压力货币

移动步数、键盘输入次数、渲染帧数不能直接增加 Event Pressure。

玩家在青玄宗里多绕三圈，不应该因此更容易触发重大事件。

## 3. 微观时间与宏观时间

为了兼顾地图沉浸和修仙长时间尺度，推荐两层表达：

### 微观时间

用于：

- 当前时辰。
- NPC 是否在某地点。
- 商店是否开放。
- 夜间入口。
- 短途行动。

### 宏观时间

用于：

- 修炼。
- 闭关。
- 宗门阶段变化。
- NPC 长期事件。
- 秘境开启窗口。
- 年龄与寿元。

玩家执行长时间行为时，可以直接跳过宏观时间，但期间仍要进行事件调度。

## 4. 长时间行为

所有长期行为消耗世界时间：

- 修炼。
- 闭关。
- 长途旅行。
- 宗门任务。
- 炼丹 / 炼器。
- 秘境持续探索。
- 养伤。

例如：

```text
闭关 30 天
→ 世界时间 +30 天
→ 获得修为
→ 期间运行事件调度
→ 可能被宗门召集 / 遇到瓶颈 / 触发功法疑难
```

长时间行动不能成为无风险的“跳过世界按钮”。

## 5. 修为、境界与突破

### 5.1 大境界骨架

当前采用传统而易理解的大境界主干：

```text
凡人
→ 胎息
→ 炼气
→ 筑基
→ 紫府
→ 金丹
→ 元婴
→ 更高境界后续设计
```

大境界名称本身不承担主要原创负担；本作差异主要来自突破方式、功法路线、资源争夺、社会地位、风险和多世 Knowledge 对成长路线的改变。

### 5.2 大境界必须产生质变

大境界不是单纯数值倍率。

跨越大境界可以改变：

- 寿元。
- 法力、神识或神魂能力边界。
- 可使用的法术、神通、法宝与环境手段。
- 对危险环境的承受能力。
- 所需修炼资源和灵地层级。
- 宗门 / 家族中的身份与权限。
- 可以接触的人物、秘密与世界事件层级。
- 对低境界修士的压制能力。

玩家突破后，应感到自己进入了一个新的修真社会层，而不仅是“攻击力翻倍”。

### 5.3 境界压制与越境

正常情况下，大境界差距具有明显压制。

```text
低一大境界
VS
高一大境界
→ 正面公平战斗通常显著劣势
```

不鼓励依靠普通 Build 高频越大境杀敌。

但越境不是绝对禁止。以下条件可以共同制造极少数合理机会：

- 对手重伤 / 中毒 / 功法反噬。
- 特定阵法或地形。
- 克制功法 / 法宝。
- 多人围攻。
- 特殊时机。
- 事先布置。
- 前世 Knowledge 揭示的弱点或窗口。

Knowledge 的价值是让玩家找到本来不知道的机会，而不是取消境界差距。

### 5.4 修为与突破资格

修为表示当前境界中的成长积累。

修为达到阈值只代表获得突破资格，不等于自动升级。

突破还可依赖：

- 功法理解。
- 身体与神魂状态。
- 灵根 / 资质。
- 丹药与材料。
- 心境 / 特殊经历。
- 地点 / 环境。
- 正确的突破方法。

### 5.5 突破是高风险核心玩法

重大突破通过明确事件或高层流程结算，可以产生：

- 成功。
- 普通失败。
- 受伤。
- 根基受损。
- 走火入魔。
- 功法异变。
- 特殊感悟。
- 隐藏成长路线。
- **死亡。**

不要把重大突破退化成无上下文“63% 成功率按钮”。

第一次突破失败甚至死亡，可以成为多世 Knowledge 的来源。例如玩家发现公开筑基法缺少关键步骤、某种丹药存在隐患、某个长老故意隐瞒方法，下一世据此调查和准备。

### 5.6 功法决定修炼路线

功法不是简单的数值装备。

不同功法应影响：

- 修炼速度与适合环境。
- 法术 / 神通方向。
- 战斗节奏与资源消耗。
- 身体、法力、神魂特征。
- 丹药 / 材料需求。
- 风险、禁忌与反噬。
- 大境界突破方式。
- 可形成的特殊 Build 与事件路线。

改修、兼修或坚持一门功法属于一世的重要人生决策。

## 6. 节奏指标

不规定：

- 首次筑基必须多少现实小时。
- 每个小境界必须多少分钟。
- 一世必须持续多少现实时间。

重点观察：

- 有效行动数量。
- 关键事件密度。
- 资源问题数量。
- 突破瓶颈数量。
- 重大选择频率。
- 可验证 Knowledge 数量。
- 重复人生机械操作量。

基础目标：

- 通常 2～4 个重大行动后，应出现一次有意义变化。
- 原则上不要连续超过 5 个重大行动完全没有新信息或新决策。
- 熟悉内容应逐步允许快捷处理。

## 7. Event Pressure

Event Pressure 用于判断“当前人生是否应该产生新的世界变化”。

主要输入：

- 经过的游戏内时间。
- 当前地图 / Zone 的事件密度。
- 当前剧情压力。
- 行动风险。
- 当前世界状态。
- 距离上一次重大事件的时间。
- 当前 Life Theme。

禁止把以下内容作为主要输入：

- 点击次数。
- 移动步数。
- 进入菜单次数。
- 请求次数。
- 渲染帧数。

同样 30 天的时间跨度，无论玩家拆成多个小修炼还是一次闭关，基础时间压力应该大体同级，再由行为性质产生差异。

## 8. 事件调度

事件来源：

- 核心事件链。
- NPC 人物事件。
- 宗门事件。
- 地点 / Zone 事件。
- 交互点事件。
- 奇遇。
- 秘境事件。
- 战斗结果。
- 修炼事件。
- 世界危机。

建议优先级：

```text
必须处理的强制事件
↓
关键事件链
↓
高相关 NPC / 地点事件
↓
普通随机事件
↓
低优先级氛围事件
```

需要：

- 冷却。
- 重复衰减。
- 核心剧情保护。
- 长时间无变化保护。

这些机制不直接暴露为玩家可刷的抽卡概率。

## 9. NPC 日程与时间

关键 NPC 不需要逐秒模拟。

使用：

```text
时间段
+
事件状态
+
NPC 当前状态
→ 当前地点 / 是否可交互
```

例如：

```text
上午：丹阁
下午：任务堂
夜晚：洞府
```

重大事件发生后，该日程可以被状态覆盖。

这样既让世界有“人在生活”的感觉，又避免复杂自主 Agent 模拟。

## 10. 锚点命运与一世变数

同一 Anchor 重复推演必须同时满足：

- 前世知识有价值。
- 下一世仍有新鲜感。

### 锚点命运

相对稳定：

- 核心人物身份。
- 重大事件根因。
- 重要传承是否存在。
- 关键时间窗口。
- 世界危机骨架。

### 一世变数

允许变化：

- 普通奇遇。
- 天气。
- 市场供给。
- 非核心 NPC 行动。
- 普通遭遇。
- 部分支线。

Knowledge 主要利用锚点命运；记录一世变数时，其适用性更容易变为“可能变化”。

## 11. 确定性随机

重大结果不能依赖全局顺序 RNG。

禁止：

```text
重大事件原本失败
→ 玩家多走 300 步
→ 随机序列被推进
→ 重大事件成功
```

重大结果应由有意义上下文决定，例如：

```text
AnchorFateSeed
+ EventId
+ DecisionId
+ 玩家关键状态
+ NPC关键状态
+ relevantStateHash
```

普通枝节可以使用：

```text
RunVariationSeed = hash(AnchorFateSeed, runNumber)
```

## 12. 战斗与风险

战斗是核心玩法支柱之一，频率可以达到中高水平，但不采用“刷大量无意义杂兵”作为主要成长方式。

战斗目标：

- 功法、法术、装备、法宝、丹药与 Build 有持续使用空间。
- 普通敌人承担基础战斗、资源和技能实践。
- 精英、修士、秘境敌人与重大敌人强调准备和策略。
- Knowledge 能揭示敌人机制、弱点、时机或准备路线，但不能替代角色成长和实际战斗。
- 逃跑是正式结果。
- 受伤会产生后续内容。

风险不只来自战斗，还包括：

- NPC 欺骗、陷害、伏杀与借刀杀人。
- 中毒。
- 环境。
- 突破失败与走火入魔。
- 社交冲突。
- 时间错失。
- 秘境陷阱与阵法。
- 寿元。
- 世界事件与意外因果。

V0.1 不要求动作连招或大量高成本战斗演出。

## 13. 死亡

死亡是跨世系统的高频入口，而不是少数剧情节点才出现的罕见失败。

核心原则：

> **玩家应该容易死，而且死法要足够多样；死亡本身是修仙世界危险性和多世回溯玩法的重要内容来源。**

典型死亡来源包括但不限于：

- 战斗死亡。
- 越级挑战与围杀。
- NPC 设局、欺骗、伏杀、下毒、借刀杀人。
- 伤势恶化。
- 中毒与诅咒。
- 突破失败。
- 走火入魔。
- 功法反噬。
- 秘境灾害、陷阱与阵法。
- 炼丹 / 炼器等高风险行为事故。
- 天劫与特殊修炼风险。
- 寿元终结。
- 世界危机。
- 主动坐化。

死亡频繁不等于廉价。一次死亡至少应满足以下之一：

- 暴露新的 Knowledge。
- 揭示人物、地点、功法、敌人或世界机制。
- 形成新的因果或人生评价事实。
- 为下一世提供可利用的准备方向。
- 形成承世 / 悟世所需的有效经历。

允许存在“完全没搞明白就死了”的人生，但不能让主要体验退化成不可理解的随机秒杀。危险在第一次遭遇时可以未知；经过死亡、调查或 Knowledge 积累后，应逐渐变得可理解、可准备、可规避或可正面解决。

死亡本身不自动奖励词条。

重复用完全相同方式机械送死，应因为：

- 对应 Knowledge 已经获得。
- 没有新增人生事实。
- 词条代表性不增加。

而自然失去收益。

## 14. 熟悉状态与重复人生

熟悉状态由 Knowledge 与历世经历派生，不是独立 Meta 货币。

可用于：

- 已知安全地点快速旅行。
- 普通事件快捷处理。
- 已知路线摘要。
- 关键交互对象前世标记。
- 缩短重复文本。

原则：

> 第一世付出探索成本，后续人生应该越来越像“利用攻略改变未来”，而不是重复劳动。
