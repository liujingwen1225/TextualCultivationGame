# 修炼与角色成长设计

## 1. 境界骨架

当前大境界：

```text
凡人
→ 胎息
→ 炼气
→ 筑基
→ 紫府
→ 金丹
→ 元婴
→ 更高境界后续设计
```

不同大境界允许采用不同内部结构：

```text
胎息 → 感气 / 纳气 / 周天
炼气 → 一至九层
筑基 → 初 / 中 / 后
紫府 → 围绕紫府、神魂与法力结构完善
```

不要求全游戏统一九层制。

## 2. 大境界必须产生质变

跨越大境界应改变：

- 寿元。
- 法力与神识边界。
- 肉身与环境适应能力。
- 可用术法、法宝和神通层级。
- 资源需求。
- 突破方式。
- 社会身份和可接触内容。
- 对低境界修士的威慑。

不采用“筑基 = 炼气属性乘 2”的设计。

## 3. 一级资质

不使用传统力量、敏捷、智力、幸运等六维模板。

核心一级资质控制在少量有明确修仙意义的维度：

- 根骨：肉身、气血、经脉承载、伤势恢复与部分突破基础。
- 悟性：功法理解、术法参悟、突破理解与学习效率。
- 神魂：精神强度、神识基础、神魂相关能力。
- 灵根：天地灵气适性和修炼路线。
- 寿元：生命期限，作为特殊战略资源。

资质相对稳定，但允许通过重大机缘、传承、天材地宝、功法或代价产生结构性变化。

## 4. 灵根与体质分离

灵根回答“更适合怎样吸收和运转灵气”。

体质回答“身体本身具有什么特殊规则”。

两者可以协同，也可以冲突。特殊体质不应人人拥有，也不使用单纯 SSR 稀有度逻辑。

## 5. 核心运行资源

### 气血

肉身生命、行动与部分体修/秘术基础。

### 法力

术法、护体、法宝等主要能量来源。

### 神识

感知、锁定、探查、神魂能力与部分高阶法术基础。

三者由境界、功法、资质、状态和装备派生，不作为自由加点的一级属性。

## 6. 寿元

寿元是真实长期资源：

- 自然消耗。
- 突破提升上限。
- 重伤、诅咒、秘术可能折寿。
- 延寿丹药和天材地宝可以延寿。
- 部分功法或魔道手段可用寿元换取短期力量。

“活下来”也可能只是把代价转化为未来寿元压力。

## 7. 功法 / 术法 / 神通

### 功法

长期修炼框架，决定：

- 法力性质。
- 修炼速度与稳定性。
- 资源与环境需求。
- 身体 / 神魂变化。
- 兼容术法。
- 突破路线。
- 隐患、禁忌与反噬。

角色在一个阶段只有一个明确主修功法，可有限兼修敛息、锻体、养魂等辅助法门。

改换主修功法属于重大人生选择。

### 术法

角色使用力量的具体方法：攻击、防御、身法、侦察、控制、治疗、逃遁等。

术法掌握可分：

```text
初学 → 熟练 → 精通 → 化境
```

成长来自使用、学习、师承、实战、感悟和研究，不做“重复施法 1000 次自动升级”。

掌握度应改变规则和使用方式，而不只增加伤害。

### 神通

高阶、稀有、规则型能力。来源可以是大境界质变、深度功法掌握、特殊体质、血脉、传承或重大感悟。

低阶修士可以掌握很多术法，但通常没有真正神通。

## 8. 突破

突破是完整玩法，而不是进度条满后点按钮。

输入可以包括：

```text
修为
+ 主修功法
+ 根基
+ 肉身 / 神魂状态
+ 突破资源
+ 环境
+ 方法
+ 已掌握情报
```

结果可以是：

- 成功。
- 失败。
- 受伤。
- 根基损伤。
- 功法异变。
- 走火入魔。
- 死亡。
- 特殊突破。

不直接向玩家展示类似“成功率 67.43%”的绝对答案；更适合使用“准备不足 / 尚可 / 充分”等判断，并通过更高情报和专业能力提升信息精度。

## 9. 伤势

采用“基础生存资源 + 结构化伤势”：

```text
普通伤势
重伤
经脉损伤
根基损伤
神魂损伤
中毒
特殊伤势
永久残缺（极少）
```

战斗胜利不代表恢复。疗伤可能消耗天、月甚至更久，并导致错过事件、资源或机会。

一次惨胜可以改变整段人生路线。

## 10. 道艺与副业

炼丹、炼器、制符、阵法、灵植、御兽等可以存在，但不默认都做复杂生产小游戏。

优先使用：

```text
专业能力
+ 配方 / 知识
+ 资源
+ 时间
+ 关键决策
+ 事件
```

表达。

一个角色通常深度专精 1～2 项，其余需求通过宗门、坊市、NPC 关系和交易解决。

## 11. 境界压制与越境

大境界之间存在明显压制。

低境界正常正面对抗高一大境界应极其困难，但可在特殊条件下创造少数越境机会：

- 对方重伤、中毒、反噬。
- 阵法与地形。
- 克制功法 / 法宝。
- 多人围攻。
- 已知弱点。
- 预先布置。
- 特殊时间窗口。

情报和准备可以创造条件，但不能抹平力量体系。
