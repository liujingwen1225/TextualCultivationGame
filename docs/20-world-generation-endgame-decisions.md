# 诸世问道：新世界与终局已确认决策

> 状态：Matt `grill-with-docs` 进行中的阶段性决策记录。
>
> 用途：记录第 12 轮关于新 World 生成、出身模板、隐藏真相、世界大势、通关与跨 World Meta 的已确认方向。

## 1. 新 World 生成方式

正式版采用“预制内容模块 + World Seed + 兼容规则组合”。

不是运行时 AI 从零临场生成整个世界，也不是每一局完全固定。

World 创建时可以组合：

- 地区与地图模块。
- 宗门 / 家族 / 散修 / 魔门等势力模块。
- 核心与重要 NPC 组。
- 秘境与资源模块。
- 世界事件链。
- 地区级 / 世界级大势。
- 隐藏真相。

World 一旦创建，核心因果、隐藏事实和锚点命运即稳定存在，使同一 World 内的 Knowledge 能够长期发挥作用。

## 2. 出身模板

V0.1 继续使用固定主角沈川，不实现正式出身系统。

正式版允许逐步解锁并选择不同出身，例如：

- 宗门外门弟子。
- 修真家族子弟。
- 散修。
- 魔门杂役 / 弟子。
- 凡人觉醒灵根。
- 特殊传承后人。

出身不是普通属性职业选择，而应真实改变：

- 初始地点。
- 身份与社会关系。
- 家庭 / 师承。
- 初始功法与资源来源。
- 义务、债务与限制。
- 可进入地点。
- 初始敌人 / 盟友。
- 开局事件与可接触的世界层。

## 3. 每个 World 必须有隐藏真相

每个 World 应预设若干玩家初始未知的核心答案。

表面现象和真正原因可以不同，例如同样是“两宗争夺黑水山”，不同 World 的真正原因可以是：

- 地下封印着重要传承。
- 某位高阶修士主动制造战争。
- 灵脉即将发生异变。
- 某家族在秘密操纵双方。

因此创建新 World 时清空 Knowledge 的理由不是角色机械失忆，而是：

> **新世界的答案真的变了。**

## 4. 世界大势

每个 World 至少应存在一条会随着世界时间持续推进的地区级 / 世界级大势，例如：

- 宗门战争。
- 高阶修士坐化。
- 妖潮。
- 魔灾。
- 秘境出世。
- 灵脉衰竭。
- 王朝更替。
- 古修复苏。
- 大宗兼并。
- 天地异变。

世界大势不是传统主线任务。玩家可以不主动参与，但它产生的后果仍会真实影响地图、资源、NPC、势力与玩家人生。

低境界时玩家可能只能被大势裹挟；随着境界、Knowledge、关系与资源增长，玩家可以逐渐干预关键节点，并最终成为地区格局的一部分。

## 5. 世界命题 / 世局

一个 World 不以“杀最终 Boss”或“修到固定境界”作为唯一通关条件。

每个 World 应存在一个核心世界命题 / 世局，即一条需要经过多世才能逐渐认识并有机会改变的主要命运结构。

玩家可能经历：

```text
不知道大势存在
→ 被大势造成的结果杀死或影响
→ 获得 Knowledge
→ 发现大势
→ 理解真正根因
→ 找到关键人物 / 资源 / 时间窗口
→ 开始介入
→ 形成稳定终局
```

稳定终局不要求道德正确，也不只有一种解决方式。

例如宗门百年大劫可以通过：

- 救下宗门。
- 让宗门覆灭。
- 让敌对双方结盟。
- 提前杀掉幕后人物。
- 夺走引发冲突的传承。
- 自己接管势力。
- 促成另一种长期稳定格局。

## 6. 结世资格

完成世界命运闭环后，不强制立刻结束当前人生。

系统授予“结世资格”，玩家可以：

- 立即结世，生成完整世界总结并进入下一 World。
- 继续当前人生，继续修炼、探索和处理人物关系，之后再主动结世。

这样特别成功的人生不会因为完成世界命题而被系统突然中断。

## 7. 世界终结与完成度

回溯耗尽后当前人生仍可继续；在 0 次回溯状态下再次死亡，该 World 正式结束。

世界结束不简单显示 GAME OVER / FAILED。

每个 World 都生成完整结局与完成度评价，例如：

- 夭折之世。
- 未竟之世。
- 有所改变。
- 破局。
- 大成。
- 传奇。

评价应考虑：

- 经历的世数。
- 最远境界。
- 解开的世界真相。
- 关键 NPC 命运。
- 对世界大势的影响。
- 是否完成世局。
- 留下的未解决因果。

## 8. 无官方道德正确答案

世界终局不要求“拯救世界”。

玩家可以：

- 救一个宗门。
- 让一个宗门覆灭。
- 加入敌对势力。
- 带走传承后远走。
- 成为魔门高层。
- 自己建立新秩序。

只要行为符合当前世界规则并形成有意义的因果闭环，即可成为有效终局。

## 9. 世界大势不会等待玩家

玩家可以拒绝主动参与世界大势，但大势仍按世界时间推进。

例如玩家持续闭关时，战争仍可能导致：

- 坊市被毁。
- 师父死亡。
- 灵药涨价。
- 宗门征召。
- 地图封锁。
- 敌对势力进入地区。

因此玩家拥有自由选择，但不是生活在一个等待主角触发的静态世界。

## 10. 新 World 的熟悉与陌生

新 World 不应彻底重新制作成另一个游戏。

采用：

> **熟悉规则 + 模块重组 + 核心答案改变。**

玩家可以再次见到熟悉的：

- 势力类型。
- 地图 / 地区模块。
- 功法体系。
- NPC 原型或部分人物。
- 秘境类型。

但核心关系、隐藏真相、事件根因、人物组合、资源归属和大势可以变化。

长期通过扩大内容模块池提高重玩差异，而不是要求每个 World 完全从零生产内容。

## 11. 跨 World Meta Progression

新 World 不继承：

- Knowledge。
- Trait Library。
- Anchor。
- 物品。
- 境界与修为。
- 永久攻击、防御、悟性等数值战力。

允许保留内容型 Meta Progression，例如：

- 世界史 / 命书收藏。
- 已见功法、NPC、死法和世界事件图鉴。
- Steam 成就与挑战记录。
- 新的 World 内容模块。
- 新出身模板。
- 新势力 / 事件 / 传承组合可能性。

这些解锁应尽量来自玩家实际经历与成就，而不是纯 Meta XP 条。

例如：

```text
曾在一个 World 成为魔门高层
→ 解锁“魔门弟子”出身模板

曾发现某上古剑道传承
→ 后续 World 内容池加入相应剑修事件 / 势力 / 出身模块
```

核心原则：

> **跨 World 成长扩大选择空间和内容广度，不通过永久数值堆叠让下一局自然变简单。**
