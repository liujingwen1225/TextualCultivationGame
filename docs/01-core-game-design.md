# 诸世问道：核心游戏设计

> 状态：当前有效基线

## 1. 一句话定位

《诸世问道》是一款以 **东方修仙、有限回溯、多人生锚点、死亡继承、事件驱动成长** 为核心的文字修仙 Roguelite / RPG。

玩家不是世界管理者，而是一名普通修士。游戏的独特体验不是“死了读档”，而是：

> 通过一世人生获得信息与成果，死亡后做一次有代价的继承选择，再从人生关键阶段重新出发。

## 2. 设计支柱

### 2.1 死亡必须产生信息价值

死亡不是简单失败。

一次有价值的一世至少应留下以下一种成果：

- Knowledge：知道了未来什么会发生。
- 承世候选：死亡时仍实际拥有的一项成果。
- 悟世条件：这一世形成的鲜明人生轨迹。
- 路线验证：确认某个事件、人物或资源链的真实规律。

如果玩家什么都没有经历就主动坐化，允许什么都得不到。

### 2.2 回溯有限，但可以付费续命

每个新世界基础拥有 10 次回溯。

```text
初始人生
死亡 → 回溯 1 次
第二世
死亡 → 回溯 1 次
……
```

基础回溯耗尽后，玩家可以使用账号级付费回溯额度继续；不补充则当前世界结束，创建新世界。

因此产品定义是：

> 免费回溯有限，付费续命无限；单次回溯仍然必须通过死亡触发。

## 3. 核心循环

```text
选择已建立 Anchor
  ↓
配置最多 5 个词条
  ↓
开始一世
  ↓
修炼 / 历练 / 社交 / 宗门 / 秘境 / 探索
  ↓
条件事件 + 一世变数 + 重大命运
  ↓
Knowledge / 功法 / 法宝 / 资源 / 人际结果
  ↓
突破 / 受伤 / 失败 / 死亡
  ↓
一世评价
  ↓
选择下一世 Anchor
  ↓
承世一项成果 OR 悟世一个词条
  ↓
消耗 1 次回溯
  ↓
下一世
```

如果角色仍然存活且进入新的大境界，玩家还可以选择“定世”，建立该大境界唯一的 Anchor。

## 4. 一局与一世

### 一世

从一个 Anchor 开始，到角色死亡结束。

### 一局 / 当前世界

从创建新世界开始，持续包含多世人生、多个 Anchor、Knowledge 和词条积累，直到：

- 角色死亡；
- 没有基础回溯；
- 没有或不愿消费付费回溯额度；
- 玩家选择结束当前世界。

此时才是真正 Game Over。

## 5. 长期可玩性来源

长期可玩性不依赖把升级速度故意拖长。

主要来源：

- 同一世界的不同人生路线。
- 多 Anchor 带来的“从哪一段人生重走”策略。
- Knowledge 对未来事件的利用。
- 承世一项成果与悟世一个词条之间的取舍。
- 词条 Build 与升级。
- 条件事件与连锁事件。
- NPC 关系和人物秘密。
- 宗门、秘境、奇遇、世界危机。
- 普通物品跨世套利。
- 唯一物的命运风险。
- 新世界预设模块组合与核心真相变化。

## 6. 玩家决策应该有代价

典型高价值选择：

### 死亡后

```text
承世极品功法
VS
悟出长期词条
```

### 选择 Anchor

```text
回炼气：能彻底重塑前期路线，但要重新成长
回金丹：损失的时间少，但无法修复早期缺陷
```

### 定世

```text
现在把这个大境界状态永久固定
VS
继续等一个可能更好的状态，但存在死亡风险
```

### 唯一物

```text
继续承世唯一物
VS
放弃它，换取更重要的词条或其他成果
```

## 7. AI 定位

AI 不是权威规则引擎。

允许用途：

- 一世评价文案。
- 事件文本润色。
- NPC 表达变化。
- 开发阶段内容生产辅助。

不允许由 AI 直接决定：

- 数值结算。
- 事件是否满足条件。
- 战斗胜负。
- 词条是否获得。
- 唯一物状态。
- Knowledge 真值与适用性。
- Anchor 快照内容。

所有权威状态必须由可测试的代码和内容规则决定。

## 8. V0.1 核心问题

V0.1 只回答一个问题：

> “活一世 → 死亡 → 总结 → 承世/悟世 → 带着前世信息重走人生”是否好玩？

只要这个循环不好玩，增加更多境界、地图、登录、支付和客户端都没有意义。
