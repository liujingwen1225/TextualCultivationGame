# 移动端 UI 视觉风格基线

> 状态：当前有效基线
>
> 本文档用于锁定《诸世问道》移动端 UI 的正式视觉方向。后续高保真原型、前端组件、图标、背景插画和动效均以本文件为视觉基线。
>
> 当前确认方向：**沿用首版高保真原型的东方修仙美术语言，不采用后续偏现代深色 App 的视觉方向。**

## 1. 核心视觉定位

《诸世问道》的 UI 应首先让玩家感受到“修仙世界中的命书 / 道卷 / 推演界面”，其次才是现代移动应用。

关键词：

```text
东方修仙
+ 墨青夜色
+ 暗金古纹
+ 山水秘境
+ 命书 / 道卷仪式感
+ 精致卡牌
+ 清晰文字信息
```

视觉目标不是做纯古籍拟物，也不是现代极简 App，而是：

> **古典修仙氛围作为外壳，现代移动端信息架构作为骨架。**

---

## 2. 已确认的整体风格

### 2.1 主色调

主背景：

- 墨黑。
- 深墨青。
- 暗蓝绿色。
- 少量山雾灰蓝。

主强调色：

- 暗金。
- 古铜金。
- 玉色青绿。

状态色：

- 危险 / 死亡：暗红、赤褐，不使用高饱和亮红。
- Knowledge / 前世记忆：青玉、幽蓝或冷青。
- 悟世词条：可使用青绿、幽蓝、紫青等低饱和色区分流派。
- 关键命运 / Anchor：金色或金蓝光效。

禁止把界面整体做成纯黑灰的现代后台 / Dashboard 风格。

### 2.2 材质语言

允许使用：

- 宣纸暗纹。
- 木纹 / 铜纹 / 玉石纹理。
- 古籍、册页、卷轴边缘。
- 祥云、阵纹、符纹、山水纹。
- 轻微金属磨损和岁月感。

但避免重度写实拟物导致信息阅读困难。

原则：

> 装饰服务于修仙氛围，不能盖过文字与交互。

---

## 3. 移动端布局原则

当前主平台以**竖屏移动端**为设计基准。

视觉风格保持首版高保真原型，但页面结构必须适合手机单手操作。

典型页面结构：

```text
顶部状态栏
↓
当前场景 / 大幅氛围插画
↓
当前人生 / 事件 / 记忆信息
↓
主要操作区
↓
底部主导航
```

不要因为移动端适配改成纯列表式现代 App。

不要直接把桌面大屏 UI 等比例缩小塞进手机。

---

## 4. 推演主界面

推演主界面是玩家停留时间最长的页面，视觉优先级最高。

### 4.1 顶部状态

顶部使用紧凑的古风状态条，展示：

- 境界。
- 年龄。
- 当前身份 / 地点。
- 回溯次数。

第二行可展示：

- 灵石。
- 气血。
- 灵力。
- 游戏内日期 / 时辰。

不要堆叠过多弱属性。

### 4.2 当前人生区

主视觉采用山水 / 宗门 / 秘境场景插画，并覆盖少量当前人生文本。

推荐：

```text
【当前人生】
你是青玄宗外门弟子……
宗门近日强调戒备黑水山……
```

下方突出前世 Knowledge：

```text
【前世记忆】 2 / 6
黑水山有异动
赵长青需提防
```

Knowledge 应具有明显青玉 / 命书感，与普通任务信息区分。

### 4.3 高频行动

主屏只展示真正高频行为，例如：

- 修炼。
- 外出历练。
- 拜访人物。
- 探索 / 查看当前线索。

行动可以使用带插画的小型竖向卡牌，但数量应控制，避免主屏变成十几个入口的功能宫格。

### 4.4 主动坐化

**主动坐化不是常用行为，不得作为主界面常驻主操作。**

入口统一放置于：

```text
更多
└─ 特殊行动
   └─ 主动坐化
```

执行时必须二次确认。

主屏不得出现与“修炼 / 历练 / 探索”等同等级的大型“主动坐化”卡片或按钮。

---

## 5. 底部导航

建议正式主导航保持 5 项以内。

当前推荐结构：

```text
推演
角色
记忆
锚点
诸世录 / 更多
```

V0.1 可以根据功能完成度缩减，但视觉设计时应预留正式结构。

导航图标采用：

- 命书。
- 人物剪影。
- 轮回 / 记忆环。
- Anchor / 定世符号。
- 古卷 / 册页。

图标应有统一古风线稿语言，不使用通用 Material / iOS 图标直接拼装。

---

## 6. 事件界面

事件页面应突出“进入一段修仙故事”的感觉。

结构：

```text
事件标题
↓
大幅事件插画
↓
事件正文
↓
前世记忆 / 词条提示
↓
选择卡片
```

选择卡片使用暗色底 + 金 / 青边框。

不同来源选项可有不同视觉标识：

- 普通选项：暗金灰。
- Knowledge 解锁：青玉 / 冷青。
- 词条解锁：对应词条色。
- 高危险选项：暗红。

不要使用现代 App 的纯白按钮或蓝色 Primary Button。

---

## 7. 一世总结

死亡总结必须具有较强仪式感，是每次轮回的重要情绪节点。

推荐：

- 大标题“第 X 世终”。
- 山水夜景 / 墓碑 / 远山宗门背景。
- 一世评价置于卷轴或命书面板。
- 人生轨迹使用时间线。
- 本世重要收获使用图鉴式卡片。
- 可悟词条倾向使用不同纹章展示。

死亡页面不做纯统计表。

数据是辅助，人生评价和轨迹才是主体。

---

## 8. Anchor / 承世 / 悟世

这是游戏最有辨识度的系统之一，必须有“轮回结算仪式感”。

### 8.1 Anchor

Anchor 采用：

- 法阵。
- 命轮。
- 道印。
- 古镜。
- 时间节点。

等视觉意象。

已建立 Anchor 应比普通菜单卡片更像“被固定的人生节点”。

选中状态可以使用暗金光晕或青金法阵。

### 8.2 承世

承世偏“实体成果”，视觉侧重：

- 功法卷轴。
- 法宝。
- 装备。
- 丹药。
- 地图 / 特殊物品。

使用暖金 / 古铜色系。

### 8.3 悟世

悟世偏“人生凝结”，视觉侧重：

- 命格纹章。
- 道纹。
- 心境图形。
- 抽象修仙意象。

使用青绿 / 幽蓝 / 紫青等色系。

承世和悟世在一屏中必须能够一眼区分，但仍属于同一套视觉体系。

---

## 9. 词条视觉

词条不是传统 SSR 卡牌，因此禁止在核心表现中使用：

```text
R / SR / SSR / UR
```

词条视觉差异来自：

- 流派。
- 纹章。
- 进阶层级。
- 描边复杂度。
- 背景道纹。

而不是抽卡稀有度颜色。

词条升级可以逐步增加：

- 边框层级。
- 道纹复杂度。
- 轻微光效。
- 图标细节。

保持克制，避免后期变成高饱和手游卡牌。

---

## 10. 字体与排版方向

标题可以使用有书法感、碑帖感的字体风格，但正文必须保证移动端长时间阅读。

建议：

- Logo / 大标题：书法感。
- 一级标题：古典宋 / 楷气质。
- 正文 / 数值：高可读宋体或现代中文正文字体。

禁止所有正文都使用书法字体。

正文需要：

- 足够字号。
- 足够行高。
- 较高前景 / 背景对比度。
- 避免在复杂插画上直接铺长文本。

---

## 11. 插画原则

插画是首版风格的重要组成部分，不应删除。

主要插画类型：

- 宗门山景。
- 城镇与坊市。
- 秘境洞府。
- 山野历练。
- NPC 会面。
- 战斗前后关键场景。
- 死亡 / 轮回背景。

同一地点允许复用主体背景，通过：

- 天气。
- 时辰。
- 雾效。
- 局部人物。
- 事件覆盖层。

产生变化，以控制美术成本。

---

## 12. 动效方向

动效应轻、慢、有仪式感。

推荐：

- 山雾轻微移动。
- 金色纹路呼吸。
- Anchor 法阵缓慢旋转。
- Knowledge 出现时玉色流光。
- 死亡后画面逐渐失色 / 墨化。
- 承世选择时物品被命轮吸入。
- 悟世时词条纹章缓慢凝聚。

不推荐：

- 高频闪烁。
- 大量粒子爆炸。
- 快节奏老虎机式抽卡反馈。

---

## 13. 明确禁止的视觉偏移

后续设计不得未经重新确认自行切换为：

- 纯现代深色 App / Dashboard。
- 大面积纯灰列表。
- Material Design 风格后台。
- 常规二次元抽卡 UI。
- 高饱和霓虹仙侠。
- 纯古籍黄纸界面。

尤其注意：

> **移动端适配只改变布局，不改变首版原型已经确认的美术语言。**

---

## 14. 高保真页面制作顺序

后续优先按以下顺序补齐高保真页面：

1. 推演主界面。
2. 事件选择界面。
3. 一世总结界面。
4. Anchor + 承世 / 悟世结算界面。
5. Knowledge / 前世记忆。
6. 角色 / 功法 / 装备。
7. 词条库 / 下一世配置。
8. 更多 / 特殊行动。

其中前 4 个页面构成核心玩法视觉闭环，必须首先保持统一。

---

## 15. 当前结论

当前正式视觉原则可以压缩为一句话：

> **保持首版高保真原型的墨青、暗金、山水、古纹与修仙仪式感，用现代移动端信息架构重新排布，而不是改造成现代 App 风格。**
