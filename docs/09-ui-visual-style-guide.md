# 诸世问道：视觉语言保留说明

> 状态：部分保留，原移动端布局规范已废弃
>
> 当前产品已调整为 **Steam / Windows 优先的东方修仙像素人生模拟 Roguelite RPG**。本文件不再定义移动端 UI，但其中已经确认的东方修仙视觉语言继续作为新像素版本的重要参考。

## 1. 继续保留的视觉语言

核心关键词：

```text
东方修仙
+ 墨青夜色
+ 暗金古纹
+ 青玉 / 幽蓝 Knowledge
+ 山水秘境
+ 命书 / 道纹
+ 轮回仪式感
```

继续保留：

- 墨黑、深墨青、暗蓝绿色作为主要氛围色。
- 暗金、古铜金作为 Anchor / 关键命运强调色。
- 青玉、幽蓝作为 Knowledge / 前世记忆识别色。
- 暗红、赤褐作为死亡 / 危险提示色。
- 宣纸暗纹、木纹、铜纹、玉石、祥云、阵纹、符纹等东方材质语言。
- Anchor 使用命轮、法阵、道印、古镜、时间节点等视觉意象。
- 承世偏实体、暖金 / 古铜；悟世偏精神凝结、青绿 / 幽蓝 / 紫青。
- 词条不用 R / SR / SSR / UR 作为核心价值表达。

## 2. 新像素世界方向

当前首版视觉目标不是复刻 HD-2D 精品 JRPG，而是：

> **高质量东方像素 RPG + 克制的现代灯光、雾效、粒子与关键插画。**

建议表现：

- 俯视 / 斜俯视像素地图。
- 2D 像素人物与 NPC。
- Tile 场景。
- 宗门、坊市、山脉、秘境具有明确区域差异。
- 少量动态光源、天气、山雾、灵气粒子加强氛围。
- 关键 NPC 对话、重大事件、死亡和轮回可以使用立绘 / 插画。
- UI 作为游戏世界的辅助层，而不是整个游戏本体。

## 3. 新桌面 UI 原则

桌面版 UI 需要围绕游戏画面服务：

```text
游戏场景
├─ 轻量 HUD
├─ 交互提示
├─ 对话 / 事件选择
├─ 角色 / 背包 / 功法
├─ Knowledge / 词条
└─ 死亡 / Anchor / 承世 / 悟世结算
```

必须避免：

- 重新做成现代 Dashboard。
- 用大量后台列表替代修仙世界体验。
- 把移动端底部导航直接搬到桌面。
- 让卡片 UI 占据大部分常规游玩时间。

## 4. 最重要的高仪式感界面

以下界面即使转为像素 RPG，仍应作为高视觉投入节点：

1. 第 X 世终 / 一世总结。
2. Anchor 选择。
3. 承世 / 悟世二选一。
4. Knowledge 获得 / 前世记忆触发。
5. 关键突破与重大秘境事件。

这些地方可以比普通地图 HUD 更精致，用插画、道纹、光效、墨化转场等加强情绪。

## 5. 已废弃的旧规则

不再适用：

- 移动端竖屏作为主平台。
- 底部 5 项导航。
- 移动 App 信息架构作为整体骨架。
- 以大幅插画 + 卡片操作代替真实地图探索。
- “一只手操作”作为 UI 验收标准。

## 6. 当前结论

新的视觉原则可以压缩为一句话：

> **用像素世界承载修仙生活和探索，用墨青、暗金、青玉、道纹与关键插画承载命运、记忆和轮回。**

具体像素规格、Tile 尺寸、角色尺寸、相机、HUD 和桌面分辨率适配，在最终游戏引擎确定后单独形成新的视觉实现规范。

原移动端完整视觉规范仍可通过 Git 历史查看。
