# 诸世问道：像素视觉风格基线

> 状态：Steam 像素 RPG 重设计当前有效基线
>
> 本文档用于锁定《诸世问道》的桌面像素视觉方向。目标不是复刻《八方旅人》的 HD-2D 制作规格，也不是做复古低信息量像素画，而是建立可被一个人 + AI 长期生产的东方修仙像素美术体系。

## 1. 核心视觉定位

关键词：

```text
东方修仙
+ 像素角色
+ 俯视 / 斜俯视地图
+ 墨青夜色
+ 暗金古纹
+ 山水云雾
+ 青玉 Knowledge
+ 命轮 / 道纹
+ 克制光影
```

核心目标：

> **第一眼是一个真正的像素修仙 RPG，进入轮回系统后又拥有独特的命书、道纹与时间感。**

## 2. 不做什么

不以以下方向作为首版目标：

- 《八方旅人》规格的 2D + 高复杂度 3D HD-2D 场景。
- 高饱和仙侠手游。
- 纯黑灰现代 Dashboard。
- 大量 Live2D / 骨骼动画角色演出。
- 每个事件都制作独立高成本插画。
- 写实 3D 修仙世界。

## 3. 场景表现

V0.1 推荐：

- Tile-based 像素地图。
- 俯视或轻斜俯视镜头。
- 2D 像素角色。
- 分层地表 / 建筑 / 植被。
- 少量动态光源。
- 雾、雨、落叶、灵气等粒子。
- 昼夜色调变化。
- 水面和灵气区域使用克制 Shader。

目标是让青玄宗、坊市、黑水山脉与秘境在有限资产下有明显辨识度。

## 4. 像素规格原则

角色与地图的具体像素尺寸在引擎原型后最终确认。

在选型前只锁定原则：

- 使用统一基础像素网格。
- 角色、建筑、道具保持一致像素密度。
- 不混用明显不同分辨率的像素资产。
- UI 可以高分辨率绘制，但像素图标与场景资产必须遵守同一视觉语言。
- 镜头缩放优先使用整数或可控倍率，避免像素抖动和模糊。

## 5. 角色设计

V0.1 角色重点不是复杂动作，而是高识别度。

至少需要：

- 待机。
- 四方向移动或适配选定镜头的移动动画。
- 受击。
- 简单施法 / 攻击。
- 倒地 / 死亡。

核心 NPC 通过：

- 发型。
- 服饰颜色。
- 武器 / 法器。
- 身形轮廓。
- 头像 / 半身立绘。

建立识别度。

## 6. 地图区分

### 青玄宗

- 青灰石阶。
- 松柏。
- 云雾。
- 暗青屋瓦。
- 金色 / 玉色阵纹点缀。

氛围：安静、有秩序、略有压迫感。

### 青石坊市

- 木结构店铺。
- 灯笼。
- 摊位。
- 更多暖色照明。
- 人流感高于宗门。

氛围：现实、繁杂、信息流动。

### 黑水山脉

- 深青 / 蓝黑。
- 潮湿岩石。
- 枯木。
- 毒雾。
- 水洼 / 黑水。

氛围：未知、压抑、危险。

### 黑水秘境

- 更强的冷色对比。
- 阵纹。
- 非自然光源。
- 稀少但高辨识度的灵性颜色。

氛围：超出正常世界规则。

## 7. 光影原则

光影用于氛围和引导，不用于掩盖像素资产质量。

推荐：

- 夜间灯笼暖光。
- 宗门法阵淡金光。
- Knowledge 相关青玉光。
- 秘境冷色灵光。
- 危险区域暗红 / 紫黑环境提示。

避免：

- 大面积 bloom。
- 满屏粒子。
- 过强景深导致像素画糊成一片。
- 复杂实时阴影成为性能和生产瓶颈。

## 8. UI 视觉语言

桌面 UI 仍继承旧设计中最有辨识度的部分：

```text
墨青
暗金
古纹
命书
道卷
青玉记忆
```

但不再按照手机卡片布局设计。

UI 应像：

> 修仙世界中的游戏界面。

而不是：

> 一张铺在屏幕上的古籍网页。

## 9. HUD

HUD 透明、轻量、边缘化。

- 气血 / 灵力：细条或符纹式状态。
- 境界：文字 + 小型道纹。
- 时间：天色 / 时辰图标 + 文字。
- 回溯：命轮 / 圆环图标。

不使用大量矩形后台卡片。

## 10. Knowledge

Knowledge 是视觉辨识度最高的系统之一。

视觉元素：

- 青玉。
- 冷青流光。
- 残影。
- 旧人生碎片。
- 轻微双重影像。

前世记忆出现时应该让玩家感觉：

> **当前现实中浮出了另一个未来的痕迹。**

但不使用强烈故障 / 科幻 Glitch 风。

## 11. Anchor

Anchor 使用：

- 命轮。
- 法阵。
- 道印。
- 古镜。
- 时间节点。

作为核心视觉意象。

每个已建立 Anchor 应像一个被“固定”的人生阶段，而不是普通存档按钮。

## 12. 承世 / 悟世

### 承世

偏实体：

- 暖金。
- 古铜。
- 功法卷轴。
- 法宝轮廓。
- 实体物品被命轮带回过去的感觉。

### 悟世

偏精神：

- 青绿 / 幽蓝 / 紫青。
- 命格纹章。
- 道纹凝结。
- 人生轨迹化为能力。

必须一眼区分。

## 13. 词条视觉

禁止使用：

```text
R / SR / SSR / UR
```

词条差异来自：

- 流派图形。
- 道纹。
- 进阶层级。
- 图标复杂度。
- 文字描述。

不把它做成手游抽卡品质框。

## 14. 事件表现

普通交互尽量留在场景中。

重大事件才加强表现：

- 镜头靠近。
- 背景轻微暗化。
- NPC 头像 / 立绘。
- 事件正文。
- 选择列表。

关键事件允许使用少量专属插画，但 V0.1 不要求每个事件都有插画。

同一背景通过：

- 时辰。
- 天气。
- 局部人物。
- 光效。
- 雾效。

产生变化，控制资产成本。

## 15. 战斗表现

V0.1 战斗视觉追求：

- 打击 / 法术反馈清楚。
- 状态可读。
- 风格统一。
- 动画资产量可控。

不追求大量华丽技能动画。

法术可以通过：

- 像素粒子。
- 小型 Sprite 动画。
- 屏幕轻微震动。
- 光效。
- 音效。

建立反馈。

## 16. 死亡与轮回

死亡不采用传统红色 GAME OVER。

推荐：

- 场景逐渐失色。
- 环境音抽离。
- 墨化 / 雾化。
- Knowledge 或关键人生片段短暂闪回。
- 出现“第 X 世终”。
- 转入命轮 / Anchor 结算。

死亡要成为玩家期待理解和总结的一部分。

## 17. 字体与排版

- Logo / 大标题：可有书法感。
- 章节 / 事件标题：宋 / 楷气质。
- 正文：高可读中文字体。
- 数值和快捷键：清晰优先。

不要把所有文字都做成书法字体。

桌面端允许比移动端更宽的文本区域，但单行仍不宜过长。

## 18. AI 美术使用原则

AI 可以用于：

- 概念图。
- 场景气氛参考。
- NPC 服装方向。
- 图标草图。
- 调色方案。

正式像素资产必须统一：

- 像素密度。
- 轮廓语言。
- 调色板。
- 动画节奏。

不能把不同 AI 风格图片直接缩小当作正式像素资产。

## 19. V0.1 美术资产上限

优先完成：

1. 主角基础动画。
2. 5～8 个重要 NPC 的场景 Sprite。
3. 青玄宗地图 Tileset。
4. 坊市补充 Tileset。
5. 黑水山脉 / 秘境 Tileset。
6. 5 种以内敌人。
7. 基础战斗特效。
8. Anchor / Knowledge / 承世 / 悟世核心 UI。
9. 少量关键人物头像。

不先制作大量皮肤、装饰物和无玩法用途资产。

## 20. 当前结论

当前视觉方向可以压缩为：

> **以可长期生产的东方像素世界作为主体，用墨青、暗金、青玉、云雾和道纹强化修仙与轮回感；追求氛围和辨识度，不追求高成本 HD-2D 资产堆量。**
