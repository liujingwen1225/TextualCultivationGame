# 战斗与 Build 设计

## 1. 战斗定位

战斗是核心玩法支柱之一，但不以刷大量无意义杂兵作为主要成长方式。

战斗用于解决：

- 修士冲突。
- 妖兽威胁。
- 秘境危险。
- 宗门 / 势力争夺。
- 资源竞争。
- 护送、逃亡、伏击与反伏击。

核心原则：

> **战斗是高风险解决问题的重要手段，但不是“缺什么就刷怪”。**

## 2. 战斗空间

战斗发生在当前地图原地，不切换独立战斗背景。

位置、距离、遮挡、地形、阵法区域具有战术意义。

不做动作 RPG 级别的精准闪避、无敌帧、连招和像素级判定。

核心原则：

> **位置是战术资源，不是手速资源。**

## 3. 时间制式

采用可暂停实时（RTwP）：

- 非暂停时战斗时间持续推进。
- 玩家可以随时暂停观察战场并下达行动。
- 行动具有启动 / 施法时间、执行窗口、打断条件和冷却 / 恢复时间。
- 可在关键情况自动暂停，例如危险术法出现、行动完成、重伤、新敌人加入或盟友倒下。

不把系统做成“每个动作强制停顿”的伪回合制。

## 4. 控制对象

玩家完全控制主角。

盟友采用简化战术倾向和有限指令，例如：

- 保护我。
- 集火指定目标。
- 优先攻击施法者。
- 保留法力。
- 撤退。
- 跟随。
- 自由行动。

不做多角色技能栏重度管理型 CRPG。

## 5. 战斗 Build

玩家可以掌握较多能力，但当前实战方案必须受限。

典型配置：

```text
主修功法       1
战斗术法       4～6
身法           1
护体 / 防御    1～2
法宝           2～3
消耗品快捷栏   少量
```

具体槽位后续平衡。

重大 Build 调整应在脱离战斗后进行；部分功法、法宝或炼化变化需要消耗游戏内时间。

## 6. 生存模型

不使用单一 HP 表达全部生存状态，也不做器官级模拟。

基础资源：

- 气血。
- 法力。
- 护体 / 防护状态。
- 神识相关资源或限制。

持续后果：

- 普通伤势。
- 重伤。
- 经脉损伤。
- 根基损伤。
- 神魂受创。
- 中毒与特殊状态。

战斗胜利后可能仍然需要长时间疗伤。

## 7. 一击致死

允许具有明确规则依据的一击致死：

- 明显境界压制。
- 致命术法直接命中。
- 护体失效后的高阶攻击。
- 特殊阵法或秘境机制。

不允许无意义的低概率随机猝死。

“不能被这一招命中”可以成为通过调查或实战获得的重要情报。

## 8. 情报与战斗

情报不直接提供“伤害 +20%”式 Meta 加成。

它主要揭示：

- 敌人习惯。
- 技能顺序。
- 功法缺陷。
- 旧伤。
- 隐藏阶段。
- 虚弱窗口。
- 可提前准备的克制手段。

表现层可以据此提供更明确的时间轴预警、特殊目标或额外战术选项。

## 9. 法宝与消耗品

法宝是能力对象，而不是单纯数值装备：

- 需要炼化或适配。
- 有境界 / 功法兼容性。
- 可以受损、被夺、留下印记或存在秘密。
- 可以提供主动技能和规则能力。

丹药、符箓、阵盘等消耗品允许非常强，因为它们代表事前准备，但受到价格、数量、使用时机和副作用约束。

## 10. 战斗与经济

资源主要来自：

- 宗门份额。
- 坊市交易。
- 人物关系。
- 秘境。
- 灵地。
- 委托。
- 生产。
- 争夺与杀人夺宝。

杀人夺宝可以高收益，但需要承担：

- 追查。
- 仇怨。
- 宗门 / 家族关系。
- 赃物来源。
- 法宝印记。
- 更高阶人物介入。

敌人不是移动宝箱。

## 11. V0.1 战斗边界

V0.1 直接验证正式制式，而不是做以后必重写的临时战斗。

内容保持很小：

- 3 种左右普通敌人。
- 1 个关键精英 / 修士战。
- 主角 4～6 个核心战斗能力。
- 1～2 件有主动意义的法宝或装备。
- 少量丹药 / 符箓。

验证重点：

```text
地图原地 Combat State
+ RTwP
+ 位置
+ 动作时间
+ 术法
+ 消耗品
+ 伤势
+ 逃跑
```
