# 诸世问道：世界资源与经济已确认决策

> 状态：Matt `grill-with-docs` 进行中的阶段性决策记录。
>
> 用途：记录第 8 轮已确认的修真资源、经济、宗门权力与 Knowledge 经济玩法方向；完整 Grill 结束后再归并到正式设计文档。

## 1. 灵石与宗门功勋

灵石不是普通金币换皮，而是兼具交易与真实修炼用途的标准资源货币。

可用于：

- 坊市交易。
- 修炼辅助。
- 阵法供能。
- 法器 / 法宝驱动。
- 传送、灵舟或其他修真服务。
- 支付修士服务。

宗门内部可以存在功勋 / 善功等权限型凭证，用于兑换宗门控制的资源、资格与传承，但不作为第二种万能货币。

## 2. 稀缺资源随境界升级

低境界问题可以较多通过灵石解决；越高境界，关键资源越不能仅靠货币购买。

炼气阶段常见稀缺项包括：

- 灵石。
- 丹药。
- 普通术法。
- 修炼地点。
- 法器。

筑基及以上逐步转向：

- 突破法门。
- 筑基 / 高阶灵物。
- 高品质灵脉。
- 核心传承。
- 师承与资格。
- 高阶洞府与秘境名额。
- 特定天地资源与时间窗口。

核心原则：

> **境界越高，真正重要的资源越依赖势力、传承、关系、机缘和世界结构，而不是单纯购买力。**

## 3. 宗门权力来源

宗门的控制力必须来自真实生产资料和保护能力，而不是仅靠设定宣称。

宗门可以掌握：

- 灵脉与灵地。
- 高阶功法与突破传承。
- 丹师、炼器师、阵师等专业能力。
- 秘境名额。
- 安全修炼环境。
- 高阶修士保护。
- 情报网络。
- 商路与地盘。

加入宗门意味着获得资源与安全，同时承担义务、规则、派系与政治风险。

## 4. 散修是完整路线

散修不是“没加入宗门的失败状态”。

散修路线特点：

- 自由度高。
- 稳定资源差。
- 风险高。
- 情报弱。
- 缺少统一保护。
- 更容易接触灰色交易与多势力合作。
- 不承担宗门固定义务。

宗门修士则资源与传承更稳定，但受身份、规则、派系、任务和因果约束。

## 5. 坊市不是无限商城

市场由实际世界状态驱动，不提供无限库存与固定常驻稀有物。

供给可以分为：

- 常规供给。
- 周期供给。
- 稀有交易。
- 拍卖。
- 私人交易。
- 黑市。
- 人物关系渠道。

高价值物品可能需要身份、关系、时间窗口或特殊渠道才能获得。

## 6. 状态驱动经济

不实现大规模 NPC 生产、运输与消费的完整经济模拟。

经济变化主要来自：

```text
世界事件
+
地区状态
+
资源池
+
商人状态
```

例如秘境开放导致解毒丹涨价、宗门大战导致疗伤丹与符箓紧缺、灵矿被毁导致某类法器价格上涨。

目标是让玩家感到经济在运行，而不承担复杂宏观模拟成本。

## 7. 修士生计结构

修士社会中的人物需要有合理生计来源。

例如：

- 宗门弟子：月例 + 宗门任务。
- 散修：护送、采药、猎妖、制符等。
- 丹师：炼丹交易。
- 阵师：布阵与维护。
- 家族修士：管理灵田、商路和地盘。
- 坊市修士：经商、鉴定、护卫。

这些职业不要求全部做成完整经营系统，但必须解释 NPC 的位置、资源、动机与利益关系。

## 8. 杀人夺宝

杀人夺宝可以具有极高经济收益，因为一个修士多年积累可能集中在储物袋、法宝、丹药、秘籍与灵石中。

但同时承担：

- 法宝认主与储物禁制。
- 赃物身份与追踪印记。
- 宗门追查。
- 亲族复仇。
- 势力关系恶化。
- 因果与高阶人物介入。
- 黑市销赃风险。

因此杀人是重大经济与政治行为，不是刷怪掉装备。

## 9. Knowledge 驱动经商

允许玩家利用前世情报进行有时间窗口的经济行为。

例如提前知道某地区即将封锁或某种物资将紧缺，可以提前采购、囤积、交易。

该玩法受到：

- 本金。
- 时间。
- 仓储。
- 风险。
- 机会成本。

约束，不发展成无脑跨城跑商刷钱。

## 10. 截胡机缘

Knowledge 可以用于提前获取前世已知的机缘、资源或交易窗口。

玩家提前截胡后，原本获得资源的人将失去该机缘，其后续人生与世界事件应真实变化。

核心原则：

> **Knowledge 让玩家利用未来情报改变资源归属，但不会自动保证拿到资源。境界、准备、竞争者、地图与政治风险仍然存在。**
