# 诸世问道：世界、NPC 与内容系统

> 状态：Steam 像素 RPG 重设计当前有效基线

## 1. 设计目标

世界要让玩家感到自己真的生活在修仙世界中，但不做持续自主模拟的无限沙盘。

核心原则：

> **地图负责空间与沉浸，事件系统负责因果与内容深度。**

世界必须同时满足：

- 有稳定骨架，让 Knowledge 有价值。
- 有一世变数，让重复人生仍有新鲜感。
- 有真实可探索空间，而不是纯菜单跳转。
- 内容量可被一个人 + AI 长期维护。

### 1.1 修真世界基调

当前世界观气质参考《玄鉴仙族》与《苟在初圣魔门当人材》的共同结构感，但不复制其具体势力、功法、人物、独有设定或剧情。

我们要保留的结构特征：

- **境界有重量**：大境界不是单纯数值台阶，而会改变寿元、能力边界、社会地位、资源获取方式和对低阶修士的压制力。
- **修炼资源真实稀缺**：功法、丹药、灵地、法器、传承和突破资源都掌握在具体人物与势力手中，获取它们需要付出关系、时间、风险、任务或代价。
- **宗门不是绝对安全区**：同门、执事、师长都可能因利益、派系、秘密或功法代价伤害玩家；身份能够带来保护，也会带来义务、限制与危险。
- **NPC 有自己的利益与因果**：人物不是只为给任务和奖励而存在，可以欺骗、利用、试探、结盟、背叛、设局，也可能因为玩家前世干预而改变立场。
- **突破本身有风险**：修炼、突破、功法选择、丹药、秘术都可能造成伤势、根基损伤、走火入魔甚至死亡。
- **高阶修士是世界结构的一部分**：高境界人物的存在应真正改变地区秩序、势力关系和玩家行为，而不是仅作为更高等级怪物。
- **Knowledge 是生存优势而不是剧本答案**：前世记忆可以帮助玩家识别陷阱、提前准备、利用人物弱点与时间窗口，但不能无条件抹平境界和资源差距。

因此本作的修仙世界不是“所有人都恶”的黑暗森林，也不是安全的传统新手村式宗门，而是一个有制度、有利益、有情义、也有算计和真实死亡风险的修真社会。

## 2. 世界结构

推荐层级：

```text
World
├─ Region
│  ├─ Map
│  │  ├─ Zone
│  │  ├─ Interaction Point
│  │  ├─ NPC Spawn / Schedule
│  │  └─ Event Pool
│  └─ Faction / Sect
├─ NPC Group
├─ Secret Realm
├─ Event Chain Pack
└─ World Crisis Pack
```

地图不是单纯背景图，而是玩家真实移动和选择路线的空间。

## 3. 地图系统边界

### 地图需要支持

- 行走。
- 进入建筑 / 区域。
- 与关键 NPC 接触。
- 调查交互点。
- 资源点。
- 危险区域。
- 战斗 / 事件入口。
- 时间与天气氛围变化。

### 地图不需要支持

- 每件家具独立物理模拟。
- 每个路人完整人生模拟。
- 任意建筑建造拆除。
- 超大无缝开放世界。
- 为“真实”而加入没有玩法价值的互动。

地图中的一个交互点应该指向有意义的规则或事件，而不是为了可点击而可点击。

## 4. 地点、事件与状态联动

同一个地点因为当前人生状态不同，应产生不同内容。

例如进入丹阁：

```text
地点 = 丹阁
时间 = 傍晚
陈执事 = 在场
赵长青 = 受伤
玩家 Knowledge = 知道黑水灵酒有毒
已装备词条 = 识毒
```

Event Engine 可以据此产生：

- 普通购买。
- 陈执事委托。
- 调查药柜。
- 前世记忆提示。
- 识毒专属观察。
- 赵长青支线。

所以内容深度主要来自状态组合，而不是不断增加新地图。

## 5. 世界模板与预设模块组合

正式游戏不由 AI 在运行时从零生成整个世界。

内容由开发者维护的预设模块组成：

- 区域 / 地图包。
- 宗门 / 势力包。
- NPC 人物组。
- 秘境包。
- 事件链包。
- 世界危机包。
- 资源分布包。

新世界按兼容规则组合。

V0.1 不做组合，只验证固定黑水世界片段。

## 6. 新世界必须改变核心答案

真正的新世界不能只换名字和数值。

允许变化：

- 地图连接关系。
- 宗门与势力。
- NPC 组合。
- 内鬼 / 敌人身份。
- 危险来源。
- 秘境机制。
- 关键事件真相。
- 重要传承位置与获得方式。

Knowledge 在新世界清空，必须因为“答案真的变了”，而不是人为清档。

## 7. NPC 分层

NPC 不采用大规模 Agent 模拟。

### S 级核心人物

- 长期人物线。
- 多层秘密。
- 多维关系。
- 重大事件参与者。
- 跨多世有不同结局。

### A 级重要人物

- 有明确动机。
- 有 1～2 条事件线。
- 能影响玩家资源、关系或路线。

### B 级模板人物

- 商人、弟子、执事、旅人等。
- 主要承担世界氛围、普通服务和随机事件。

V0.1 只需要 5～8 个重要 NPC，再补少量模板 NPC 营造场景。

## 8. NPC 状态与日程

像素世界需要最低限度的“人在世界里”的感觉。

关键 NPC 可具有：

- 当前地点。
- 简单日程。
- 是否可交互。
- 当前关系。
- 关键记忆。
- 事件链状态。
- 受伤 / 失踪 / 死亡等状态。

不要求逐分钟模拟所有 NPC。

建议采用：

```text
时间段 + 当前事件状态
→ 决定 NPC 出现位置与行为
```

而不是昂贵的全天候 AI 行为模拟。

## 9. NPC 关系

关系按需要使用：

- 亲近。
- 信任。
- 尊敬 / 畏惧。
- 怀疑。
- 兴趣。
- 敌意。

不是所有 NPC 都拥有所有维度。

关系属于当前现实 / Anchor 状态；玩家对 NPC 的未来了解属于 Knowledge。

## 10. NPC 记忆与玩家 Knowledge

必须区分：

### NPC 记忆

属于当前世界线。

回到更早 Anchor 后，NPC 不记得尚未发生的未来。

### 玩家 Knowledge

跨 Anchor 保留。

玩家可能记得与某 NPC 相处几十年的经历，而当前 NPC 第一次见到玩家。

这种信息不对称是重要情绪来源。

## 11. 宗门与势力

宗门首先是：

- 空间。
- 身份网络。
- NPC 网络。
- 权限网络。
- 事件网络。
- 资源分配网络。
- 道统与传承网络。

不是 V0.1 的经营模拟。

可以包含：

- 藏经阁。
- 丹阁。
- 任务堂。
- 演武场。
- 弟子居所。
- 山门。

玩家通过实际移动进入地点，再由规则与事件系统提供内容。

### 11.1 境界即权力的重要基础

境界提升不仅改变战斗能力，也改变玩家在修真社会中的身份与可接触内容。

典型结构可以表现为：

```text
低阶修士
→ 受制度与资源分配约束

筑基等中坚修士
→ 开始拥有实际职务、资源、弟子或独立行动权

紫府 / 金丹等高阶人物
→ 可以决定地区势力格局、资源分配和重大事件走向
```

但境界不是唯一地位来源。实际权力还受到：

- 传承与师承。
- 家族 / 宗门背景。
- 派系。
- 职务。
- 法宝和实际战力。
- 掌握的资源。
- 人情与盟友。

玩家突破后，应自然解锁以前无法接触的人、地点、秘密和冲突，而不是只获得新的战斗数值。

### 11.2 正魔不是简单善恶阵营

“正道”“魔道”主要描述道统、组织方式、修炼伦理和资源逻辑，而不是直接等同于善恶值。

正道势力可能为了秩序、利益或宗门延续牺牲低阶弟子；魔道势力也可能存在稳定规则、契约、师徒关系和利益信用。

势力差异可以体现在：

- 如何获得修炼资源。
- 如何约束弟子。
- 如何处理凡人和附属势力。
- 对禁术、夺舍、血祭、炼魂等手段的容忍程度。
- 如何分配功法和突破机会。
- 对背叛、契约、血缘和师承的看法。

玩家判断一个势力是否值得加入，应依赖其具体制度、人物和自身路线，而不是阵营标签自动给出答案。

## 12. 秘境

秘境是高密度探索 + 事件 + 风险空间。

结构：

```text
进入地图
↓
路线选择
↓
调查 / 战斗 / 环境风险
↓
资源 / Knowledge
↓
继续深入或撤离
↓
更高收益 + 更高死亡风险
↓
核心成果 / 死亡 / 撤退
```

不要求复杂程序化迷宫。

首版可以使用固定骨架 + 少量可变事件和路线。

## 13. 事件内容模型

基础事件：

```text
Event
├─ id
├─ trigger
├─ title / text
├─ tags
├─ conditions
├─ choices
│  ├─ conditions
│  ├─ effects
│  └─ next
├─ knowledgeRewards
├─ chainId
├─ priority
└─ repeatPolicy
```

Trigger 可以来自：

- 进入地图区域。
- 与 NPC 交互。
- 调查对象。
- 时间推进。
- 修炼 / 炼丹等行动。
- 战斗结束。
- 世界状态变化。

## 14. Condition / Effect

### Condition

典型条件：

- 境界。
- 地点 / Zone。
- 时间。
- NPC 状态。
- 关系。
- Knowledge。
- 已装备词条。
- 持有物品。
- 已发生事件。
- 世界标签。

### Effect

典型效果：

- 时间推进。
- 修为 / 状态变化。
- 资源变化。
- NPC 关系变化。
- NPC 位置 / 状态变化。
- 物品获得 / 消耗。
- 伤势。
- Knowledge 获得。
- 事件链推进。
- 世界状态变化。
- 战斗触发。
- 死亡。

## 15. 事件链

事件链用于表达持续因果：

```text
发现异状
→ 调查
→ 获得线索
→ 是否干预
→ NPC 反应
→ 世界状态改变
→ 新地点 / 新交互 / 新事件
```

回到更早 Anchor 后现实事件链状态可以重置，但玩家 Knowledge 保留。

## 16. 熟悉与减少重复

重复人生不应该要求玩家机械地重新走完所有地图。

熟悉状态可以由 Knowledge 和历史经历派生，用于：

- 快速旅行到已知安全地点。
- 自动略过低价值重复对话。
- 已解决普通事件显示“按前世经验处理”。
- 地图标记已知关键对象。
- 缩短重复路线。

但高价值风险与重要资源决策仍必须由玩家确认。

## 17. 内容生产优先级

### 高价值内容

- 第一世不知道会吃亏。
- 第二世 Knowledge 能改变选择。
- 改变之后产生新的未来。
- 同一地点因为人物 / 时间 / 状态不同产生不同内容。
- 失败会留下可利用的信息。

### 低价值内容

- 每世完全相同。
- 只有数值奖励。
- 无论选择什么结果都一样。
- 只增加跑地图时间。
- 需要大量资产但几乎没有规则变化。

## 18. V0.1 世界范围

只提供固定世界片段：

```text
青玄宗        1 个核心地图
青石坊市      1 个核心地图
黑水山脉      1～2 个探索地图
黑水秘境      1 个核心地图
```

内容：

- 5～8 个重要 NPC。
- 少量模板 NPC。
- 1 条黑水三世主事件链。
- 若干普通地点 / NPC 事件验证一世变数。
- 5 种以内敌人。

先证明“小世界可以因为多世状态变化而很深”，再扩大地图数量。
