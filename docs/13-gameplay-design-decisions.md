# 诸世问道：玩法设计决策稿

> 状态：Matt `grill-with-docs` 进行中的已确认设计决策。
>
> 用途：在完整设计树收口前集中记录已经由用户确认的玩法、世界观、修炼与战斗方向；Grill 结束后再归并到 `01/03/04/05` 等正式设计文档。

## 1. 玩家核心幻想

玩家扮演的是修仙世界中的一个具体的人，而不是宗门管理者、纯战斗角色或剧情选择器。

核心体验：

> **我在这个真实运转、等级森严且危险的修仙世界中活过很多世，并利用前世 Knowledge 一次次改变自己的命运。**

修炼、战斗、人物关系、秘境、势力和事件都属于人生的一部分。

## 2. 一世的基础结构

采用“自由人生 + 有约束的世界时间线”。

玩家从 Anchor 开始一世后，可以自由决定当前人生方向：

- 修炼与突破。
- 前往坊市或其他地点。
- 与 NPC 建立关系或调查人物。
- 利用前世 Knowledge 验证或改变事件。
- 探索野外与秘境。
- 参与宗门 / 势力事务。
- 战斗、争夺资源、躲避危险。
- 为未来已知危险提前准备。

世界本身存在稳定的大事件、人物行动和时间窗口。玩家可以参与、错过、提前准备、阻止、利用或改变它们。

## 3. 时间是核心战略资源

现实操作时间不等于游戏世界时间。

有意义行为才消耗世界时间，例如：

```text
重要交谈 / 本地调查 → 分钟 / 小时
采集 / 短途行动       → 小时 / 半日
跨区域旅行             → 小时 / 天
炼丹 / 养伤 / 普通修炼 → 天 / 月
闭关                   → 月 / 年
```

玩家不可能在同一天处理所有机会，因此必须做取舍。

Knowledge 的重要价值之一是降低第二世以后重复调查与试错的时间成本。

## 4. 一世长度与死亡

不设置固定现实时间上限。

体验目标：

- 早期夭折可能只有几十分钟。
- 普通一世通常约 1～3 小时。
- 极其成功的长寿人生可以明显更长。

玩家应该**容易死亡**，而且死法非常多样：

- NPC 设局、欺骗、下毒、伏杀、借刀杀人。
- 普通或越级战斗。
- 围杀。
- 突破失败。
- 走火入魔。
- 功法反噬。
- 中毒、诅咒、伤势恶化。
- 秘境阵法、陷阱和环境灾害。
- 炼丹 / 炼器事故。
- 天劫。
- 世界事件。
- 寿元终结。
- 主动坐化。

死亡频繁不等于随机秒杀。第一次可以完全未知，但经历、调查或死亡后，危险应逐渐变成可以理解、准备、利用、规避或正面解决的问题。

长寿不是常态，而是一种非常成功的人生。玩家第一次真正从炼气活到筑基、紫府甚至更高境界，本身就应该具有很强成就感。

## 5. 一世最小玩法循环

锁定为：

```text
发现机会 / 危险
↓
准备
├─ 修炼
├─ 功法 / Build
├─ 丹药 / 法宝 / 装备
├─ 找 NPC / 盟友
├─ 调查
└─ 利用 Knowledge
↓
行动
├─ 战斗
├─ 秘境
├─ 争夺
├─ 调查
├─ 宗门 / 人物事件
└─ 突破
↓
后果
├─ 成长
├─ 伤势
├─ 资源变化
├─ NPC / 势力关系变化
├─ Knowledge
├─ 新机会
├─ 新危险
└─ 死亡
```

这套“准备 → 行动 → 后果”是连接修炼、战斗、事件与多世系统的基础循环。

## 6. 目标与任务表达

不使用传统 RPG 主线任务列表作为整个游戏的组织骨架。

玩家可以通过“机会 / 风声 / 人生目标”知道世界当前有哪些值得关注的事情，例如：

- 还差一种筑基资源。
- 三日后宗门小比。
- 某 NPC 最近行为异常。
- 坊市出现特殊法器。
- 半月后秘境开启。

玩家可以选择全部不管。

宗门任务、坊市委托等传统任务仍可以存在，但只是世界中一种具体行为。

世界事件、人物诉求、势力行动和时间窗口应独立于玩家持续发生。

## 7. NPC 世界模拟

关键 NPC 采用：

```text
时间段
+
事件状态
+
NPC 当前状态
→ 当前地点 / 可用行为
```

不逐秒模拟所有人物。

NPC 有自己的利益、关系、秘密和目标，可以：

- 帮助玩家。
- 欺骗玩家。
- 试探玩家。
- 利用玩家。
- 背叛。
- 设局。
- 结盟。
- 被玩家前世干预改变命运。

## 8. 战斗的产品地位

战斗是核心玩法支柱之一，频率中高，但不以刷大量无意义杂兵作为成长主循环。

核心体验应同时包含：

- 修炼 / Build。
- 战斗。
- 探索。
- NPC / 世界事件。
- 资源与机会准备。

Knowledge 可以让玩家“更会打”，不能简单让玩家“不用打”。

它可以揭示：

- 敌人弱点。
- 技能顺序。
- 特殊阶段。
- 功法缺陷。
- 某个虚弱时间窗口。
- 可以提前取得的克制法宝。
- 可邀请的盟友。

最终仍需要角色实力、Build、资源和实际战斗决策完成挑战。

## 9. 战斗制式

当前锁定方向：

> **地图原地进入 Combat State 的暂停 / 半即时战术时间轴战斗。**

不切换传统 JRPG 独立战斗背景，也不做强调操作手感和连招的动作 RPG。

地图仍是当前战斗空间，进入战斗后敌我动作通过时间轴执行。

战斗系统应能表达：

- 施法 / 动作时间。
- 打断。
- 法力与资源。
- 法术。
- 法宝。
- 丹药。
- 状态与伤势。
- 距离与位置。
- 阵法 / 环境。
- 多人参战。
- 逃跑。

Knowledge 可以对时间轴产生信息优势，例如提前知道敌人某次攻击后的空门或隐藏技能。

## 10. 熟悉内容与快速处理

多世不能要求玩家机械重复已经证明会做的事情。

Knowledge 与熟悉状态可逐渐开放：

- 已知安全地点快速旅行。
- 已解决普通事件快速处理。
- 缩短重复对话。
- 已知路线摘要。
- 地图标记已知关键对象。
- 明显碾压且不存在未知变化的普通战斗快速解决。

原则：

> **压缩已解决问题，但不能自动跳过仍包含新风险、新变量或重大资源决策的内容。**

## 11. 修炼行为

普通修炼主要是：

> **时间投资 + 资源配置 + 少量关键决策。**

不把每次修炼做成重复小游戏。

玩家进行普通修炼时可以选择：

- 功法。
- 灵地 / 环境。
- 丹药或辅助资源。
- 修炼时长。
- 修炼侧重。

真正需要高强度决策的是：

- 瓶颈。
- 大境界突破。
- 功法冲突。
- 功法异变。
- 走火入魔。
- 特殊悟法。
- 天劫。
- 特殊传承。

## 12. 大境界

当前采用：

```text
凡人
→ 胎息
→ 炼气
→ 筑基
→ 紫府
→ 金丹
→ 元婴
→ 更高境界后续设计
```

每个大境界必须产生明显质变，而不是单纯增加数值。

质变可以包含：

- 寿元。
- 法力 / 神识 / 神魂能力边界。
- 可使用法术、神通和法宝层级。
- 环境生存能力。
- 资源需求。
- 身份与社会权力。
- 可以接触的修真秘密与事件层级。

## 13. 小境界

不同大境界允许拥有不同的内部成长结构，不要求全游戏统一“九层制”。

例如可以是：

```text
胎息 → 感气 / 纳气 / 周天
炼气 → 一至九层
筑基 → 初期 / 中期 / 后期
紫府 → 围绕紫府与神魂完善程度成长
```

具体结构后续按每个大境界的玩法意义设计。

## 14. 境界压制与越境

大境界之间存在明显压制。

正常情况下，低一大境界修士正面对抗高一大境界修士应极其困难。

但以下条件可以组合创造少数越境机会：

- 对方重伤、中毒、反噬。
- 阵法与地形。
- 克制功法 / 法宝。
- 多人围攻。
- 特殊时间窗口。
- 提前布置。
- 前世 Knowledge。

Knowledge 制造机会，而不是取消力量体系。

## 15. 灵根与资质

灵根不采用简单的“垃圾 / SSR”稀有度设计。

- **灵根**主要决定修炼适性、路线、兼容性和特殊可能性。
- **资质**可以表示学习、肉身、神魂、悟性等更细的潜力组合。

例如杂灵根可以修炼较慢但兼容路线更广；单灵根可以在单一路线成长更顺，但不代表无条件拥有最高最终强度。

## 16. 功法路线与功法隐患

功法不是数值装备，而是长期修炼路线。

功法可以影响：

- 修炼速度。
- 法术 / 神通方向。
- 战斗节奏。
- 身体、法力和神魂特征。
- 环境与资源需求。
- 大境界突破方式。
- 可形成的 Build。
- 风险、禁忌和反噬。

**功法允许存在未公开的隐患甚至人为设计的陷阱。**

例如一门功法可能修炼极快，却在筑基时留下控制印记；玩家第一世因此死亡或受制，获得 Knowledge 后，可以在下一世寻找破解、换功法、反向利用或把陷阱引向别人。

## 17. 修真势力与身份路线

正道、魔门、家族、散修组织等势力不按简单善恶划分，而按：

- 道统。
- 利益。
- 制度。
- 修炼伦理。
- 资源控制。
- 人物关系。

境界是社会权力的重要基础，但实际地位还受到传承、背景、派系、职务、战力、资源和关系影响。

加入一个势力是重大人生 / Build 决策，可以改变：

- 可获得功法。
- 修炼资源。
- 可接触 NPC。
- 敌对关系。
- 义务与限制。
- 地图权限。
- 突破路径。
- 人物事件。

正式游戏应允许出现散修、家族修士、正道宗门、魔门、小宗、大宗或特殊传承等不同人生路线，并允许叛门或改变阵营。

## 18. 世界观参考边界

世界观结构感参考：

- 《玄鉴仙族》：境界与资源有重量、势力与修真社会真实运转、高阶修士改变社会秩序。
- 《苟在初圣魔门当人材》：宗门内部也危险、功法和资源可能有代价、NPC 有利益算计、死亡产生下一世信息优势。

只参考结构和气质，不复制其具体人物、势力、剧情、独有功法或专有设定。
