# Steam 像素修仙 RPG 重设计状态

> 分支：`redesign/steam-pixel-rpg`
>
> 用途：记录当前重设计方向，避免旧移动端 / Web、多世回溯 Roguelite 与新的正统修仙人生模拟 RPG 混用。

## 当前最高优先级方向

产品形态已调整为：

> **Steam / Windows 优先的东方修仙人生模拟 RPG。**

玩家在真实像素地图中移动、探索、接触 NPC、修炼和战斗；世界时间持续推进，NPC、宗门、资源与事件不会等待玩家。玩家通过长期选择形成自己的修仙人生，并逐渐影响人物、宗门和地区格局。

当前产品决策以 `21-orthodox-cultivation-rpg-pivot.md` 为最高优先级。

## 已锁定

- 产品平台：Steam / Windows 优先。
- 引擎：Godot 4.7.x .NET + C# + .NET 8。
- 表现：pure 2D 东方修仙像素 RPG。
- 权威规则位于纯 C# Game Core；Godot Scene / Node 负责表现、输入和适配。
- 地图负责沉浸、空间选择、探索和战斗空间；Event Engine 负责结构化内容规则。
- 核心体验：修炼成长、探索、NPC、宗门社会、时间推进、情报调查、资源取舍、RTwP 战术战斗和长期后果。
- 战斗采用原地图 Combat State + 可暂停实时（RTwP），位置是战术资源，不以动作精准操作为核心。
- 境界是能力规则和社会层级的质变，不是简单等级增长。
- NPC / 世界事件不会等待玩家。
- 单机本地权威运行时。
- AI / Codex 自动开发与测试仍作为工程硬约束。

## 已移出当前产品方向

以下内容属于此前多世 Roguelite 历史方案，不再约束当前产品和架构：

- Anchor / 天衍锚点。
- 回溯次数。
- 死亡后开启下一世。
- 承世。
- 悟世。
- 跨世 Trait Library。
- 跨世 Knowledge。
- 多世唯一物时间线规则。
- 以多世回溯为核心的 World Fate / Meta Progression。
- “黑水三世”作为 V0.1 验收结构。

相关旧文档暂保留用于追溯设计历史，后续统一标记为历史或重写，不再作为当前实现依据。

## 继续保留的设计资产

此前 Grill 中以下方向继续有效：

- 游戏内时间与机会成本。
- 功法 / 术法 / 神通分层。
- 灵根、体质、资质路线差异。
- 气血 / 法力 / 神识等运行资源。
- 结构化伤势与长期后果。
- 宗门 / 家族 / 散修等修真社会结构。
- 核心 NPC 目标、利益、秘密和状态。
- 多维人物关系，但 UI 以描述性表达为主。
- 高阶修士形成真实政治威慑。
- 状态驱动轻量经济，不做全量社会仿真。
- 情报 / 见闻 / 调查系统保留原 Knowledge 中有价值的认知设计，但不再跨死亡继承。

## V0.1 当前方向

V0.1 调整为“一段连续修仙人生”的纵向切片，而不是三世回溯 Demo。

建议骨架：

```text
青玄宗外门生活
↓
发现黑水机会
↓
调查人物 / 情报
↓
有限时间与灵石下准备
↓
修炼 / Build / 购买资源
↓
黑水山与秘境探索
↓
RTwP 战斗与危险处理
↓
揭开一层隐藏真相
↓
获得成果并返回宗门
↓
NPC / 世界状态持续变化
```

V0.1 只需要证明：

> **探索、修炼、时间、NPC、资源、情报与战斗组合起来，能否形成一段真正有修仙人生感的小型 RPG。**
