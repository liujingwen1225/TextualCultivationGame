# 诸世问道：角色属性与成长已确认决策

> 状态：Matt `grill-with-docs` 进行中的阶段性决策记录。
>
> 用途：记录第 7 轮已确认的角色属性、资源、资质、寿元与境界成长方向；完整 Grill 结束后再归并到正式设计文档。

## 1. 一级资质保持少量

不采用传统 RPG 的力量 / 敏捷 / 智力 / 精神 / 体质 / 幸运六维作为修仙角色主框架。

角色的先天与长期资质主要围绕少量真正影响修仙规则的维度组织，例如：

- 根骨：肉身、气血、经脉承载与恢复倾向。
- 悟性：功法理解、术法参悟、突破理解与学习效率。
- 神魂：神识、精神抗性、神魂术法与感知潜力。
- 灵根：灵气适性、属性兼容与修炼路线。
- 特殊体质：独立于灵根的稀有身体 / 神魂规则特征。

攻击、防御、速度等战斗表现尽量由境界、功法、术法、法宝、伤势与当前状态派生，不再堆叠大量可自由加点的一阶属性。

## 2. 三类核心运行资源

气血、法力、神识是角色在战斗与冒险中的核心运行资源，而不是角色创建时自由加点的基础属性。

- 气血：肉身生命、行动与部分体修 / 血道手段的基础。
- 法力：施展术法、催动法宝、维持护体和阵法的主要资源。
- 神识：感知、锁定、控物、神魂手段与部分高阶战斗行为的基础。

不同功法、境界和 Build 可以改变三者的容量、恢复、转换关系和使用方式。

## 3. 灵根与特殊体质分离

灵根回答“如何感应、吸收、运转天地灵气以及更适合哪些修炼路线”。

特殊体质回答“角色身体或神魂本身具有什么特殊规则”。

二者可以同时存在，甚至互相冲突。例如火灵根与玄阴体可以同时成立，并产生独特修炼问题和路线。

特殊体质不采用人人都有一个高稀有度标签的设计，应保持相对稀少，并允许优势与代价并存。

## 4. 资质稳定但可被重大机缘改变

先天资质是相对稳定的角色基础，但不是绝对不可改变。

只有重大事件、特殊传承、高阶资源或显著代价才能造成结构性变化，例如：

- 洗髓改善根骨或经脉。
- 天材地宝改变身体适性。
- 特殊功法重塑肉身或神魂。
- 奇遇提升或损伤神魂。
- 严重伤势留下长期缺陷。
- 魔功以寿元、根基或其他代价交换资质改变。

普通升级不通过“每级加一点属性”持续修改这些资质。

## 5. 寿元是战略资源

寿元不是单纯角色界面的预计死亡年龄，而是可被规则真实消耗、增长或交换的特殊资源。

寿元可以受以下因素影响：

- 自然流逝。
- 大境界突破增长。
- 重伤、诅咒或根基损伤折寿。
- 秘术、血遁、魔功等主动燃寿。
- 极少数延寿丹药、灵物或传承。

因此玩家可以用寿元换取一次逃生、爆发、突破机会或其他重大收益，但这种代价必须具有长期意义。

## 6. 结构化伤势进入人生路线

伤势分为不同层级，不把所有伤害都简化为战斗结束后喝药回满。

典型结构：

- 普通伤势：较容易恢复。
- 重伤：需要大量时间、丹药或治疗资源。
- 经脉损伤：影响修炼、施法与突破。
- 根基损伤：影响长期成长、境界路线或突破条件。
- 神魂损伤：影响感知、神识、心智与神魂类能力。
- 永久残缺：极少数重大后果，需要特殊机缘才能修复或只能带着继续活。

一次战斗、突破或事件即使没有死亡，也可能彻底改变这一世的目标。玩家可能选择疗伤、换路线、带伤继续，甚至主动坐化重开下一世。

## 7. 精确资源与模糊世界判断并存

玩家需要精确掌握直接操作和规划所需的核心信息，例如：

- 当前气血。
- 当前法力。
- 当前寿元。
- 明确持有的资源与丹药数量。
- 修为积累。
- 已掌握术法的可见施法信息。

但世界判断、人物关系、突破危险和敌人强度不全部公开为精确百分比和数值。

例如更适合显示：

- 根基稳固 / 有损。
- 筑基准备不足 / 尚可 / 充分。
- 某 NPC 信任但有所保留。
- 对手气息明显强于自己。
- 毒势正在侵入经脉。

Knowledge、特殊术法、神识能力和调查可以提高这些信息的可靠度或精确度。

## 8. 大境界突破会新增规则层

大境界不是单纯数值膨胀。

每次重大突破都可以增加新的角色结构、能力边界和玩法层。例如：

- 炼气重点围绕经脉、法力和基础术法。
- 筑基形成道基、正式扩展神识与更高阶法宝 / 功法能力。
- 紫府进一步打开神魂、紫府与神通层面的玩法。

因此境界提升应让玩家逐渐接触新的规则，而不是重复同一套炼气玩法并不断提高 HP / 攻击力。

核心原则：

> **境界提升 = 进入新的修仙规则层，而不仅是获得更高数值。**
