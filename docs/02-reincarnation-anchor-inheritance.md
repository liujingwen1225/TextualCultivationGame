# 诸世问道：回溯、Anchor 与跨世继承

> 状态：Steam 像素 RPG 重设计当前有效基线

## 1. 设计目标

《诸世问道》的跨世系统由四层组成：

```text
Knowledge = 记得什么
词条 = 自身沉淀了什么
承世 = 这一世带走什么
Anchor = 下一世从哪个特殊检查点重新开始
```

核心原则：

> **Anchor 本质上是一个受玩法规则限制的完整 checkpoint 存档。复杂的是跨世叠加规则，而不是存档本身。**

## 2. 回溯次数

每个新世界固定拥有 **10 次回溯**。

- 初始第一世不消耗回溯。
- 每次角色死亡后成功开启下一世，回溯次数 -1。
- 主动坐化属于正式死亡。
- 保存退出、回到主菜单、关闭游戏不消耗回溯。
- 普通玩法不能稳定刷取或恢复回溯次数。

剩余回溯为 0 时，当前一世仍可以正常游玩；下一次死亡时当前 World 结束并生成世界总结。

## 3. Anchor = 特殊检查点存档

### 3.1 与普通 SaveGame 的区别

普通 SaveGame 用于：

- 保存退出。
- 恢复当前正在进行的人生。

Anchor 用于：

- 角色死亡后的回溯。
- 选择下一世从哪个人生阶段重新开始。

两者底层都可以保存完整世界状态，但 Anchor 有额外玩法约束：

- 只能在规则允许的时机建立。
- 建立后不可覆盖或修改。
- 每个大境界最多一个 Anchor。
- 只有死亡结算时才能作为跨世起点读取。

### 3.2 初始 Anchor

新 World 创建时自动生成初始 Anchor，并占用初始大境界的 Anchor 位。

例如：

```text
16 岁
炼气三层
青玄宗外门
初始背包
初始 NPC / 世界状态
```

### 3.3 大境界 Anchor

- 每个大境界最多一个。
- 玩家进入该大境界后，可以在尚未使用 Anchor 位时手动“定世”。
- 定世就是把当前完整世界状态保存为该境界专用 checkpoint。
- 建立后不可更新、不可覆盖。

因此“刚突破就定世”和“经营多年后再定世”会形成真实战略取舍。

### 3.4 多个 Anchor 可以同时保留

例如玩家已经建立：

```text
炼气 Anchor
筑基 Anchor
紫府 Anchor
```

从炼气 Anchor 重新开始后，旧的筑基 / 紫府 Anchor 仍然保留，因为它们只是其他已经保存好的 checkpoint 快照。

游戏不需要因此模拟多条并行时间线；当前只运行玩家这一次读取出来的人生。

## 4. Anchor 保存什么

Anchor 保存建立时完整的现实世界状态，包括但不限于：

- 当前世界时间。
- 玩家境界、修为、状态。
- 功法、术法掌握。
- 装备、法宝、物品。
- NPC 状态、生死、位置、关系。
- 玩家身份。
- 势力状态。
- 资源归属。
- Event Chain 状态。
- 地图 / 地点变化。
- 市场和地区状态。

不直接属于 Anchor 快照的跨世状态：

- Knowledge。
- Trait Library。
- 剩余回溯次数。
- 本次承世结果。

这些在读取 Anchor 后由跨世层额外叠加。

## 5. 死亡与下一世创建

标准流程：

```text
角色死亡
↓
冻结本世状态
↓
生成一世事实与评价
↓
更新 Knowledge / 历史
↓
选择下一世 Anchor
↓
承世 OR 悟世
↓
选择下一世 Trait
↓
消耗 1 次回溯
↓
读取 Anchor checkpoint
↓
叠加 Knowledge / Trait / 承世结果 / 回溯次数
↓
开始下一世
```

如果死亡时回溯次数已经为 0，则不再创建下一世，直接进入 World 终局总结。

## 6. 承世

### 6.1 基本规则

死亡时，从本世仍合法持有或掌握的成果中选择一项，直接带入紧接着的下一世。

允许类型可以包括：

- 一门功法的实际掌握成果。
- 一门术法的实际掌握成果。
- 法宝。
- 装备。
- 丹药。
- 特殊材料。
- 其他明确允许的单项成果。

绝对禁止：

- 境界。
- 修为。
- 筑基道基、紫府、金丹等大境界本体结构。
- 由高境界直接派生的基础能力层级。

### 6.2 必须死亡时仍拥有

曾经得到、但死亡前已经被消耗、夺走、赠予、销毁或失去合法掌握资格的成果，不进入本次承世候选。

### 6.3 高阶成果回到低境界

允许带回，但仍受当前境界、肉身、法力和使用条件限制。

承世可以让玩家提前拥有“成果本身”，但不能让炼气角色直接获得紫府级生命层次。

### 6.4 承世只持续到紧接着的下一世

承世不是永久 Meta 背包。

如果下一世死亡后选择一个不包含该成果的旧 Anchor，该成果不会自动继续存在。

继续保留通常只能：

- 再次选择该成果承世；或
- 活到后续 Anchor 建立时，把它自然保存进新的 checkpoint。

### 6.5 一次一个成果单位

- 功法 / 术法：一门。
- 法宝 / 装备：一个对象。
- 可堆叠消耗品：按单独数量上限。
- 容器不能通过套娃一次携带整个背包。

## 7. 悟世与 Trait

选择悟世时，放弃本次承世，根据这一世真实经历生成最多 3 个 Trait 候选并选择一个。

没有足够人生经历时允许没有候选，因此“出生后立即坐化”不会稳定刷能力。

Trait：

- 进入当前 World 的 Trait Library。
- 跨 Anchor 保留。
- 每世开始前最多装备 5 个。
- 一世中不能随意切换。
- 新 World 创建时全部清空。

Trait 优先提供：

```text
信息能力 / 特殊选项 / 条件性规则变化
>
纯百分比数值加成
```

高境界经历形成的 Trait 可以拥有境界门槛或分阶段效果。

## 8. Knowledge

Knowledge 是跨世保留的可行动认知，而不是当前身体与现实状态。

Knowledge 可以记录：

- 人物秘密。
- 事件时间。
- 危险规律。
- 资源位置。
- 功法隐患。
- 战斗弱点。
- 突破经验。
- 世界关系与推论。

世界线变化后不删除旧 Knowledge，而重新评估其适用性，例如：

- 仍可信。
- 可能变化。
- 已改变。
- 已失效。
- 存在矛盾。

Knowledge 记录的是“我知道什么”，不是“我当前已经练会什么”。

## 9. 唯一物与 checkpoint

唯一物不需要再解释成跨所有 Anchor 共享的一套神秘世界实体状态。

每个唯一物拥有稳定 `UniqueId`，并遵守当前活动人生去重规则：

- 当前活动人生中同一 `UniqueId` 最多存在一份。
- 如果承世将某唯一物带回其原获取时间之前，则该人生中原获取点不能再次产生第二份。
- 如果所选 Anchor 已经包含同一个 `UniqueId`，则跨世叠加时不重复生成。
- 未被读取的其他 Anchor 仍然只是独立 checkpoint 快照，不需要被追溯修改。

这样即可防止复制漏洞，同时保持存档模型简单。

## 10. 地图重走与 Knowledge

重复人生不应该要求玩家机械重走已解决内容。

Knowledge / 熟悉状态可以支持：

- 已发现安全地点快速旅行。
- 已解决低风险事件快捷处理。
- 前世路线摘要。
- 已知危险提示。
- 关键 NPC / 地点的前世记忆标记。

但资源、时间、关系和高风险决策仍必须由玩家重新做出选择。

## 11. 一世与世界总结

一世评价由规则事实驱动，包括持续时间、成长、主要事件、人物关系、重要成果与死亡原因。AI 可以润色文字，但不能决定事实。

World 最终结束后生成世界总结，包括经历世数、Anchor、最高境界、重要人物命运、已解秘密、世界大势与未竟事项。

## 12. 最终定义

Anchor 以后统一理解为：

> **多世玩法专用的特殊存档点。**

它可以有“天衍锚点”“定世”等世界观包装，但设计、实现和测试都按 checkpoint 处理，不再引入额外的超时空数据模型。
