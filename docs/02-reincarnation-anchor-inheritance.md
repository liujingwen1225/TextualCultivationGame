# 诸世问道：回溯、Anchor 与跨世继承

> 状态：当前有效基线

## 1. 设计目标

本系统参考“百世书式”死亡继承的核心取舍，但不照搬原作结构。

《诸世问道》的独特机制由四层组成：

```text
Knowledge = 记得什么
词条 = 自身沉淀了什么
承世 = 这一世带走什么
Anchor = 下一世从人生哪里重新开始
```

四者必须保持边界清晰。

## 2. 回溯次数

### 2.1 基础额度

每个新世界固定拥有 10 次基础回溯。

- 初始第一世不消耗回溯。
- 每次角色死亡后成功进入下一世，回溯次数 -1。
- 因此 10 次回溯理论上允许初始人生 + 10 次重来。
- 角色主动坐化也属于死亡。

### 2.2 0 次状态

剩余回溯为 0 时，当前一世仍可继续游玩。

下一次死亡时：

```text
账号有付费回溯额度
→ 消耗 1
→ 正常进入死亡结算 / 下一世

账号无付费额度
→ 购买
或
→ 结束当前世界并新开游戏
```

### 2.3 付费回溯

- 付费额度属于账号，不属于某个世界。
- 未消耗额度可带到新世界。
- 基础回溯优先消耗。
- 当前设计不限制累计购买总量。
- V0.1 只提供 DEV 增加额度，不接真实支付。

## 3. 天衍锚点

### 3.1 初始 Anchor

新世界创建时自动生成初始 Anchor，并占用初始大境界的唯一 Anchor 位。

例如：

```text
16 岁
炼气三层
初始宗门身份
初始背包
初始 NPC 状态
```

该 Anchor 永久不可修改。

### 3.2 大境界 Anchor

- 每个大境界最多一个。
- 除初始大境界外，玩家进入并稳定处于该大境界后，可在任意时点手动“定世”。
- 定世时完整固化当前现实状态。
- 建立后不可更新、不可覆盖。

例如：

```text
炼气 Anchor A（自动）
筑基 Anchor B（手动）
金丹 Anchor C（手动）
元婴 Anchor D（手动）
```

### 3.3 Anchor 永久可选

已经建立的 Anchor 不会因之后的世界线变化失效。

即使玩家：

```text
从金丹 C 死亡
→ 回炼气 A
→ 使用后来获得的高阶功法
→ 走出不同筑基路线
```

旧的筑基 B 和金丹 C 依然可选。

这意味着 Anchor 不是线性历史存档，而是玩家已经固定下来的“人生坐标”。

## 4. 死亡结算顺序

固定流程：

```text
角色死亡
  ↓
生成一世事实摘要
  ↓
生成一世评价
  ↓
更新 Knowledge / 历史记录
  ↓
选择下一世 Anchor
  ↓
显示该 Anchor 下的承世价值
  ↓
承世 OR 悟世
  ↓
消耗回溯额度
  ↓
选择下一世装备词条（最多 5）
  ↓
创建下一世
```

如果没有可用回溯额度，则先解决付费补充 / 新世界选择。

## 5. 承世

### 5.1 基本规则

死亡时从本世合法持有或掌握的成果中选择一项，带入紧接着的下一世。

允许类型：

- 功法。
- 法宝。
- 装备。
- 丹药。
- 普通物品。
- 后续设计明确允许的其他成果。

禁止类型：

- 当前境界。
- 当前修为。

### 5.2 必须死亡时仍拥有

以下情况不能承世：

- 曾经拥有但已经被夺走。
- 已经消耗。
- 已经赠送。
- 已被销毁。
- 当前已不再合法掌握。

### 5.3 跨境界使用

高境界成果允许带回低境界 Anchor。

但“带回来”不等于“立即可完整使用”。

例如金丹功法可能要求：

- 筑基神识。
- 特定灵根。
- 特定资源。
- 特定身体强度。

高阶丹药也可能因药力过强造成危险。

因此高阶成果主要提供：

- 提前规划。
- 提前参悟。
- 解锁隐藏选项。
- 改变资源路线。
- 满足条件后提前取得优势。

### 5.4 承世不是永久 Meta

承世只把成果带入“下一世”。

若下一世再次死亡并回到一个不包含该成果的旧 Anchor，成果不会自动存在。

要继续持有，需要：

- 再次把它作为承世对象；或
- 在本世活到新的大境界并将其固化进尚未建立的 Anchor。

### 5.5 一个成果单位

一次只能承世一个成果单位：

- 功法：一门。
- 法宝/装备：一个完整对象。
- 可堆叠消耗品：按独立承世数量上限。
- 容器不能通过套娃一次带走整个背包。

普通非唯一物允许通过多世人生形成跨世套利。

## 6. 悟世与词条

### 6.1 悟世

选择悟世时放弃本次实体承世，根据这一世真实经历产生最多 3 个词条候选，从中选择一个。

没有足够人生经历时，可以没有候选。

因此：

```text
出生 → 立即坐化
```

通常只会浪费一次回溯，而不是刷出永久天赋。

### 6.2 词条形成

候选来自规则评分，不是抽卡。

输入可包括：

- 某类行为持续时间。
- 战斗次数与关键战斗。
- 炼丹、炼器、剑道等专业行为。
- 重大选择。
- 特殊事件。
- NPC 人际轨迹。
- 大境界突破。
- 死亡原因。
- 成就与极端经历。

满足条件的候选按“这一世代表性”排序，最多取 3 个。

### 6.3 词条库与装备槽

- 当前世界获得的词条永久进入词条库。
- 跨 Anchor 不丢失。
- 每一世开始前最多装备 5 个。
- 未装备词条保留，但本世不生效。
- 真正新世界全部清空。

### 6.4 词条升级

同源词条允许升级，例如：

```text
丹心
→ 丹心·通明
→ 丹道宗师
```

升级：

- 仍然占用一次完整悟世选择。
- 不自动发生。
- 高阶版本替换低阶版本。
- 同一进阶链始终只占一个槽位。
- 重点提升规则能力、信息和事件选项，数值增益为辅。

## 7. Knowledge

Knowledge 是玩家跨世保留的“记忆”，不是角色当前世界状态。

例如：

```text
赵长青计划在 138 年毒杀陈长老
某遗迹第三层存在杀阵
某秘境入口在雨夜出现
```

Knowledge 跨所有 Anchor 保留。

世界线改变后，不删除记忆，而改变适用性：

- 仍可信。
- 可能变化。
- 已失效。
- 与后来信息矛盾。

例如赵长青提前被逐出宗门后，“138 年毒杀”仍是玩家真实经历过的未来记忆，但当前适用状态变为已失效。

独立 Insight 系统取消，能力沉淀由词条负责。

## 8. 唯一物

唯一物使用当前世界级唯一身份。

```text
uniqueEntityId = QINGMING_SWORD
```

一旦通过承世改变命运：

- 原未来获取路径不能生成第二份。
- 切换到一个不包含它的旧 Anchor，也不会恢复原掉落。
- 如果后来没有继续承世，也没有固化进 Anchor，该唯一物可以永久丢失。

这是唯一物应有的决策重量，不提供无风险试错。

## 9. 一世评价

评价由事实驱动。

规则系统负责生成：

- 一世持续时间。
- 境界变化。
- 关键成就。
- 主要职业/道路标签。
- 核心人物关系变化。
- 重大事件。
- 失败与死亡原因。
- 词条候选及原因。

AI 可以把这些事实润色成人生评语，但不能修改事实，也不能决定词条资格。
