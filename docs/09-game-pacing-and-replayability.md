# 诸世问道：游玩节奏与长期可玩性原则

> 状态：当前有效决策 V0.1  
> 本文覆盖此前关于“首次筑基 15～30 小时”等过长固定时长建议。`04-character-cultivation-system.md` 中的具体小时数仅视为旧版讨论参数，不再作为实现目标。

---

# 1. 最新决策

长期可玩性**不靠故意拖慢升级**。

核心应为：

```text
适中的修炼成长
+
高密度随机事件
+
条件事件
+
连锁事件
+
NPC人物线
+
奇遇
+
秘境
+
前世知识
+
世界线变化
```

玩家留下来，是因为：

> “这一世又会发生什么？”

而不是：

> “还要再点多少次修炼才能升级？”

---

# 2. 境界成长原则

## 2.1 不能太快

境界仍然必须有分量。

不应该：

```text
进入游戏
20分钟
→ 炼气九层
→ 筑基
```

玩家需要经历：

- 多次修炼
- 小瓶颈
- NPC事件
- 资源选择
- 历练
- 风险
- 至少若干随机/条件事件

才能完成一个阶段。

## 2.2 也不能太慢

不再以“首次筑基 15～30 小时”为目标。

正式数值由试玩决定，原则是：

> 一个小境界的成长过程中，应有明显事件和选择，但不能让玩家感觉自己长时间停在同一进度条上。

境界是内容阶段，不是时长墙。

---

# 3. 长期游玩的主要来源

优先级建议：

```text
随机/条件事件差异
>
人物与事件链差异
>
前世 Knowledge 改变路线
>
不同功法/资源/秘境路线
>
数值成长本身
```

因此内容投入也应优先事件，而不是优先设计巨大的升级数值曲线。

---

# 4. 单世节奏

一世不应该是几个小时连续无中断的大流程。

推荐以“短决策循环”组成：

```text
选择行动
↓
时间推进
↓
获得修炼/资源反馈
↓
随机或条件事件
↓
做出选择
↓
状态改变
↓
继续规划
```

理想状态：

- 玩家几分钟内能完成多个有意义决策。
- 连续多次纯修炼后应有事件反馈。
- 闭关可以一次推进较长游戏时间，但不能让现实操作变成等待。
- 玩家随时可以暂停并下次继续。

---

# 5. 内容密度目标

不硬锁实际分钟数，先锁“行动密度”。

首轮建议：

- 连续 2～4 个主要行动后，应大概率出现至少一次有意义变化。
- 最多连续 5 个主要行动没有交互内容时，事件系统应进行保护。
- 每一次小境界期间，至少经历若干事件，而不是纯闭关通过。
- 一次主要事件链应横跨多个行动，必要时横跨多个游戏年份或多世。

---

# 6. 随机事件支撑重复游玩

同一个玩家重新经历炼气阶段时：

世界骨架相同：

- 青玄宗仍在
- 黑水秘境仍会开启
- 关键 NPC 仍存在

但经历不同：

```text
第一世
外门竞争 + 黑水秘境 + 丹阁异常

第二世
师徒事件 + 坊市散修 + 黑水秘境

第三世
韩石命运线 + 魔宗线索 + 古修奇遇
```

这样前世既有“熟悉感”，又不会完全重复。

---

# 7. 固定内容和随机内容比例

初步内容投入建议：

| 内容类型 | 比例参考 |
|---|---:|
| 日常随机/条件事件 | 40%～50% |
| 人物与连锁事件 | 25%～30% |
| 固定世界事件/主干 | 10%～15% |
| 奇遇/稀有事件 | 10%～15% |
| 前世特殊变化 | 融入以上所有类型 |

这不是运行时触发概率，而是内容生产投入比例。

---

# 8. 前世知识负责减少重复

重复游玩最大的危险是：

> 每一世重新做同一套流程。

解决方式不是简单倍速，而是 Knowledge 改变玩法。

例如：

第一世：

```text
不知道解毒丹重要
→ 被赵长青下毒
→ 死亡
```

第二世：

```text
已知下毒
→ 提前买解毒丹
→ 进入新事件
```

第三世：

```text
已知洞府杀阵
→ 提前学习阵法
→ 进入更深区域
```

因此同一境界可以重复，但目标和决策不断向前。

---

# 9. 已掌握内容可快速处理

玩家多世重复遇到低价值内容时，应逐渐提供：

```text
★【轻车熟路】快速处理
```

例如：

- 入门杂务
- 已解决过多次的普通修炼问题
- 已知答案的小谜题
- 低风险重复任务

快速处理不能覆盖：

- 世界线已经偏移后的事件
- 高风险事件
- 新变体
- 核心选择

---

# 10. 升级过程本身也要随机

随机事件不只是“修炼之外”的内容。

修炼过程中也存在事件池：

- 灵气波动
- 经脉异常
- 功法顿悟
- 师长指点
- 同门打扰
- 灵地争夺
- 心境问题
- 功法缺陷

所以“闭关”不是纯数值按钮。

---

# 11. 瓶颈作为事件入口

瓶颈仍然保留，但目的改变。

瓶颈不是：

> 让玩家再刷 100 次修炼。

而是：

> 把玩家推入新的事件和路线。

例如：

```text
炼气六层瓶颈
↓
继续闭关收益下降
↓
可选择：
- 找师父请教
- 去藏经阁研究
- 接历练任务
- 买辅助丹药
- 冒险进入后山
```

不同选择进入不同事件池。

---

# 12. 奇遇负责制造“这一世特别”

稀有奇遇不能成为基础升级必需品。

它们主要负责：

- 开新路线
- 新功法
- 新 NPC
- 新秘密
- 特殊道基
- 高风险选择

玩家应能正常筑基而不依赖中彩票。

但奇遇可以让这一世的筑基方式完全不同。

---

# 13. 正式时长暂不硬编码

当前阶段不再规定：

- 首次筑基必须 X 小时
- 一个小境界必须 Y 分钟
- 一世必须 Z 分钟

这些必须通过可玩原型数据确定。

后续记录：

- 每个小境界实际耗时
- 每小时有效事件数
- 玩家连续修炼次数
- 玩家觉得重复的节点
- 一世平均事件数量
- 回溯后重复内容比例
- 奇遇触发体验

再决定正式数值。

---

# 14. 评价标准

如果玩家反馈：

> “升级太快，没有修仙成长感。”

增加：

- 阶段内容
- 资源准备
- 瓶颈事件

而不是简单把经验需求乘 10。

如果玩家反馈：

> “升级太慢，很无聊。”

优先检查：

- 是否事件密度太低
- 是否重复内容过多
- 是否修炼选择太少
- 是否瓶颈只有等待

而不是直接加永久经验倍率。

---

# 15. 当前最终结论

《诸世问道》的长期感来自：

```text
我修得越来越高
+
我见过越来越多事情
+
我越来越了解这些人
+
我知道越来越多未来
+
但我改变得越多，未来又越来越陌生
```

而不是：

```text
经验条越来越长
```

因此当前开发优先级是：

> **先把事件系统做到“重复修仙仍然有新鲜经历”，再用试玩决定境界速度。**
