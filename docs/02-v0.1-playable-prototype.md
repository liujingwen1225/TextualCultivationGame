# V0.1 可玩原型范围与验收

> 状态：V0.2  
> 目的：只验证《诸世问道》最核心的“前世知识改变下一世”是否真正好玩，不用原型速度代表正式成长速度。

---

# 1. V0.1 唯一目标

玩家在第一次体验中至少完成：

```text
第一世未知未来
↓
正常修炼与探索
↓
遭遇核心事件
↓
因缺少情报/准备失败或死亡
↓
诸世结算
↓
获得明确 Knowledge / Insight
↓
回到锚点
↓
再次抵达相关事件
↓
出现 ★ 前世记忆选项
↓
改变结果
↓
抵达此前未见过的未来
```

只要玩家产生“我还想再推演一世”的动力，V0.1 即完成核心验证。

**V0.1 不要求玩家筑基。**

正式游戏第一次筑基是长期目标，预计需要多轮推演和十几至几十小时有效游玩；原型不能为了演示而把正式平衡做成快速升级。

---

# 2. 平衡配置

项目必须从一开始支持两套 Balance Profile。

## DEVELOPMENT

用于开发、自动化测试和快速演示：

- 修炼速度大幅提高
- 时间门槛缩短
- 可快速触发事件
- 可快速测试死亡/结算/回溯

## STANDARD

正式玩家使用：

- 境界成长缓慢
- 时间和寿元是真实资源
- 瓶颈、资源、关系和事件共同决定成长
- 不能通过连续点击闭关快速跨境界

测试数据不得反向污染正式设计。

# 5. 原型修炼范围

V0.1 只需要完整实现：

```text
炼气三层
→ 修为积累
→ 一个真实小瓶颈
→ 炼气四层
```

可以预置炼气五层以上规则供测试，但不作为首次可玩原型内容目标。

原型要验证的不是“升级爽不爽”，而是：

> 第一世解决一个瓶颈很慢或失败，第二世因为 Insight / Knowledge 能更聪明、更快地处理同一问题。

筑基系统仍保留在总体设计中，但放到后续正式里程碑。

# 10. V0.1 核心三世事件链

黑水事件链用于证明“知识改变未来”。

## 第一世：不知道危险

```text
进入黑水山脉
↓
与赵长青同行
↓
发现古修洞府入口
↓
接受赵长青提供的丹药/饮水
↓
中毒
↓
重伤或死亡
```

结算：

```text
KNOWLEDGE_ZHAO_POISON
赵长青会在古修洞府附近下毒。
```

## 第二世：知道赵长青

出现：

```text
★【前世记忆】提前准备解毒丹
★【前世记忆】拒绝赵长青的东西
```

玩家避开第一次死亡后，进入新的深层事件。

例如发现洞府禁制并死亡/失败。

结算：

```text
KNOWLEDGE_CAVE_ARRAY
洞府内存在致命阵法。
```

## 第三世：准备阵法手段

玩家提前：

- 去藏经阁学习《基础阵解》
- 获取破阵符
- 结交能提供线索的 NPC

事件出现：

```text
★【前世记忆】寻找上一世发现的阵眼
```

成功进入过去未见区域。

原型可以在这里结束，不需要让玩家立即得到筑基或顶级传承。

奖励可以是：

- 新 Knowledge
- 一段古修残卷
- 新地点线索
- 新功法线索

让玩家明确感受到“更深的未来还存在”。

# 11. 原型中的成长节奏

即使是原型，也不要设计成点击几次就升级。

正式 `STANDARD` 配置下：

- 炼气三层 → 四层应需要多个游戏内月度决策。
- 玩家需要在修炼、宗门任务、资源准备、事件机会之间取舍。
- 黑水秘境是一次重要机会，不是日常副本。

演示时若需要缩短体验，使用 DEVELOPMENT 配置，而不是修改规则。

---

# 12. V0.1 必须验证的机制

| 机制 | 验证目标 |
|---|---|
| 时间 | 行动会真实消耗人生 |
| 修炼 | 成长缓慢但有反馈 |
| 瓶颈 | 升级不只是填满修为条 |
| 事件 | 选择改变状态 |
| Knowledge | 前世获得的具体未来信息 |
| Insight | 前世积累的理解/经验 |
| 死亡 | 能结束一世并进入结算 |
| 回溯 | Run 物质状态恢复到 Anchor |
| 前世选项 | Knowledge 解锁新决策 |
| 新未来 | 玩家真的能越过过去死亡点 |

# 14. 原型验收场景

必须能够稳定复现以下测试：

### Case A：普通成长

```text
炼气三层
→ 修炼/任务
→ 修为达到瓶颈
→ 解决瓶颈
→ 炼气四层
```

### Case B：第一世死亡

```text
未知赵长青风险
→ 中毒
→ 死亡
→ Knowledge 入 Meta
```

### Case C：回溯隔离

死亡后：

- 境界恢复到 Anchor
- 灵石恢复到 Anchor
- 物品恢复到 Anchor
- NPC 世界状态恢复到 Anchor
- Knowledge 保留
- 诸世录保留

### Case D：第二世改命

```text
Knowledge_Zhao_Poison 存在
→ 解锁 ★ 前世选项
→ 避开第一次死亡
→ 进入新事件
```

### Case E：Insight 追赶

第一世解决过炼气瓶颈后死亡。

第二世相同瓶颈：

- 所需时间更短，或
- 出现更优解决选项。

### Case F：重复收益递减

反复用完全相同方式死亡，不允许无限刷 Knowledge/Insight。

---

# 15. 成功标准

V0.1 成功不是“内容很多”，而是测试玩家能够明确说出：

> “第一次我不知道所以死了；第二次我知道该准备什么，于是进入了之前看不到的内容。”

并且同时认为：

> “修仙成长需要长期规划，我想继续把这个角色推得更远。”

这两个条件同时成立，才进入下一阶段。
