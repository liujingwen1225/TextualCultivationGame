# V0.1 可玩原型范围与验收

> 目的：只验证《诸世问道》最核心的“前世知识改变下一世”是否真正好玩。

---

# 1. V0.1 唯一目标

玩家在 15–30 分钟内至少完成：

```text
第一世未知未来
↓
遭遇核心事件
↓
因错误选择/缺少情报死亡
↓
诸世结算
↓
获得一条明确前世知识
↓
回到锚点
↓
再次推进到同类事件
↓
出现 ★ 前世记忆选项
↓
改变结果
↓
进入新的事件分支
```

只要这个循环让玩家想继续第三世，V0.1 就算成功。

# 4. V0.1 角色成长

只实现：

- 炼气三层 → 炼气九层
- 炼气九层 → 筑基初期

不做：

- 筑基中后期
- 金丹
- 炼体独立境界
- 神魂独立境界

玩家应能通过不同路线获得筑基资格，但第一版只需要 2 种筑基方案：

1. 宗门正统筑基。
2. 黑水秘境特殊筑基机缘。

# 9. V0.1 核心事件链

## 9.1 宗门入门/日常线

作用：教学。

玩家学会：

- 时间推进
- 修炼
- NPC
- 物品
- 条件事件

## 9.2 黑水秘境主链

这是首版真正核心。

### 第一层认知

玩家不知道赵长青有恶意。

典型结果：

```text
与赵长青合作
↓
深入洞府
↓
被下毒
↓
死亡
```

结算获得：

```text
KNOWLEDGE_ZHAO_POISON
赵长青会在古修洞府中下毒。
```

### 第二层认知

下一世出现：

```text
★【前世记忆】提前准备解毒丹
```

玩家成功识破下毒后进入第三层。

遭遇杀阵死亡。

获得：

```text
KNOWLEDGE_CAVE_KILLING_FORMATION
古修洞府第三层存在杀阵。
```

### 第三层认知

下一世可提前：

```text
学习《基础阵解》
或准备破阵符
```

最终：

```text
破解杀阵
↓
获得古修筑基传承
↓
开启特殊筑基路线
```

此链必须是 V0.1 最完整、最好玩的部分。

# 12. 回溯

V0.1：

- 只有一个锚点。
- 死亡自动回到锚点。
- 不做任意 Save/Load。
- 不允许回溯保留普通物品、灵石和境界。
- 前世知识永久进入 Meta State。
- 功法理解只保留一部分。

主动结束模拟可以后置。

---

# 13. 世界线改变

首版不做全局偏移数值系统。

只需要实现：

```text
关键事件被改变
→ 标记关联未来情报为 stale/invalid
→ 后续走新的事件链
```

例如玩家提前揭露赵长青：

- 原本“赵长青洞府下毒”的未来不再发生。
- 赵长青可能提前逃离宗门。
- 后续秘境事件需要进入另一分支。

这样已经足够验证“未来会改变”。

# 15. V0.1 验收场景

## 场景 A：时间与修炼

1. 玩家点击修炼。
2. 时间增加 3 天。
3. 修为增加。
4. 满足条件后可以突破炼气小层级。

通过条件：状态一致，无时间错乱。

## 场景 B：条件事件

1. 当前时间达到秘境开放窗口。
2. 玩家境界满足条件。
3. 系统触发秘境资格事件。

通过条件：不满足条件时绝不错误触发。

## 场景 C：第一次死亡

1. 玩家不知道赵长青秘密。
2. 选择同行。
3. 被下毒死亡。
4. 进入诸世结算。
5. 获取对应 Knowledge。

通过条件：Knowledge 进入 Meta State。

## 场景 D：回溯

1. 完成结算。
2. 返回锚点。
3. 角色年龄、境界、物品恢复。
4. Knowledge 仍然存在。

通过条件：Run State 与 Meta State 无串数据。

## 场景 E：前世选项

1. 再次进入同一事件。
2. 因存在对应 Knowledge，出现 ★ 前世记忆选项。
3. 未获得知识的玩家不可见该选项。

通过条件：选择能进入不同结果。

## 场景 F：改变未来

1. 玩家使用前世知识改变关键事件。
2. 原有未来分支失效。
3. 进入此前不可访问的新分支。

通过条件：不是简单文本变化，而是真实事件链状态发生变化。

# 16. 原型失败判定

出现以下情况时，不应继续堆外围系统：

- 玩家第一次死亡后不想再来一次。
- 前世知识只是答案提示，没有新的玩法选择。
- 第二世体验与第一世高度重复。
- 玩家无法理解什么跨世保留、什么不会保留。
- 修炼占据大量点击，但没有决策。
- 时间/寿元没有形成任何压力。

应优先重做核心循环，而不是增加炼丹、炼器、地图和 AI 对话。

---

# 17. V0.1 完成定义

V0.1 不是“功能很多”，而是以下一句话成为真实可玩体验：

> 我上一世因为不知道真相而死；这一世我知道了，所以我可以做出以前根本没有的选择。
