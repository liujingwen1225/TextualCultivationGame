# V0.1 连续人生纵切

## 1. 唯一验收目标

V0.1 不验证多世回溯，也不验证完整境界体系。

它只回答一个问题：

> **“作为一个炼气期修士，在这个世界里探索、修炼、调查、准备、战斗并承担后果，本身是否好玩？”**

## 2. 纵切主题

固定主角：

```text
姓名：沈川
年龄：16
身份：青玄宗外门弟子
境界：炼气三层
```

连续体验：

```text
青玄宗外门
↓
日常修炼 / 人物接触
↓
发现黑水机会
↓
调查情报
↓
青石坊市准备
↓
黑水山探索
↓
RTwP 战斗
↓
黑水秘境
↓
揭开一层隐藏真相
↓
取得成果
↓
返回宗门
↓
人物 / 资源 / 世界状态持续改变
```

整个 V0.1 是一段连续人生，不要求玩家按脚本死亡。

## 3. 地图范围

```text
青玄宗
├─ 外门生活区
├─ 修炼点
├─ 丹阁 / 资源服务点
└─ 关键 NPC 交互点

青石坊市
├─ 常规商铺 / 摊位
├─ 丹药 / 符箓 / 装备购买
└─ 情报 / 人物事件点

黑水山
├─ 山道
├─ 危险区域
├─ 调查点
└─ 秘境入口

黑水秘境
├─ 外围危险
├─ 核心战斗 / 阵法区域
└─ 隐藏真相与成果点
```

不追求面积，追求每个地点都有清晰玩法意义。

## 4. NPC 范围

3～5 个真正重要 NPC 即可。

至少包括：

- 一名与黑水事件直接相关的同门，例如赵长青。
- 一名宗门资源 / 丹药相关人物。
- 一名能够提供不同利益立场的人物。
- 可选：坊市商人 / 情报人物。

重要 NPC 至少验证：

- 时间段位置变化。
- 目标与当前状态。
- 基础关系变化。
- 不同情报 / 身份下的对话与行动差异。
- 玩家错过时间窗口后 NPC 会继续行动。

## 5. 黑水事件结构

黑水事件不再采用“第一世毒死、第二世阵死、第三世破局”的强制多世结构。

改为一条可调查、可失败、可绕行、可准备的事件链。

示意：

```text
表面：
赵长青邀沈川参与黑水相关机会，并出现一批看似正常的灵酒 / 丹药 / 资源。

调查层：
玩家可以直接接受，也可以检查来源、询问丹阁、跟踪人物、在坊市寻找替代资源。

隐藏层：
某批资源存在人为问题，背后涉及外门弟子、丹阁或某个利益关系。

秘境层：
即使避开前期风险，黑水内部仍有独立的阵法、环境和敌人问题。
```

V0.1 只需要揭开一层可信的隐藏真相，不需要搭建完整宗门阴谋。

## 6. 时间与机会

至少存在一个明确时间窗口，例如：

- 黑水秘境若干日后开放。
- 某 NPC 某日离开宗门。
- 某商人只在特定时间出现。

玩家修炼、疗伤、旅行都会消耗时间，因此无法完成所有准备。

## 7. 修炼验证

V0.1 保持轻量：

- 沈川固定炼气三层开局。
- 可进行基础修炼行为，消耗天数并增加修为。
- 至少有两种不同的准备取向，例如更偏修炼 / 更偏调查 / 更偏购买资源。
- 不实现完整筑基。
- 可以通过 NPC、情报或场景展示筑基修士与筑基资源，让世界显得比 V0.1 更大。

## 8. 资源取舍

必须验证“知道问题不等于买得起所有答案”。

例如：

```text
沈川可用灵石：120

解毒丹：45
破阵符：70
疗伤丹：30
更好武器：90
```

玩家不能一次买齐全部准备，需要根据情报做选择。

数值仅为示意，后续平衡。

## 9. 战斗验证

直接使用正式目标制式：

```text
当前地图 Combat State
+ RTwP
+ 暂停下令
+ 位置 / 距离
+ 动作时间
+ 术法
+ 法宝 / 消耗品
+ 伤势
+ 逃跑
```

内容上限：

- 3 种左右普通敌人。
- 1 个关键精英 / 修士战。
- 4～6 个主角战斗能力。
- 1～2 件有主动意义的法宝 / 装备。
- 少量丹药 / 符箓。

不做盟友复杂微操。

## 10. 情报验证

至少验证：

- 从 NPC、调查点或事件中获得情报。
- 情报改变后续对话、准备或战斗选择。
- 至少有一条“传闻 / 推断 / 验证”的信息演进。
- 情报不会自动公布完整答案。

示例：

```text
观察：喝下某批灵酒后出现异常症状
↓
调查：灵酒来自特定来源
↓
验证：发现其中确有异常材料
↓
行动：换药、避开、调包、拿证据交换利益
```

## 11. 后果验证

V0.1 结束时必须能看到持续后果，而不是副本结算后世界复原：

- NPC 关系变化。
- 某角色是否受伤 / 离开 / 获益。
- 黑水事件状态变化。
- 玩家资源与伤势保留。
- 获得的功法 / 物品 / 情报继续存在。
- 返回宗门后开放新的对话或机会。

## 12. Save / Load

使用普通单机 SaveGame：

- 手动保存。
- 关键节点自动保存。
- 退出并重新启动后恢复。
- 死亡后读取最近合法存档 / 检查点。

Save/Load 不触发任何多世、Anchor、Knowledge Meta 或继承规则。

## 13. 自动化测试

至少建立：

```text
L1 Pure C# Game Core Unit Tests
L2 Blackwater Continuous-Life Scenario Test
L3 Godot Headless Runtime Integration
L4 Visual / Input Smoke Test
```

L2 不启动正式画面，也能执行：

```text
开局
→ 获取机会
→ 调查
→ 修炼 / 购买准备
→ 进入黑水
→ 战斗 / 事件
→ 返回宗门
→ 验证世界与 NPC 后果
```

## 14. 明确不做

V0.1 不实现：

- Anchor / 回溯 / 承世 / 悟世 / 跨世 Trait。
- 筑基完整突破与第二大境界规则层。
- 完整宗门派系政治。
- 家族路线。
- 大规模经济模拟。
- 世界程序化生成。
- 大型开放世界。
- Steamworks 正式集成。
- 运行时 AI NPC Agent。
- 复杂生产系统。

## 15. 完成标准

V0.1 完成至少满足：

1. Windows 构建可启动。
2. 玩家可控制沈川探索四类最小区域。
3. 游戏时间能够被修炼、旅行、疗伤等有意义行为推进。
4. NPC 会基于时间和状态改变位置 / 行为。
5. 情报能改变准备、对话或战斗合法选项。
6. 玩家面对真实资源取舍。
7. RTwP 战斗能够完整跑通。
8. 伤势和资源后果会延续到战斗后。
9. 黑水事件至少有一层可调查隐藏真相。
10. 事件结束后 NPC / 世界状态持续改变。
11. 普通 Save / Load 能正确恢复权威状态。
12. Continuous-Life Scenario Test 可在 CI / AI 环境自动运行。
