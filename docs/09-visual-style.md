# 视觉风格基线

## 1. 总体方向

> **精致纯 2D 东方修仙像素 RPG。**

关键词：

```text
东方修仙
像素角色
俯视 / 斜俯视
墨青
暗金
山水云雾
克制光影
古朴材质
```

不采用高成本 3D HD-2D 作为当前制作路线。

## 2. 场景表现

地图以 TileMapLayer 和 2D Sprite 为基础，通过以下手段增强层次：

- Y-sort / Z layering。
- Light2D。
- 雾气 / 云气。
- Particles2D。
- 少量 2D Shader。
- 前景遮挡与环境动画。
- 局部光源和天气变化。

目标是“有氛围的像素修仙世界”，不是追求电影级特效。

## 3. 色彩

主色倾向：

- 墨青 / 深青：世界与界面基础。
- 暗金 / 古铜：重要资源、身份、稀有对象。
- 青玉 / 冷青：灵气、信息、特殊修真感。
- 米白 / 宣纸色：文本与信息面板。

不同宗门、功法和地区可以有自己的副色体系。

## 4. 人物

角色视觉应优先保证：

- 在地图尺度下可辨识。
- 宗门 / 身份 / 境界差异能通过服饰、法器、光效体现。
- 动作数量可控，服务移动、施法、受击、死亡等核心玩法。

V0.1 不追求大量方向帧与复杂骨骼动画。

## 5. 修炼表现

修炼、突破和高阶能力可以使用：

- 灵气粒子。
- 法阵 / 道纹。
- 气流 / 云雾。
- 光照变化。
- 短暂全屏或局部特效。

避免常态化满屏粒子，重要境界变化才提升视觉强度。

## 6. 战斗表现

战斗特效必须优先服务规则可读性：

- 施法范围清楚。
- 危险区域清楚。
- 弹道 / 目标关系清楚。
- 打断和状态变化清楚。

不因为像素风而牺牲 RTwP 战术信息。

## 7. UI 风格

UI 使用东方修真语汇，但避免过度装饰：

- 墨青底色。
- 暗金边框或强调。
- 青玉色用于情报、灵气、可交互提示。
- 宣纸 / 玉简 / 木牌感可用于局部面板。

不再使用“命轮 / Anchor / 前世 Knowledge / 承世 / 悟世”作为核心视觉符号。

## 8. 事件与立绘

重要 NPC 或重大事件允许使用：

- 像素半身像。
- 低成本插画。
- 场景内聚焦演出。

但普通交谈不要求每个 NPC 配高成本立绘。

## 9. V0.1 视觉范围

只需要建立一套可扩展的基础视觉语言：

- 青玄宗。
- 青石坊市。
- 黑水山。
- 黑水秘境。
- 沈川与 3～5 个重要 NPC。
- 少量敌人、术法和法宝特效。

先证明地图、人物、事件和战斗能在同一视觉语言下成立，再扩大资产量。
