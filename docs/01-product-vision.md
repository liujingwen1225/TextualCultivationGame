# 产品愿景：正统修仙人生模拟 RPG

## 1. 产品定位

《诸世问道》（暂定名）当前定位：

> **Steam / Windows 优先的东方修仙人生模拟 RPG。**

玩家扮演修真世界中的一个具体修士，在真实可探索的 2D 像素世界中生活、修炼、探索、战斗、社交、调查和争夺机缘。

游戏的核心幻想不是“管理一个宗门”或“不断刷副本升级”，而是：

> **我真正作为一个修士，在这个修真社会里活过一段完整的人生。**

## 2. 设计参考与取向

世界观结构参考方向：

- 《玄鉴仙族》的修真社会真实感、资源与制度约束。
- 《苟在初圣魔门当人材》的高危修仙、信息差与利益关系。

只吸收结构，不复制具体人物、势力、剧情、功法和设定。

产品原则：

> **有制度、有利益、有情义、有算计，也有真实死亡风险的修真社会。**

正道、魔道、家族、宗门、散修之间的差异来自道统、制度、资源使用方式和利益逻辑，不采用“正道必善、魔道必恶”的简单二元划分。

## 3. 核心玩法支柱

### 3.1 修炼成长

境界、功法、术法、法宝、资源、伤势、寿元和突破共同构成成长，而不是单一经验等级。

### 3.2 世界探索

玩家直接控制角色在宗门、坊市、野外、秘境等地图中移动、调查和行动。地图负责空间关系和沉浸，而不是用菜单替代世界。

### 3.3 战术战斗

战斗是核心支柱之一，采用当前地图 RTwP 战术制式。强调位置、动作时间、术法、法宝、消耗品、伤势和准备，不强调动作游戏手速。

### 3.4 NPC 与关系

重要 NPC 有自己的目标、利益、秘密、关系和时间安排，不等待玩家触发。玩家可以建立师徒、同门、盟友、敌对、利益合作等关系。

### 3.5 修真社会

宗门、家族、散修、坊市和高阶修士共同形成地区秩序。境界是权力基础，但身份、传承、关系、职位和资源同样重要。

### 3.6 世界时间与动态事件

修炼、旅行、疗伤等会真实推进游戏时间。秘境会关闭、NPC 会行动、战争会发生、机会会过期。

### 3.7 情报、调查与机缘

角色通过观察、交谈、调查、文献和人物关系获得情报。情报可能是事实、传闻或推断，并能改变准备、对话、战斗和资源决策。

### 3.8 长期后果

选择会持续影响伤势、资源、关系、身份、NPC 命运、势力状态和世界事件。游戏不把每个问题重置成独立任务副本。

## 4. 核心循环

```text
发现机会 / 危险
↓
调查与判断
↓
准备
├─ 修炼
├─ Build
├─ 丹药 / 符箓 / 法宝
├─ NPC / 盟友
├─ 情报
└─ 时间安排
↓
行动
├─ 战斗
├─ 秘境
├─ 宗门事务
├─ 调查
├─ 交易
└─ 突破
↓
后果
├─ 成长
├─ 伤势
├─ 资源变化
├─ 关系 / 身份变化
├─ 新情报
├─ 新机会 / 危险
└─ 世界状态变化
↓
继续人生
```

## 5. 时间是战略资源

现实操作时间不等于游戏世界时间。

```text
重要交谈 / 本地调查 → 分钟 / 小时
采集 / 短途行动       → 小时 / 半日
跨区域旅行             → 小时 / 天
疗伤 / 炼制 / 普通修炼 → 天 / 月
闭关                   → 月 / 年
```

玩家不可能同时抓住所有机会，因此需要选择。

## 6. 目标与任务表达

游戏不以传统主线任务列表组织全部玩法。

玩家更常看到“当前机会 / 风声 / 人生目标”，例如：

- 还差一味药可尝试突破。
- 三日后外门小比。
- 某师兄近期频繁前往黑水山。
- 坊市出现适合当前功法的法器。
- 半月后秘境开放。

玩家可以忽略这些机会，但世界会继续变化。

宗门任务和坊市委托存在，但只是世界中的活动类型之一。

## 7. 死亡与存档

当前产品不把死亡设计成 Meta 循环。

```text
死亡
→ 失败反馈
→ 读取最近合法 SaveGame / 自动存档 / 检查点
→ 继续游玩
```

死亡在世界内容中仍然可以很危险、很频繁，但存档机制不需要世界观解释。

## 8. 明确不做

当前产品不做：

- Anchor / 回溯 / 承世 / 悟世。
- 跨世 Trait、跨世 Knowledge。
- Roguelite 多周目数值成长作为核心。
- 纯文字 / AI Dungeon 自由输入游戏。
- 《Project Zomboid》级别的全社会逐秒模拟。
- 《八方旅人》级别的 3D HD-2D 制作规模。
- 大型无缝开放世界。
- MMORPG / 联机 / 账号服务器架构。
- 宗门建造经营作为主玩法。
- 每一种炼丹、炼器、制符、阵法都做成复杂生产小游戏。

## 9. 产品成功标准

如果游戏成立，玩家应能产生这样的叙述：

> “我原本只是青玄宗一个炼气弟子。为了筑基资源，我认识了谁、得罪了谁、学了哪门功法、错过了什么机会、在哪场战斗留下重伤、为什么最后选择离开宗门——这些都构成了我自己的修仙人生。”

这比单纯“我升到了多少级、打了多少 Boss”更重要。
