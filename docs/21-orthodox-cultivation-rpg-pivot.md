# 《诸世问道》产品方向调整：正统修仙人生模拟 RPG

> 状态：当前产品方向最高优先级决策。
>
> 本文覆盖此前以多世回溯为核心的 Roguelite 设计。旧 Anchor / 承世 / 悟世 / 跨世 Trait / 回溯次数等文档保留为历史方案，不再约束当前产品和架构。

## 1. 新产品定位

《诸世问道》调整为：

> **Steam / Windows 优先的东方修仙人生模拟 RPG。**

玩家扮演修真世界中的一个具体人物，在持续运转的修真社会中探索、修炼、战斗、建立关系、争夺资源、经历宗门与地区事件，并通过长期选择形成属于自己的修仙人生。

不再以“死亡 → 回溯 → 跨世成长”作为核心循环。

## 2. 核心体验

核心循环调整为：

```text
探索世界
↓
发现人物 / 机缘 / 危险
↓
准备
├─ 修炼
├─ 功法 / 术法 Build
├─ 法宝 / 丹药 / 符箓
├─ 调查与情报
├─ NPC 关系
└─ 时间与资源取舍
↓
行动
├─ 战斗
├─ 秘境
├─ 宗门事务
├─ 调查
├─ 交易
└─ 突破
↓
承担长期后果
↓
继续人生
```

玩家幻想从“记住未来并改命”调整为：

> **真正活完一段修仙人生，并逐渐从底层修士成长为能够影响人物、宗门与地区格局的人。**

## 3. 当前核心支柱

1. 修炼成长与境界质变。
2. 可探索的纯 2D 像素修真世界。
3. 原地图 RTwP 战术战斗。
4. NPC 目标、关系、秘密与时间安排。
5. 宗门、家族、散修、坊市等修真社会结构。
6. 游戏内时间持续推进，世界事件不会等待玩家。
7. 情报、调查、传闻、隐藏真相与机缘。
8. 玩家选择对人物与世界产生长期后果。

## 4. 明确移除的核心系统

从当前产品方向中移除：

- Anchor / 天衍锚点。
- 回溯次数。
- 死亡后开启下一世。
- 承世。
- 悟世。
- 跨世 Trait Library。
- 跨世 Knowledge。
- 多世唯一物时间线规则。
- 以多世回溯为基础的 World Fate / Meta Progression。

这些内容只作为历史设计保留，不进入当前实现。

## 5. 死亡与存档

死亡恢复为正统单机 RPG 逻辑：

```text
死亡
→ 读取最近存档 / 玩家选择的存档
→ 继续游戏
```

存档采用普通 SaveGame：

- 自动存档。
- 关键节点存档。
- 手动存档。

无需区分 AnchorSnapshot 与跨世状态。

## 6. 情报 / 见闻系统

原 Knowledge 中有价值的部分保留，但改为角色当前世界内的“情报 / 见闻 / 认知”。

它可以记录：

- 人物秘密。
- 地点信息。
- 危险机制。
- 资源与机缘线索。
- 传闻与可信度。
- 调查结果。
- 势力关系。

这些信息来自当前人生中的真实调查、观察、交谈和事件，不跨死亡或新游戏永久继承。

## 7. 保留的既有设计

此前以下方向继续有效：

- Godot 4.7.x .NET + C# + .NET 8 + pure 2D。
- Steam / Windows-first。
- Game Core 为纯 C# 规则层，Godot 负责表现、输入和适配。
- 游戏时间由有意义行为推进，不由帧数 / 移动步数推进。
- 功法 / 术法 / 神通分层。
- 境界是规则质变和社会层级，不是单纯等级。
- 灵根、体质、资质的路线差异。
- 气血 / 法力 / 神识等运行资源。
- 结构化伤势与长期后果。
- 宗门 / 家族 / 散修路线。
- 状态驱动的轻量经济。
- 核心 NPC 拥有目标、利益、秘密和状态。
- 世界事件与 NPC 不等待玩家。
- 高阶修士形成真实政治威慑。
- 原地图 RTwP 战术战斗，位置是战术资源而非操作技术考核。

## 8. 当前架构原则

当前运行时收敛为：

```text
Godot Scene / Node
        ↓
Application Layer
        ↓
Pure C# Game Core
        ├─ Player / Cultivation
        ├─ World / Time
        ├─ NPC / Relationship
        ├─ Event Engine
        ├─ Combat
        ├─ Journal / Knowledge
        ├─ Inventory / Economy
        └─ SaveGame
```

明确不提前建设：

- MultiAnchorTimelineManager。
- InheritanceResolver。
- TraitCandidateGenerator。
- CrossLifeState。
- MetaProgressionService。
- 跨世唯一物协调器。

## 9. V0.1 新目标

V0.1 不再做“黑水三世”。

新的垂直切片应验证一段连续人生中的完整小循环：

```text
青玄宗外门生活
↓
发现黑水机会
↓
调查人物与情报
↓
在有限灵石和时间下准备
↓
修炼 / 配置术法 / 购买资源
↓
前往黑水山与秘境
↓
RTwP 战斗与危险处理
↓
揭开一层隐藏真相
↓
获得成果并返回宗门
↓
NPC / 世界状态发生持续变化
```

V0.1 的目标不是覆盖完整修仙世界，而是证明：

> **探索、修炼、NPC、时间、资源、情报和战斗组合起来，已经能形成一段有修仙人生感的小型 RPG。**
