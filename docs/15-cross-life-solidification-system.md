# 诸世问道：跨世固道系统

> 状态：设计基线 V1.0  
> 目标：在“Knowledge / Insight 为主要跨世成长”的基础上，引入高代价、低频率的实体成果保留机制，让玩家在极其成功的一世中拥有真正的取舍。

---

# 1. 为什么需要固道

如果所有实体成长都必然在回溯后消失，玩家可能产生：

> 这一世拿到再好的东西也终究会消失。

因此增加：

# 固道

玩家在一世结算时，可以消耗稀有的跨世资源，从以下成果中选择 **一项** 固化到锚点：

- 当前境界
- 部分修为
- 一件物品
- 一部功法
- 一件装备

Knowledge / Insight 仍按正常规则结算，不占固道选择。

---

# 2. 核心循环

```text
本世结束
↓
诸世结算
↓
获得 Knowledge / Insight
↓
检查是否拥有足够天衍本源
↓
选择是否固道
↓
从本世实体成果中选择一项
↓
消耗天衍本源
↓
将对应成果写入新的 Anchor State
↓
回到锚点
```

固道是主动战略选择，不是死亡自动奖励。

---

# 3. 固道资源

暂定名称：

> **天衍本源**

特点：

- 极稀有
- 跨世持有
- 不通过普通刷怪或日常任务稳定获得
- 用于突破“未来只是推演”的边界

主要来源：

- 首次完成重大事件链
- 首次破解重要秘境
- 首次突破大境界
- 解决重大因果
- 发现重大世界秘密
- 稀有诸世成就
- 特殊天衍事件

禁止：

- 普通怪物掉落
- 普通随机事件大量产出
- 通过反复自杀稳定刷取

---

# 4. 五类固道

## 4.1 固道·境界

保留当前已稳定完成的境界。

例如：

```text
Anchor：炼气三层

本世：炼气七层

结算选择：
固道·境界

新的 Anchor：炼气七层
```

特点：

- 价值最高
- 成本最高
- 只能保留已经稳定突破完成的境界
- 不允许固化“突破进行中”或临时增境状态

建议：

> 大境界固化成本显著高于小境界。

---

## 4.2 固道·修为

将本世一部分修为沉淀到 Anchor。

例如：

```text
Anchor：炼气六层 20%
本世：炼气六层 88%

固道后：
Anchor：炼气六层 55%
```

原则：

- 不直接 100% 搬运。
- 具体转化比例由平衡决定。
- 不允许借此跨越境界突破。

它的定位是：

> 减少重复修炼，而不是绕过突破系统。

---

## 4.3 固道·物

从本世背包选择一件允许跨世的物品带回锚点。

例如：

- 筑基丹
- 稀有灵药
- 秘境令牌
- 特殊材料
- 唯一剧情物品

每个物品定义：

```text
solidifiable: true / false
solidify_cost
```

部分世界观上不能跨世的物品可以禁止固化。

---

## 4.4 固道·法

保留一部本世真正掌握的功法。

区别：

```text
Knowledge：
我知道《玄水真诀》在哪里。

固道·法：
我已经掌握《玄水真诀》并带回锚点。
```

可以保留：

- 功法掌握状态
- 基础理解

不应默认完整保留本世所有极高理解度；具体理解仍受 Insight 规则约束。

这样不会让一次固道同时得到两个系统的全部收益。

---

## 4.5 固道·器

保留一件装备。

例如：

```text
青冥剑
古修护符
特殊法袍
```

装备必须满足：

- 当前真实持有
- 未损毁
- 可固道

装备本身可能存在境界要求，即使带回低境界锚点，也不一定能立刻发挥全部效果。

---

# 5. 为什么只能选一项

一世可能同时获得：

```text
炼气八层
修为 78%
玄水真诀
青冥剑
筑基丹
```

如果全部保留，回溯系统会迅速失去意义。

因此核心选择是：

```text
① 固化境界
② 固化修为
③ 带回筑基丹
④ 固化玄水真诀
⑤ 带回青冥剑
```

只能选一项。

玩家真正面对：

> 这一世最值得变成“现实”的究竟是什么？

---

# 6. 固道与定世的区别

两者不能混为一谈。

## 固道

只把一项成果带回当前锚点。

```text
Anchor A
↓
Run
↓
固道一项
↓
仍然回到 Anchor A 的时间点
```

## 定世

确认整条未来路线，将现实真正推进到新的时间点，并建立新锚点。

```text
Anchor A
↓
验证一段未来
↓
定世
↓
现实推进
↓
Anchor B
```

固道是“把一点未来带回来”。

定世是“让这一段未来成为现实”。

---

# 7. 防止破坏平衡

必须限制：

1. 一次结算最多固道一项。
2. 固道消耗天衍本源。
3. 同类高价值固道成本递增或受阶段限制。
4. 不允许复制唯一物品。
5. 固化装备仍受装备条件限制。
6. 固化功法不等于保留全部本世悟道。
7. 固化修为不能绕过突破。
8. 固化境界必须来源于真实完成的境界。
9. 不能通过回溯制造两个同一唯一实体。
10. 天衍本源不能被低成本无限获取。

---

# 8. 与随机事件的关系

固道会显著提高奇遇的价值。

原本：

```text
极低概率得到稀有灵药
↓
这一世最终死亡
↓
灵药消失
```

现在：

```text
极低概率得到稀有灵药
↓
是否值得消耗天衍本源固化？
```

因此奇遇不再只是短期收益，还会产生跨世战略选择。

---

# 9. 与前世 Knowledge 的关系

即使玩家没有选择固化某件物品，也可能保留相关知识。

例如：

```text
第一世：
发现黑水洞府里有筑基丹
但选择固化青冥剑

下一世：
没有筑基丹
但拥有 Knowledge：洞府中存在筑基丹
```

玩家可以重新规划，再次获取。

所以 Knowledge 仍然是最基础、最稳定的永久成长。

---

# 10. 与长期成长的关系

最终跨世成长由两层组成：

```text
Knowledge / Insight
高频、稳定、认知型成长

+

固道
低频、昂贵、实体型成长
```

这种组合可以避免两个极端：

- 什么都不保留导致一世成果缺乏价值。
- 什么都保留导致 Roguelite 回溯失去意义。

---

# 11. 技术状态变化

Game Core 必须把固道作为明确命令执行。

概念：

```java
public sealed interface SolidificationChoice {
    record Realm(...) implements SolidificationChoice {}
    record Cultivation(...) implements SolidificationChoice {}
    record Item(...) implements SolidificationChoice {}
    record Technique(...) implements SolidificationChoice {}
    record Equipment(...) implements SolidificationChoice {}
}
```

执行：

```java
SolidificationResult solidify(
    AnchorState anchor,
    RunState completedRun,
    MetaState meta,
    SolidificationChoice choice
);
```

必须完成：

- 校验本世是否真实拥有该成果
- 校验是否允许固道
- 校验天衍本源
- 消耗资源
- 生成新 Anchor State
- 写入固道历史记录

客户端不得自行修改 Anchor。

---

# 12. 结论

跨世体系最终不是：

> 所有东西都清空。

也不是：

> 死了以后什么都能继承。

而是：

> **知识默认属于你，实体未来则必须付出极高代价，选择其中最重要的一项，把它变成现实。**
