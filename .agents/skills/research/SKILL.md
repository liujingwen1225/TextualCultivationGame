# Research

Investigate the question using sources that own the fact: official documentation, standards/specifications, source repositories, release notes, or first-party APIs.

1. State the research question precisely.
2. Prefer primary sources and verify time-sensitive claims against current material.
3. Separate observed facts from interpretation or recommendation.
4. Capture assumptions, version/date constraints, and contradictory evidence.
5. When the result should persist, write one cited Markdown note in the repository's existing research/docs convention and link it from the relevant issue/spec.

Research informs decisions; it does not silently change `CONTEXT.md`, active design docs, or implementation scope.

Completion criterion: every material claim is traceable to a high-trust source and the answer identifies what is known, uncertain, and decision-relevant.
