# 诸世问道（暂定名）

一款以 **未来推演、死亡回溯、前世情报、修仙成长** 为核心的东方文字修仙 Roguelite / RPG。

> 经历未来，记住死亡，然后重新选择。

## 项目定位

玩家扮演一名普通修士，而不是天道或世界管理者。玩家通过修炼、历练、秘境、人物关系与事件选择推进一世人生；当本次推演死亡或失败后，回到天衍锚点，物质成果消失，但可保留部分情报、认知与悟道，再利用前世经验改变新的时间线。

项目首先是一款 **游戏**。AI 是辅助能力，不是核心规则引擎：

- 游戏代码决定数值、条件、结果和状态变化。
- 内容配置决定事件结构、选择和因果链。
- AI 可用于事件润色、NPC 表现、人生总结和内容生产辅助。
- V0.1 不依赖自由输入，也不依赖运行时 AI 才能完成核心循环。

## 核心循环

```text
建立天衍锚点
    ↓
开始一世推演
    ↓
修炼 / 历练 / 交友 / 探索 / 决策
    ↓
时间与寿元推进
    ↓
获得资源 / 功法 / 情报 / 因果
    ↓
突破 / 失败 / 死亡
    ↓
诸世结算
    ↓
保留部分情报与悟道
    ↓
回到锚点
    ↓
解锁前世记忆选项
    ↓
改变未来，产生世界线偏移
```

## 当前明确边界

V0.1 采用固定行动与事件选项，不做自由输入。第一阶段只验证：

1. 时间与寿元是否形成有效压力。
2. 修炼成长是否有明确反馈。
3. 事件选择是否能形成因果。
4. 死亡回溯是否带来“再来一世”的动力。
5. 前世情报是否能真正解锁新决策，而非仅提供攻略文本。
6. 改变未来后，旧情报是否会逐渐失效并形成新的未知。

## 开发原则

- **游戏先于 AI**：没有模型 API，核心游戏仍可完整运行。
- **系统先于内容量**：先验证循环，再扩充宗门、秘境、功法和剧情。
- **规则先于文案**：事件结果必须由规则和配置决定，AI 只负责表现。
- **知识也是资源**：跨世继承的核心不是装备，而是玩家对世界的认知。
- **一个人可维护**：优先数据驱动和内容工具，避免大地图、全 NPC Agent、复杂开放世界模拟。

## 第一阶段目标

做出一个约 15–30 分钟即可体验核心特色的可玩原型：

> 第一世因未知而死亡 → 结算获得前世情报 → 回到锚点 → 同一事件出现新的“前世记忆”选项 → 改写事件结果 → 进入此前未见的未来。
