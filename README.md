# 诸世问道（暂定名）

一款以 **未来推演、死亡回溯、前世情报、随机事件与修仙成长** 为核心的东方文字修仙 Roguelite / RPG。

> 经历未来，记住死亡，然后重新选择。

## 项目定位

玩家扮演一名普通修士，而不是天道或世界管理者。玩家通过修炼、历练、秘境、人物关系与事件选择推进一世人生；当本次推演死亡或失败后，回到天衍锚点，物质成果消失，但可保留部分情报、认知与悟道，再利用前世经验改变新的时间线。

项目首先是一款 **游戏**。AI 是辅助能力，不是核心规则引擎：

- 游戏代码决定数值、条件、结果和状态变化。
- 内容配置决定事件结构、选择和因果链。
- AI 可用于事件润色、NPC 表现、人生总结和内容生产辅助。
- 核心游戏不依赖自由输入，也不依赖运行时 AI 才能成立。

## 核心循环

```text
建立天衍锚点
    ↓
开始一世推演
    ↓
修炼 / 历练 / 交友 / 探索 / 决策
    ↓
随机事件 / 条件事件 / 连锁事件 / 奇遇
    ↓
获得资源 / 功法 / 情报 / 因果
    ↓
突破 / 失败 / 死亡
    ↓
诸世结算
    ↓
保留部分 Knowledge / Insight
    ↓
回到锚点
    ↓
解锁前世记忆选项
    ↓
改变未来，产生世界线偏移
```

## 当前核心设计决策

### 1. 长期游玩不靠拖慢升级

境界要有分量，但不通过巨型经验条或固定超长小时数制造时长。

长期可玩性主要来自：

```text
随机事件
+
条件事件
+
连锁事件
+
NPC人物线
+
奇遇
+
秘境
+
前世 Knowledge
+
世界线变化
```

正式境界速度由可玩原型数据决定，当前不硬编码“首次筑基必须多少小时”。

### 2. 同一世界，每一世经历不同

世界保留可学习的骨架，例如宗门、秘境开启和关键人物；日常经历、人物事件、奇遇和部分事件链则由当前状态和随机事件池决定。

玩家应该产生：

> “这个世界我熟悉，但这一世发生的事情不完全一样。”

### 3. 前世知识是真正的永久成长

上一世死亡后，玩家可获得 Knowledge / Insight。

下一世它们可以：

- 解锁新的事件选项
- 解锁调查事件
- 提前规避风险
- 缩短已经反复验证的低价值流程
- 改变人物命运
- 改变事件池

而不是直接继承修为和装备。

### 4. 改命越多，未来越陌生

固定锚定事件提供“知未来”的基础，但重要行为会造成世界线偏移。

玩家越成功利用前世信息改变命运，越会进入过去从未经历过的新未来。

### 5. NPC 不做全量 Agent

核心 NPC 使用：

```text
目标
+
秘密
+
多维关系
+
因果
+
关键记忆
+
人物专属事件池
```

来形成稳定人物行为。

V0.1 不运行全天候 NPC LLM Agent。

### 6. 战斗不是刷怪主循环

战斗主要承担风险结算：

- 是否值得冒险
- 是否准备充分
- 打不过能否撤退
- 受伤之后会发生什么
- 死亡能学到什么

关键失败必须尽量产生可理解的后果，而不是纯随机暴毙。

### 7. 世界采用节点式结构

不做开放世界大地图。

世界由：

```text
区域
→ 地点
→ 子地点
→ 地点事件池
```

组成。

秘境采用“固定骨架 + 可变事件”，使前世知识既有价值，又不会让每一世完全重复。

## 当前开发边界

V0.1：

- 固定行动与事件选项
- 不做自由文本行动
- 不做开放世界大模拟
- 不做全 NPC Agent
- 不做复杂宗门经营
- 不做多人
- 不做大地图

第一阶段只验证：

```text
未知未来
↓
随机/条件事件
↓
错误决策或信息不足
↓
失败 / 死亡
↓
获得前世知识
↓
回溯
↓
出现新的特殊选项或事件
↓
改变结果
↓
进入新的未知内容
```

## 开发原则

- **游戏先于 AI**：没有模型 API，核心游戏仍可运行。
- **事件支撑长期可玩性**：不要靠故意拖慢境界升级制造时长。
- **规则先于文案**：所有真实状态变化由规则和配置决定。
- **知识也是资源**：跨世继承的核心是玩家对世界的认知。
- **固定骨架 + 随机经历**：让未来既可以被学习，又不会变成固定攻略。
- **风险必须有信息价值**：重大失败与死亡应尽量让玩家理解下一世该改变什么。
- **一个人可维护**：优先数据驱动、事件编辑器和内容工具。

## 第一阶段目标

做出一个短时间即可体验核心特色的可玩原型：

> 第一世因未知而失败 → 结算获得前世情报 → 回到锚点 → 同一世界出现新的“前世记忆”选项或事件 → 改写结果 → 进入此前未见的未来。

首个验证场景使用 **黑水秘境**：第一次死于未知，第二次利用已知，第三次踏入新的未知。
